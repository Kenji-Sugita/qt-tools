# Qt Creator プラグイン案メモ

## 前提

- 主機能は `qtcling` の対話実行環境
- プロパティーエディターは主機能ではなく開発支援ツール
- 今後はサンプルコードを追加し、ドキュメントを充実させる予定
- 対象には Qt / C++ が初めての学習者も含まれる
- 主な適用対象はアプリケーション全体の実行ではなく、ウィジェット開発や UI 調整などの
  部品単位の試行と確認

この前提では、Qt Creator プラグインの中心価値は単なる開発効率化だけではなく、
「サンプルを動かしながら Qt と C++ を学べること」と
「ウィジェット開発や UI 調整を速くすること」に置くのが自然。

## 方向性

初心者向けでは、自由な REPL 単体よりも次を前面に出した方がよい。

- 説明付きサンプル
- 段階実行
- 実行結果の即時可視化
- REPL から通常の `.cpp` への橋渡し

プロパティーエディターも、開発支援だけでなく `QObject` と property の学習補助として使える。

## 案

### 1. Sample + Explanation Runner

サンプルコードを一覧表示し、それぞれに「何を学ぶサンプルか」を短く添えて実行できる案。
実行後はそのまま `qtcling` の REPL に接続し、続きを試せるようにする。

狙い:

- 静的なサンプル集より学習効率を上げる
- 初学者が「読むだけ」で止まらず、その場で挙動を確認できる
- 今後追加するサンプル群をそのまま価値に変えやすい

### 2. Interactive Qt Learning Console

サンプルやチュートリアルの説明に沿って、コードを一行ずつ `qtcling` に流せる案。
`QPushButton` の生成、signal-slot 接続、property 変更などを段階的に体験させる。

狙い:

- Qt と C++ の初学者の理解を早める
- 失敗箇所を小さく分けて試せる
- REPL の自由度を保ちつつ学習導線を与えられる

### 3. Step-by-Step Qt Tutorial Dock

Qt Creator 内にチュートリアル専用 Dock を置き、`QObject`、widget、signal/slot、
property などを順番に体験できる案。

狙い:

- ドキュメント充実の方針と相性がよい
- IDE 内で読む、実行する、試すを往復できる
- 初学者が概念を断片ではなく流れで理解しやすい

### 4. Live Object Explorer

実行中の Qt アプリのオブジェクトを選ぶと、クラス名、親子関係、主要 property、
signal などを見られる案。

狙い:

- 初学者が「今見えている部品が何か」を理解しやすくする
- `QObject` の構造を可視化できる
- REPL やプロパティーエディターと自然に連携できる

### 5. Property Playground

既存のプロパティーエディターを学習用に再解釈し、`text`、`enabled`、`geometry`、
`orientation` などを変えると UI がどう変化するかを即座に見せる案。

狙い:

- property の概念を体感的に学ばせる
- 主機能ではなく補助教材として使う
- 開発支援ツールを学習支援にも転用できる

### 6. REPL History to Source

REPL で試した内容を、最終的に通常の `.cpp` サンプルへ整形して保存する案。

狙い:

- 対話実験から通常の C++ コードへ移りやすくする
- 学習者が「試しただけ」で終わらず成果物を残せる
- サンプルやドキュメントの素材としても再利用しやすい

## 優先度案

学習効率の観点では、まず次の順がよい。

1. Sample + Explanation Runner
2. Interactive Qt Learning Console
3. Step-by-Step Qt Tutorial Dock
4. Live Object Explorer
5. Property Playground

## MVP の考え方

最初の MVP は次の 3 点セットが現実的。

- サンプル一覧
- 各サンプルの短い説明表示
- 実行後に REPL へ接続する導線

これで「読む」「動かす」「少し改変して試す」までを最短で回せる。

## メッセージ整理

利用者向けの主メッセージ:

- Qt アプリを動かしたまま IDE 内で対話実験できる
- サンプルと説明を通して Qt と C++ を学びやすい

補助メッセージ:

- 実行中オブジェクトの構造や property を可視化できる
- プロパティーエディターは開発支援と学習支援の両方に使える
