Qt Cling 実験的リリース

Qt Cling 実験的にリリースします。以下のページからダウンロードできます。

    http://sraap298/~sugita/tools/qtcling/index.html

適用範囲と対象ユーザーはニッチですが、製品化できる機能を備えたツールです。

  Qt Cling は、Qt GUI プログラムを GUI 画面を表示したまま対話的に試せるツール
です。実験的リリースでは、ハードコーディングされたパスなど開発環境に依存した部
分を修正すれば動作させられます。多少の Cling の知識が必要です。

  主な対象ユーザーは、Qt と C++ を試しながら学びたい初学者、教材や研修環境を整
えたい教育担当者、部品や機能の動きをその場で確かめたい試行型の開発者です。通常
の「編集、ビルド、実行」の繰り返しを軽くし、プログラムを動かしながら理解や試作
を進めやすくする点が強みです。アプリケーション全体の実行ではなく、ウィジェット
開発やウィジェットの見た目調整、小さな挙動確認に向いています。

  支援ツール、サンプル、解説文書などを用意し、配布に適するようにする予定です。
現在のサンプルはウィジェット使ったもののみのため、QML 向けのサンプルも必要です。

  Qt Cling の基本機能は、Qt に依存しないように実装した CLing GUI REPL (対話実
行) です。従って、Qt 以外の GUI フレームワークへの適用もできます。主要な候補は、
GTK、FLTK、wxWidgets です。

  配布に向けた主な残作業としては、Windows での対話実行への対応と、Windows での
ネイティブ動作方式への対応があります。Qt Creator プラグインの案もいくつか考え
ています。
