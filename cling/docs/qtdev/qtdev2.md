# Widgets 向け 20案、QML 向け 20案

承知しました。
では、**Cling を Qt 開発へ適用するための具体的なサンプルテーマ一覧**として、
**Widgets 向け 20案**、**QML 向け 20案**、加えて **共通/ハイブリッド 20案** をまとめます。

単なる列挙ではなく、各案について

* 何を試すか
* 何に役立つか
* Cling と相性がよい理由

が分かるようにします。

4. palette/style sheet 実験
5. オブジェクトツリー診断

2. binding/state 実験
3. contextProperty 試作
4. C++ model と ListView 接続
5. 実行中 QML インスペクター

# 5. 実際の開発フローに落とす案

このままテーマ一覧で終わらせず、実務向けにすると次の3系統が有効です。

## 1. 実験用

* `widgets_repl`
* `qml_repl`
* `hybrid_repl`

の3つの起動環境を作る。

## 2. 教材用

* 1テーマ1ファイル
* 小さな独立サンプル
* 目的と観察点をコメント化

する。

## 3. 診断用

* オブジェクトツリー表示
* プロパティー表示
* signal ログ
* レイアウト確認

の補助関数を整備する。
