# 概要設計

## 目的

`qeyes` の全体構成、主要責務、データの流れを定義し、詳細設計書の上位となる設計方針を示す。

## 対象

- メインウィンドウ
- 描画処理
- 入力処理
- 色設定ダイアログ
- 設定保存
- リソース参照

## 対象外

- 個別機能の詳細仕様
- 画面部品ごとの細かな寸法
- 描画アルゴリズムの数式詳細
- 画像生成手順の詳細

## システム概要

`qeyes` は、マウスポインターの方向を向く 2 つの目を表示する小さな Qt Widgets アプリケーションである。

アプリケーションは次の要素で構成される。

- 常時表示されるメインウィンドウ
- 目の描画処理
- マウス操作処理
- 色設定ダイアログ
- `QSettings` を使った設定保存
- アイコンなどのリソース参照

## 構成要素

### 1. メインウィンドウ

役割:

- 2 つの目を表示する
- マウス操作を受け付ける
- 再描画を駆動する

### 2. 描画処理

役割:

- 輪郭、白目、虹彩、瞳孔を描画する
- マウスポインター位置に応じて虹彩と瞳孔の位置を決める

### 3. 入力処理

役割:

- 左ドラッグによる移動
- 左ダブルクリックによる終了
- 右クリックによる色設定ダイアログ表示

### 4. 色設定ダイアログ

役割:

- 色設定を編集する
- プレビュー表示を行う
- 色選択ダイアログを開く

### 5. 設定保存

役割:

- 色設定を `QSettings` に保存する
- 起動時に設定を復元する

### 6. リソース参照

役割:

- アプリケーションアイコンを各プラットフォームに提供する
- ビルド設定やリソースファイルから参照される

## 主なデータの流れ

### 起動時

1. アプリケーション開始
2. メインウィンドウ生成
3. `QSettings` から色設定を読み込む
4. ウィンドウを表示する

### 通常動作時

1. タイマーで再描画要求を出す
2. 現在のマウスポインター位置を取得する
3. 目の各要素の位置を計算する
4. ウィンドウへ描画する

### 色設定変更時

1. 右クリックで色設定ダイアログを開く
2. 色プレビューから色選択ダイアログを開く
3. `OK` 時に色設定を反映する
4. `QSettings` に保存する
5. 再描画して見た目を更新する

## 責務分割

- メインウィンドウ
  - 表示、入力受付、再描画の起点
- 描画処理
  - 目の見た目と追従計算
- ダイアログ
  - 編集 UI と一時状態の保持
- 設定保存
  - 永続化と既定値管理
- リソース
  - 各プラットフォーム向けアイコン供給

## 非機能方針

- Qt Widgets ベースとする
- 描画は `QPainter` ベースとする
- 軽量な常駐ツールとして扱う
- macOS 固有対応は必要最小限に留める
- 画像アセットへの依存は最小限とする
