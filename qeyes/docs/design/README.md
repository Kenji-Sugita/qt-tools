# design/ README

このファイルは、`docs/design/` 配下の詳細設計書を案内するための README です。

## 現在ある設計書

- `PRODUCT_DESIGN.md`
  - `qeyes` が提供する機能、状態、対象範囲を定義する
- `UI_DESIGN.md`
  - 画面構成、操作、ダイアログ構成を定義する
- `RENDERING_DESIGN.md`
  - 目の描画構成、視線追従、再描画を定義する

## 将来追加する可能性がある設計書

- `SETTINGS_DESIGN.md`
  - 設定項目、保存キー、既定値、保存・復元タイミングを整理する
  - 設定の種類や保存仕様が増えた場合に追加する
- `RESOURCE_DESIGN.md`
  - アイコンやその他リソースの正本、派生物、参照関係を整理する
  - リソース種別や更新規則が増えた場合に追加する
