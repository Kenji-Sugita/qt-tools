# UI 詳細設計

## 目的

`qeyes` の画面構成、操作導線、ダイアログ構成を定義する。

## 画面一覧

- メインウィンドウ
- 色設定ダイアログ
- 色選択ダイアログ

## 1. メインウィンドウ

### 役割

- 2 つの目を表示する
- ポインター追従を視覚化する
- 最小限の操作を受け付ける

### 表示特性

- フレームレス
- 透過背景
- 最前面
- ツールウィンドウ
- 起動時にアクティブ化しない

### 操作

- 左ドラッグ
  - ウィンドウ移動
- 左ダブルクリック
  - アプリケーション終了
- 右クリック
  - 色設定ダイアログを開く

## 2. 色設定ダイアログ

### 役割

- 目の色設定を編集する

### 項目

- Outline
- Sclera
- Iris
- Pupil

### 行構成

各行は次で構成する。

- ラベル
- 色プレビュー
- `Reset` ボタン

### 色プレビュー

- 現在色を背景色として表示する
- 色コードを文字列で中央表示する
- 文字列は等幅フォントとする
- 文字サイズは標準ボタン文字の寸法感に合わせる
- 左クリックで色選択ダイアログを開く

### ダイアログ下部

- `Cancel`
- `OK`

### 動作

- `Reset`
  - 対象項目を既定値へ戻す
- `Cancel`
  - 編集内容を破棄する
- `OK`
  - 編集内容を反映して保存する

## 3. 色選択ダイアログ

### 役割

- 色の選択を行う

### 動作

- 色を確定した場合のみ対象項目へ反映する
- キャンセル時は変更しない

## プラットフォーム差分

- macOS では標準ボタンとの見た目差分を必要最小限で吸収する
- 他プラットフォームには不要な特例を持ち込まない
