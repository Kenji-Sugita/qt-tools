# 生成指示文

この文書の指示は、空の `qeyes/` ディレクトリを作成し、その直下に `OVERVIEW_DESIGN.md`、`PRODUCT_DESIGN.md`、`UI_DESIGN.md`、`RENDERING_DESIGN.md`、`AGENTS.md`、`UI_DESIGN_TEMPLATE.md` を配置した状態を前提にする。

標準の生成指示文は次の通りです。

```text
OVERVIEW_DESIGN.md と AGENTS.md に従って、
PRODUCT_DESIGN.md、UI_DESIGN.md、RENDERING_DESIGN.md を生成してください。
必要なら UI_DESIGN_TEMPLATE.md も参照してください。
```

更新時は次のように指示します。

```text
OVERVIEW_DESIGN.md の内容に合わせて
PRODUCT_DESIGN.md、UI_DESIGN.md、RENDERING_DESIGN.md を更新してください。
必要なら UI_DESIGN_TEMPLATE.md も参照してください。
```
