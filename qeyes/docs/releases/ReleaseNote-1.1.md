# qeyes 1.1 リリースノート

`qeyes` 1.1 では、見た目を調整できる設定ダイアログを追加しました。

## 追加した機能

- 右クリックで色設定ダイアログを開けます
- 次の色を個別に変更できます
- 輪郭
- 白目
- 虹彩
- 瞳孔
- `Reset` ボタンで各項目を既定値へ戻せます

## 改善点

- 虹彩レイヤーを追加し、瞳の色変更が見えるようにしました
- 選択した色を `QSettings` に保存し、再起動後も設定が維持されます
- macOS では色プレビューの見た目を標準ボタンの寸法感に合わせて調整しました

## 操作方法

- 左ドラッグ: ウィンドウ移動
- 左ダブルクリック: 終了
- 右クリック: 色設定ダイアログを開く

## ビルドと起動

```text
$ cmake -S . -B build
$ cmake --build build
$ ./build/qeyes
```

詳しい使い方は `docs/guides/USER_GUIDE-1.1.md` を参照してください。
