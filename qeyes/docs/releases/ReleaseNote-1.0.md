# qeyes 1.0 リリースノート

`qeyes` を追加しました。`qeyes` は、マウスポインターの方向を追いかける 2 つの目をデスクトップ上に表示する、小さな Qt Widgets アプリケーションです。

## 主な特徴

- 透明背景のフレームレスウィンドウ
- 常に最前面で表示
- 黒目がマウスポインターの位置を追従
- 左ドラッグで移動可能
- 左ダブルクリックで終了

## ビルドと起動

```text
$ cmake -S . -B build
$ cmake --build build
$ ./build/qeyes
```

## 実装メモ

- `Qt6::Widgets` ベースのアプリケーションです
- 画像ではなく `QPainter` による描画で目を構成しています

## 想定用途

- デスクトップ上の小さなアクセサリー
- Qt の透過描画サンプル
- マウス追従 UI の最小実装例
