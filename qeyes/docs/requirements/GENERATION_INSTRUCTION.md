# 生成指示文

この文書の指示は、空の `qeyes/` ディレクトリを作成し、その直下に `REQUEST.md`、`REQUIREMENTS.md`、`AGENTS.md`、`REQUIREMENTS_TEMPLATE.md` を配置した状態を前提にする。

標準の生成指示文は次の通りです。

```text
REQUEST.md と AGENTS.md に従って、
REQUIREMENTS.md を生成してください。
必要なら REQUIREMENTS_TEMPLATE.md も参照してください。
```

更新時は次のように指示します。

```text
REQUEST.md の内容に合わせて
REQUIREMENTS.md を更新してください。
必要なら REQUIREMENTS_TEMPLATE.md も参照してください。
```
