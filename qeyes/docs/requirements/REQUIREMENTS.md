# 要件定義

## 目的

`qeyes` が満たすべき機能要件、非機能要件、制約、受け入れ条件を定義する。

## 背景

`qeyes` は、マウスポインターの方向を追う 2 つの目をデスクトップ上に表示する小さな常駐型アプリケーションである。

視覚的なアクセサリーとしての用途に加え、Qt Widgets による透過描画、追従 UI、軽量な常駐ツールの実装例としても扱えることを目指す。

## 対象ユーザー

- デスクトップ上の小さなアクセサリーを使いたいユーザー
- Qt Widgets の描画や追従 UI の実装例を確認したい開発者

## 利用シーン

- デスクトップ上で常時小さな目を表示する
- マウスポインター追従の見た目を楽しむ
- Qt の透過描画やカスタムペイントの参考実装として利用する

## 機能要件

### 1. 表示

- 2 つの目を持つウィンドウを表示できること
- ウィンドウは最前面表示できること
- 背景は透明であること

### 2. 視線追従

- 目がマウスポインターの方向を向くこと
- 虹彩と瞳孔が白目の外へはみ出さないこと

### 3. 基本操作

- 左ドラッグでウィンドウを移動できること
- 左ダブルクリックで終了できること
- 右クリックで色設定ダイアログを開けること

### 4. 色設定

- 輪郭、白目、虹彩、瞳孔の色を変更できること
- 色プレビューから色を選択できること
- `Reset` により既定値へ戻せること
- `OK` で反映し保存できること
- `Cancel` で変更を破棄できること

### 5. 設定保存

- 色設定を保存できること
- 次回起動時に復元できること

## 非機能要件

- Qt Widgets ベースであること
- 描画は `QPainter` によること
- 軽量な常駐ツールとして扱えること
- QML / Qt Quick に依存しないこと
- macOS 固有対応は必要最小限に留めること

## 制約

- ウィンドウサイズ変更 UI は必須としない
- 位置永続化は必須としない
- テーマ機能は必須としない
- トレイ常駐は必須としない

## 対象外

- 複雑なアニメーション機能
- 詳細なテーマ管理
- 複数プロファイル管理
- 高度なアクセシビリティ設定 UI

## 受け入れ条件

- 起動すると 2 つの目が表示される
- マウスポインター移動に応じて視線が変わる
- 左ドラッグでウィンドウが移動する
- 左ダブルクリックで終了する
- 右クリックで色設定ダイアログが開く
- 色設定を変更して保存すると、再起動後も維持される
