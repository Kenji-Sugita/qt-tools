# 1. 概要

`qeyes` は、マウスポインターの位置を追いかける 2 つの目を常時最前面に表示する小さな Qt アプリケーションです。

1.1 版では、表示色を変更できる設定ダイアログが追加されました。

主な特徴は次の通りです。

- 透明背景の小さなウィンドウとして表示される
- 虹彩と瞳孔がマウスポインターの方向を向く
- 最前面表示で他のウィンドウの上に置ける
- ドラッグで好きな位置へ移動できる
- 右クリックで色設定ダイアログを開ける
- ダブルクリックで終了できる

# 2. 起動方法

ビルド済みバイナリーを起動します。

```text
$ ./build/qeyes
```

ソースからビルドする場合の一例です。

```text
$ cmake -S . -B build
$ cmake --build build
$ ./build/qeyes
```

# 3. 基本操作

## 3.1 ウィンドウを動かす

左ボタンでドラッグすると、ウィンドウ全体を移動できます。

```text
左ドラッグ: ウィンドウ移動
```

## 3.2 色を変更する

ウィンドウ上で右クリックすると、色設定ダイアログが開きます。

変更できる項目は次の通りです。

- Outline: 輪郭線
- Sclera: 白目
- Iris: 虹彩
- Pupil: 瞳孔

色プレビューをクリックすると色選択ダイアログが開きます。

```text
右クリック: 色設定ダイアログを開く
プレビューをクリック: 色選択
Reset: 対象項目を既定値へ戻す
OK: 変更を保存
Cancel: 変更を破棄
```

## 3.3 終了する

左ボタンでダブルクリックすると終了します。

```text
左ダブルクリック: 終了
```

ウィンドウを閉じた場合もアプリケーション全体が終了します。

# 4. 設定の保存

選択した色は `QSettings` に保存され、次回起動時に復元されます。

保存しているキーは次の通りです。

- `colors/outline`
- `colors/sclera`
- `colors/iris`
- `colors/pupil`

macOS では通常、ユーザー設定領域に保存されます。

# 5. 表示の仕組み

`qeyes` の見た目はコード内で動的に描画されています。

## 5.1 目の構成

左右の目はウィンドウサイズから計算され、各目は次の要素で構成されます。

- 輪郭
- 白目
- 虹彩
- 瞳孔

## 5.2 視線の追従

虹彩と瞳孔の中心位置は、各目の中心と現在のマウスポインター座標から求めます。

ただし、白目の内側に収まる範囲で移動量を制限しているため、目の外へはみ出しません。

## 5.3 再描画

約 16 ミリ秒ごとに再描画しているため、おおむね 60fps 相当で追従します。

# 6. ウィンドウの性質

`qeyes` は次の性質を持つ小さな常駐型ウィンドウです。

- フレームレスウィンドウ
- ツールウィンドウ
- 常に最前面
- 透過背景
- 起動時にアクティブ化しない設定

# 7. 制約と注意点

現状の実装では、次の点に注意が必要です。

- ウィンドウサイズの変更 UI はない
- 位置やサイズの永続化はしない
- 色以外の形状設定はない
- 複数モニター環境向けの細かな調整機能はない
- 終了操作はダブルクリック前提

# 8. まとめ

`qeyes` 1.1 は、マウスポインターを追う目を表示する基本機能に加えて、見た目の色を調整できるようになりました。

小規模な Qt Widgets アプリとして、透過描画、カスタムペイント、設定保存の例をまとめて確認できます。
