# 生成指示文

この文書の指示は、空の `qeyes/` ディレクトリを作成し、その直下に `CMakeLists.txt`、`main.cpp`、`qeyes.rc`、`assets/`、`AGENTS.md`、`BUILD_RESULT_TEMPLATE.md`、`VERIFICATION_RESULT_TEMPLATE.md`、`ISSUES_TEMPLATE.md` を配置した状態を前提にする。

標準の生成指示文は次の通りです。

```text
CMakeLists.txt、main.cpp、qeyes.rc、assets/、AGENTS.md に従って、
BUILD_RESULT.md、VERIFICATION_RESULT.md、ISSUES.md を生成してください。
必要なら BUILD_RESULT_TEMPLATE.md、VERIFICATION_RESULT_TEMPLATE.md、ISSUES_TEMPLATE.md も参照してください。
```

更新時は次のように指示します。

```text
CMakeLists.txt、main.cpp、qeyes.rc、assets/、AGENTS.md の内容に合わせて
BUILD_RESULT.md、VERIFICATION_RESULT.md、ISSUES.md を更新してください。
必要なら BUILD_RESULT_TEMPLATE.md、VERIFICATION_RESULT_TEMPLATE.md、ISSUES_TEMPLATE.md も参照してください。
```
