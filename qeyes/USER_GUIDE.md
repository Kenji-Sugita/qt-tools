# 1. 概要

`qeyes` は、マウスポインターの方向を追いかける 2 つの目をデスクトップ上に常時表示する小さな Qt Widgets アプリケーションです。

このガイドでは、単に操作方法を並べるのではなく、**`qeyes` を軽量な常駐ツールとしてどう使うか** という観点で整理します。

前提として重要なのは次の点です。

- `qeyes` は装飾的なウィンドウではなく、常時表示を前提にした小さなツールです
- 操作は最小限で、左ドラッグ、右クリック、左ダブルクリックに絞っています
- 見た目は画像ではなくコードで動的に描画しています
- 保存する設定は色と最前面設定だけで、位置やサイズなどは永続化しません

つまり、`qeyes` は多機能なデスクトップアクセサリではなく、**邪魔になりにくく、すぐ動いて、すぐ消せる目の常駐ツール** と考えると分かりやすくなります。

# 2. `qeyes` は何ができて、何をしないか

`qeyes` が提供するのは、次のようなシンプルな機能です。

- マウスポインター方向への視線追従
- 既定では常に最前面での表示
- 左ドラッグによる移動
- 右クリックによる外観設定
- 左ダブルクリックによる終了

一方で、次のような機能は意図的に持っていません。

- 複雑な設定画面
- ウィンドウサイズ変更 UI
- 位置やサイズの永続化
- 形状やアニメーションの詳細調整
- プラットフォームごとの大きな振る舞い差分

つまり、`qeyes` は **表示と最小限の見た目調整だけに役割を絞ったツール** です。

# 3. 基本方針

`qeyes` は、常駐しても扱いが重くならないように、次の方針で使うのが前提です。

- 必要な場所へドラッグして置く
- 気になるときだけ右クリックで色や最前面設定を調整する
- 使い終わったらダブルクリックで閉じる
- 細かな状態管理を期待しない

このため、使い方もできるだけ短い操作で完結します。

# 4. 起動

ビルド済みバイナリーを起動します。

```text
$ ./build/qeyes
```

ソースからビルドする場合の一例です。

```text
$ cmake -S . -B build
$ cmake --build build
$ ./build/qeyes
```

起動すると、透明背景のフレームレスウィンドウとして 2 つの目が表示されます。

# 5. まず把握すべき基本操作

`qeyes` の操作は少ないため、最初に次の 3 つを覚えておけば十分です。

```text
左ドラッグ: ウィンドウ移動
右クリック: 外観設定ダイアログを開く
左ダブルクリック: 終了
```

この 3 つだけで、日常的な操作はほぼ完結します。

# 6. ウィンドウを移動する

左ボタンでドラッグすると、ウィンドウ全体を移動できます。

`qeyes` はタイトルバーを持たないため、一般的なウィンドウのようにフレームをつかむのではなく、表示されている目の上をそのままドラッグして動かします。

```text
左ドラッグ: ウィンドウ移動
```

位置は保存されないため、次回起動時は前回終了時と同じ場所に戻るとは限りません。

# 7. 外観を変更する

右クリックすると外観設定ダイアログが開きます。

変更できる項目は次の通りです。

- Outline: 輪郭線
- Sclera: 白目
- Iris: 虹彩
- Pupil: 瞳孔

色プレビューをクリックすると色選択ダイアログが開きます。色コード表示には等幅フォントを使っているため、値を見比べやすくなっています。

このダイアログでは、常時最前面にするかどうかも切り替えられます。

```text
右クリック: 外観設定ダイアログを開く
プレビューをクリック: 色選択
[Always on top]: 最前面表示の ON/OFF
Reset: 対象項目を既定値へ戻す
OK: 変更を保存
Cancel: 変更を破棄
```

`qeyes` は多くの外観設定を持ちません。見た目を変えたい場合も、基本はこの 4 項目と最前面設定だけを調整する使い方になります。

# 8. 終了する

左ボタンでダブルクリックすると終了します。

```text
左ダブルクリック: 終了
```

常駐型の小さなツールとして、すぐ閉じられることを優先した操作です。

ウィンドウを閉じた場合も、アプリケーション全体が終了します。

# 9. 設定はどこまで保存されるか

保存されるのは色設定と最前面設定です。

選択した色と最前面設定は `QSettings` に保存され、次回起動時に復元されます。

保存しているキーは次の通りです。

- `colors/outline`
- `colors/sclera`
- `colors/iris`
- `colors/pupil`
- `window/alwaysOnTop`

macOS では通常、ユーザー設定領域に保存されます。

逆に、次のような状態は保存しません。

- ウィンドウ位置
- ウィンドウサイズ
- 形状の比率
- 追従速度

この割り切りにより、設定管理を増やさずに軽量さを保っています。

# 10. 表示の仕組み

`qeyes` の見た目は画像アセットではなく、コード内で動的に描画されています。

## 10.1 目の構成

左右の目はウィンドウサイズから計算され、各目は次の要素で構成されます。

- 輪郭
- 白目
- 虹彩
- 瞳孔

## 10.2 視線の追従

虹彩と瞳孔の中心位置は、各目の中心と現在のマウスポインター座標から求めます。

ただし、白目の内側に収まる範囲で移動量を制限しているため、追従中も目の外へはみ出しません。

## 10.3 再描画

約 16 ミリ秒ごとに再描画しているため、おおむね 60fps 相当で追従します。

このため、特別な操作をしなくても、ポインター移動に対して自然に視線が動いて見えます。

# 11. ウィンドウの性質

`qeyes` は、見た目よりも挙動に特徴があるウィンドウです。

- フレームレスウィンドウ
- ツールウィンドウ
- 既定では常に最前面
- 透過背景
- 起動時にアクティブ化しない設定

この組み合わせによって、通常のアプリケーションウィンドウというより、デスクトップ上に置く小さな補助表示として振る舞います。

必要なら、外観設定ダイアログから最前面表示を OFF に切り替えられます。

# 12. 制約と注意点

現状の実装では、次の点に注意が必要です。

- ウィンドウサイズの変更 UI はない
- 位置やサイズの永続化はしない
- 色以外の形状設定はない
- 複数モニター環境向けの細かな調整機能はない
- 終了操作はダブルクリック前提

`qeyes` は、この制約を残したままシンプルさを保つ方針です。多機能化よりも、小さな常駐ツールとして破綻しないことを優先しています。

# 14. まとめ

`qeyes` は、マウスポインターを追う目を常時表示するための小さな Qt アプリケーションです。

使い方は最小限で、移動、外観変更、終了だけに絞られています。見た目は動的描画で構成され、保存する設定も色と最前面設定に限定されています。

そのため、`qeyes` は多機能なデスクトップ玩具ではなく、**軽く起動して、すぐ置けて、すぐ閉じられる常駐ツール** として使うのが適しています。
