# 社内レビュー依頼文

AI を使ったアプリ作成ワークフローを試作しています。

任意形式の要求メモから、仕様化前ノート、三点セット、実装プロンプトを作成し、その後にアプリ実装へ進む流れです。
AI にいきなりコードを書かせるのではなく、途中に人がレビューしやすい中間文書を置くことで、意図違い、仕様漏れ、未決事項の放置を減らすことを狙っています。

現時点では、小規模なアプリでの実験が中心です。
大規模開発や業務上重要なシステムでの実績はまだありません。

そのため、完成した手法としてではなく、検証中のワークフローとして見ていただきたいです。
特に次の点について意見をいただけると助かります。

- 要求から仕様化前ノートを作る考え方は分かりやすいか
- 三点セットに分けることで、レビューしやすくなっているか
- AI 生成物をレビューする箇所は十分に明確か
- 実際の開発作業に使う場合、足りない手順や不安な点は何か
- 小規模アプリ以外に試すべき題材は何か
