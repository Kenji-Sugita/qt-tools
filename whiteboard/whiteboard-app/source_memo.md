# ホワイトボードアプリ 仕様化前ノート

このノートは、三点セットを作成する前の材料置き場である。
まだ UC仕様書、UI仕様書、ビジネスレイヤー仕様書に分けなくてよい。

## 目的

- オンラインセミナーで利用するホワイトボードアプリを作成する。
- セミナー中に講師または進行役が参加者へ説明するためのボードとして使う。
- シンプルですっきりした見栄えにし、キャンバスを主役にする。

## 利用者

- オンラインセミナーの講師または進行役。
- セミナー中にホワイトボードを見ながら説明を受ける参加者。

- [ ] 入力・計算・結果表示アプリ
- [ ] データ管理アプリ
- [ ] ビューアアプリ
- [x] エディタアプリ
- [ ] 変換ツール
- [ ] ゲーム / インタラクティブアプリ

補足:

- セミナー中にホワイトボード上へ描画、編集、確認を行う用途を主目的とする。

## やりたいこと

- セミナー中に使いやすい白いホワイトボード画面を表示する。
- 上部ツールバーから主要な編集操作へアクセスする。
- ホワイトボード上へ自由曲線、図形、折れ線、テキストを配置する。
- ホワイトボード上へベジェ曲線、円弧、円を配置する。
- PNG、JPEG、BMP、SVG の画像ファイルを取り込み、通常の描画要素として配置する。
- 直線、開いた折れ線、ベジェ曲線、円弧の端点に矢印を付ける。
- 直線の端点を矩形、角丸矩形、楕円、円、テキスト、画像へ接続し、接続先図形の移動、サイズ変更、回転、スケールに追従させる。
- 矢印形状は複数から選べるようにする。
- ペン、線、図形の線種を実線または点線から選べるようにする。
- 色、塗り潰し、線幅、線種、矢印、フォントを標準スタイルへ一括で戻せるようにする。
- 描画要素を消しゴムで削除する。
- 選択ツールで描画要素を選択し、移動、サイズ変更、回転を行う。
- 選択ツールで空白領域をドラッグしてラバーバンドを表示し、範囲内の複数オブジェクトを選択する。
- ラバーバンドで選択した複数オブジェクトをまとめて移動、削除する。
- 選択中オブジェクトをコピーし、ペーストする。複数選択時は複数オブジェクトをまとめてコピー、ペーストする。
- 矩形、楕円、円の辺を掴んで、その辺と直角方向のサイズを変更する。
- 円弧は長径と短径を常に同一にし、円弧の角を変更できるようにする。
- 円は長径と短径を常に同一にする。
- 選択済みのテキストオブジェクトの文字列を変更する。
- 選択済みのテキストオブジェクトの色とフォントを変更する。
- テキストオブジェクトへ複数行の文字列を入力する。
- テキストはダイアログではなく、キャンバス上の配置位置でその場編集する。
- 操作の取り消しとやり直しを行う。
- よく使う操作をショートカットキーで実行する。
- ヘルプメニューからショートカットキー一覧を確認する。
- 複数ページを扱い、ページ追加、ページ削除、前後ページ移動、ページ番号表示を行う。
- 終了時に設定情報、ページ、描画内容を保存し、起動時に読み込む。
- 現在表示しているページを、描画要素の範囲に切り抜いて PNG または SVG 画像として保存する。
- 画像保存の背景は透明を既定とし、キャンバス表示と同じ白も選べるようにする。
- 保存する設定情報は、ズーム倍率、選択中ツール、選択中の色、線幅、角丸矩形の丸み、線種、フォント設定、ウィンドウサイズとする。
- 初回起動時のデフォルトウィンドウ幅は、ツールバーのボタンと操作部品がすべて表示される幅にする。
- 採用デザイン `design/whiteboard-concept-1-minimal.svg` の方向性をアプリ画面へ反映する。
- 採用デザイン `design/whiteboard-concept-1-minimal.png` を元に、何かを描画中であることが分かるアプリケーションアイコンを表示する。

## 入力ルール

- ペンツールはドラッグ軌跡を自由曲線として描画する。
- 消しゴムツールはドラッグ位置に重なる描画要素を削除する。
- 選択ツールはクリック位置に重なる描画要素を選択する。
- 選択ツールでオブジェクトがない場所を左ボタンで押してドラッグした場合、ラバーバンドを表示する。
- ラバーバンド内に入ったオブジェクトは、ドラッグ中に選択状態表示にする。
- マウスボタンを離した時点で、ラバーバンド内に入ったオブジェクトを選択確定する。
- 選択ツールで Ctrl を押したまま描画要素をクリックした場合、その描画要素を既存の選択状態へ追加する。
- ラバーバンドで複数選択したオブジェクトは、まとめて移動できる。
- ラバーバンドで複数選択したオブジェクトは、Delete または Backspace でまとめて削除できる。
- 選択済み描画要素の内側をドラッグした場合、その描画要素を移動する。
- 選択済み描画要素の角ハンドルをドラッグした場合、その描画要素をサイズ変更する。
- 選択済み描画要素の回転ハンドルをドラッグした場合、単体は要素中心、複数選択またはグループは選択範囲中心を基準に回転する。Shift を押した場合は 15 度単位にスナップする。
- 回転した矩形系描画要素のリサイズハンドルは、描画要素自身の辺に沿ったローカル座標でサイズ変更する。
- 折れ線オブジェクト選択時は端点と屈曲点に頂点ハンドルを表示し、頂点ハンドルをドラッグすると該当頂点だけを移動して変形する。
- 選択済み描画要素がある状態で Delete または Backspace を押した場合、その描画要素を削除する。
- 選択済み描画要素がある状態で Copy を実行した場合、その描画要素をコピー対象にする。macOS では Command-C で実行する。
- コピー対象がある状態で Paste を実行した場合、コピー対象を現在ページへ複製して選択状態にする。macOS では Command-V で実行する。
- 選択ツールでテキストオブジェクトをダブルクリックした場合、既存テキストを初期値にしたその場編集欄を表示し、確定後にテキストを変更する。
- 描画、消しゴム、ページ移動、Undo/Redo を行った場合、選択状態は解除する。
- 選択状態は画面操作中だけの状態とし、保存対象には含めない。
- 図形ツールは直線、矩形、角丸矩形、円を扱う。
- 角丸矩形ツールはドラッグした矩形領域に、設定された丸みを持つ角丸矩形を作成する。
- 角丸矩形の丸みは 0 以上の値として調整でき、選択中の角丸矩形がある場合は選択済み角丸矩形へ反映し、選択中でない場合は以後作成する角丸矩形の既定丸みへ反映する。
- 円ツールと円弧ツールは、作成時とサイズ変更時に長径と短径を常に同一にする。
- 直線、開いた折れ線、ベジェ曲線、円弧は、開始端点と終了端点ごとに矢印形状を設定できる。
- 矢印形状は、なし、三角、開いた矢印、ひし形から選択できる。
- 直線の作成時、開始点または終了点が矩形、角丸矩形、楕円、円、テキスト、画像の上にある場合、その端点を対象描画要素の永続 ID へ接続する。接続した端点は対象描画要素の境界上に配置する。
- 接続済みの直線端点は、接続先描画要素の移動、サイズ変更、回転、スケール、テキストサイズ変更、角丸変更に追従する。
- 接続先描画要素を削除した場合、直線は残し、削除された接続先への接続だけを解除する。
- 接続済み直線の端点を手動で移動して図形外で離した場合、操作した端点の接続を解除する。図形上で離した場合は、その図形へ再接続する。
- 接続済み直線をリサイズした場合、操作した端点の接続を解除する。
- 接続済み直線と接続先図形をまとめてコピー、ペーストした場合、貼り付け後の直線は貼り付け後の図形へ接続する。接続先を含まずに直線だけ貼り付けた場合、接続は解除する。
- ペン、直線、折れ線、ベジェ曲線、円弧、矩形、角丸矩形、楕円、円は、線幅を 0 以上に設定できる。線幅 0 は輪郭線なしとして扱う。
- 選択済み描画要素がある状態で線幅を変更した場合、テキスト以外の選択済み描画要素へ反映する。
- ペン、直線、折れ線、ベジェ曲線、円弧、矩形、角丸矩形、楕円、円は、線種を実線または点線に設定できる。
- 選択済み描画要素がある状態で線種を変更した場合、テキスト以外の選択済み描画要素へ反映する。
- 選択済み描画要素がある状態で色を変更した場合、テキスト以外の選択済み描画要素の描画色または輪郭線色へ反映する。
- 矩形、角丸矩形、楕円、円、閉じた折れ線、閉じたベジェ曲線は内部を塗り潰せる。
- 塗り潰し色は透明を指定でき、透明の場合は内部を塗り潰さない。
- 選択済み描画要素がある状態で塗り潰し色を変更した場合、矩形、角丸矩形、楕円、円、閉じた折れ線、閉じたベジェ曲線へ反映する。
- スタイルリセットを実行した場合、選択済み描画要素があれば選択済み描画要素の色、塗り潰し、線幅、角丸矩形の丸み、線種、矢印を標準値へ戻し、テキスト要素はフォントも標準値へ戻す。選択済み描画要素がない場合は、以後作成する描画要素の既定スタイルと既定フォントを標準値へ戻す。標準値は、描画色 `#344054`、塗り潰し透明、線幅 `3`、角丸矩形の丸み `24`、線種 `solid`、開始端点矢印なし、終了端点矢印なし、フォント `Sans Serif 18pt` とする。
- 折れ線ツールはクリックごとに頂点を追加し、ダブルクリックまたは Enter で確定、Esc でキャンセルする。
- 既存の開いた折れ線の始点または終点を Ctrl+クリック（macOS は Control+クリック）した場合、その折れ線を選択して端点から頂点を追加し、折れ線を延長できる。
- 折れ線延長中に既存折れ線の反対側端点付近をクリックした場合、追加した線分を含めて閉じた折れ線として確定できる。反対側端点は重複頂点として追加せず、closed の閉じ線分として扱う。
- 折れ線ツールで3点以上入力済みの場合、始点付近をクリックまたは Ctrl+Enter で始点と終点を結んだ閉じた折れ線として確定できる。
- 選択済みの開いた折れ線は Ctrl+Shift+C で閉じられる。
- 選択済みの閉じた折れ線は Ctrl+Shift+O で開いた折れ線に戻せる。
- 閉じた折れ線の頂点を Ctrl+Shift+クリックした場合、その折れ線を選択し、クリックした頂点と直前の頂点の間を開いて開いた折れ線に戻せる。
- ベジェ曲線ツールで3点以上入力済みの場合、始点付近をクリックまたは Ctrl+Enter で滑らかな閉じたベジェ曲線として確定できる。
- 選択済みの開いたベジェ曲線は Ctrl+Shift+C で閉じられる。
- 選択済みの閉じたベジェ曲線は Ctrl+Shift+O で開いたベジェ曲線に戻せる。
- 閉じたベジェ曲線では端点矢印を表示せず、矢印形状変更の対象外とする。
- 直線オブジェクトと折れ線オブジェクトは、端点だけでなく線分の中間点付近でも選択できる。
- 直線オブジェクト選択時は実際の 2 端点にハンドルを表示し、端点ハンドルをドラッグした場合はドラッグした端点だけを移動する。矩形 bounds の正規化で端点の向きや対応を入れ替えない。
- ベジェ曲線オブジェクトと円弧オブジェクトも線上付近で選択できる。
- 矩形、楕円、円の辺ハンドルをドラッグした場合、その辺と直角方向のサイズだけを変更する。
- 円弧オブジェクトの角ハンドルをドラッグした場合、開始角または終了角を変更する。
- テキストツールはクリック位置にその場編集欄を出し、確定後に文字列を配置する。
- テキスト入力欄は複数行入力できる。
- テキスト入力欄はフォーカス移動、Ctrl+Enter、Ctrl+Return で確定する。
- 選択済みテキストオブジェクトがある状態で色またはフォントを変更した場合、以後の描画設定ではなく選択済みテキストオブジェクトへ反映する。
- メニューバーの「ファイル」から「画像を取り込み...」を実行すると、PNG、JPEG、BMP、SVG の画像ファイルを現在ページへ追加する。
- 取り込んだ SVG はベクター分解せず、読み込み時に PNG 画像へ変換して画像要素として扱う。
- 画像要素はページ中央に配置し、キャンバス内に収まる初期表示サイズへ縮小する。小さい画像は拡大しない。
- 画像要素は選択、移動、サイズ変更、回転、コピー、ペースト、グループ化、削除の対象にする。
- 画像要素は線幅、線種、塗り潰し、矢印、フォント、スタイルリセットの対象外にする。
- 画像要素のデータは PNG の Base64 として保存 JSON に埋め込み、他ホストへ保存ファイルを移しても画像が欠けないようにする。
- すべての描画要素は保存 JSON 上で永続 ID を持つ。既存保存ファイルに ID がない場合は読み込み時に一意な ID を補完し、図の見た目や座標は変更しない。
- コピー、ペースト、MCP の図反映で新しく作成される描画要素には、コピー元や入力元とは異なる新しい永続 ID を付ける。
- 色、線幅、フォント設定を実装する。
- 対応する入力デバイスは、マウス、タッチ、ペンタブレットなどの一般的な入力デバイスとする。
- ズーム倍率は最小 10%、最大 400%、初期値 100% とする。
- ズーム倍率の範囲外の入力を受けた場合は、最小値または最大値にクランプする。
- ズーム倍率入力欄で数値を変更しただけでは反映せず、Enter またはフォーカス移動で確定した時に反映する。
- ズーム変更時はキャンバス表示サイズをズーム倍率に合わせて更新する。
- キャンバスサイズは幅 1920px、高さ 1080px とする。
- 描画可能範囲はキャンバス全体とする。
- ページ数上限は最大 20 ページとする。
- 最大 20 ページに達している場合、ページ追加ボタンを無効化する。
- ページ数が 1 ページの場合、ページ削除ボタンを無効化する。
- Undo/Redo の履歴が空の場合は操作を無視する。
- 入力デバイスがない場合は描画入力を受け付けない。
- 描画入力が中断された場合は、現在の描画操作を終了する。
- ページ削除は削除前に確認する。
- 画像保存は現在表示しているページだけを対象とし、ズーム倍率とスクロール位置の影響を受けない。
- 選択中の描画要素がない場合は、現在ページ内の全描画要素を囲むバウンディングボックスを切り抜き範囲とする。
- 選択中の描画要素がある場合は、選択中の全描画要素を囲むバウンディングボックスを切り抜き範囲とする。
- 選択中の描画要素がある場合は、選択中の描画要素だけを画像へ描画する。
- 現在ページに描画要素がない場合は、画像保存操作を無効にする。
- 線幅、矢印、回転後形状などを含めて画像が欠けないように、描画範囲から必要な余白を計算して切り抜き範囲へ加える。
- PNG と SVG の切り抜き範囲は同一とする。
- PNG はキャンバス座標 1 単位を 1px として保存する。
- SVG は通常の描画要素をベクターとして保存し、取り込み画像だけを Base64 data URI の `<image>` として埋め込む。各描画要素には保存 JSON と共通の永続 ID を付ける。
- 画像保存時の背景は透明を既定とし、キャンバス表示と同じ白を選択可能にする。
- 選択枠、リサイズハンドル、回転ハンドル、ラバーバンドは画像に含めない。
- 編集中のテキストは確定してから画像へ保存する。
- 作成途中の図形プレビューは画像に含めず、作成を確定した描画要素だけを保存する。
- ページロック中でも画像を保存できる。
- 画像形式は保存ダイアログのフィルターまたはファイル名の拡張子で決定する。
- ファイル名に拡張子がない場合は、選択中の形式に応じて `.png` または `.svg` を自動付加する。
- 保存ダイアログのフィルターとファイル名の拡張子が異なる場合は、入力した拡張子を優先する。
- 既存ファイルの上書き確認は標準ファイルダイアログの挙動に従う。
- 画像保存に失敗した場合はエラーを表示し、同じ画像保存操作を再試行できるようにする。
- メニューバーの「ファイル」から「画像を保存...」を実行すると、画像保存設定ダイアログを表示する。
- 画像保存設定ダイアログでは、画像形式を PNG または SVG、背景を透明または白から選択する。背景の既定値は透明とする。
- 画像保存設定ダイアログの「保存...」を実行すると、選択した画像形式を初期フィルターにした標準ファイルダイアログを表示する。
- 画像保存設定ダイアログまたは標準ファイルダイアログをキャンセルした場合は、画像を保存しない。
- 画像保存に失敗した場合は画像保存設定を保持し、「再試行」または「キャンセル」を選択できるようにする。

## 操作

- ホワイトボード画面を開く。
- ツールバーから編集ツールを選ぶ。
- ペンツールでホワイトボード上へ自由曲線を描画する。
- 消しゴムツールで描画要素を削除する。
- 選択ツールで描画要素を選択する。
- 選択ツールで空白領域をドラッグし、ラバーバンドで複数オブジェクトを選択する。
- 選択済み描画要素をドラッグして移動する。
- 複数選択済み描画要素をドラッグしてまとめて移動する。
- 選択済み描画要素をコピー、ペーストする。
- 選択済み描画要素を前面方向または背面方向へ 1 段移動し、重なり順を変更する。
- 選択済み描画要素の角ハンドルをドラッグしてサイズ変更する。
- 図形ツールで直線、矩形、角丸矩形、円を配置する。
- 折れ線ツールで複数点の折れ線を配置する。
- ベジェ曲線ツールでクリックごとに通過点を追加し、ダブルクリックまたは Enter で確定、Esc でキャンセルする。
- 円弧ツールで円弧を配置し、角を変更する。
- 円ツールで円を配置する。
- 直線、開いた折れ線、ベジェ曲線、円弧の端点矢印形状を変更する。
- テキストツールで文字列を配置する。
- 色、線幅、角丸矩形の丸み、線種、フォント設定を変更する。
- テキスト以外の描画要素を選択中に色を変更し、選択済み描画要素の描画色または輪郭線色を変更する。
- 操作を取り消す。
- 取り消した操作をやり直す。
- 表示倍率を確認または変更する。
- 前ページ、次ページへ移動する。
- ページを追加する。
- 確認後にページを削除する。
- アプリ終了時に保存する。
- アプリ起動時に保存済み内容を読み込む。
- 現在表示しているページを PNG または SVG 画像として保存する。
- PNG、JPEG、BMP、SVG の画像ファイルを現在ページへ取り込む。
- 「ファイル」メニューの「画像を保存...」から画像保存設定ダイアログを開き、形式と背景を指定して保存する。
- ショートカットキーでツール選択、Undo/Redo、ズーム、ページ移動、ページ追加、ページ削除を実行する。
- ショートカットキーは、選択 `Ctrl+1`、ペン `Ctrl+2`、消しゴム `Ctrl+3`、直線 `Ctrl+4`、矩形 `Ctrl+5`、円 `Ctrl+6`、テキスト `Ctrl+7`、折れ線 `Ctrl+8`、ベジェ曲線 `Ctrl+9`、円弧 `Ctrl+0`、折れ線またはベジェ曲線延長開始 `Ctrl+端点クリック`（macOS は `Control+クリック`）、折れ線またはベジェ曲線を閉じる `Ctrl+Shift+C`、折れ線またはベジェ曲線を開く `Ctrl+Shift+O`、選択要素削除 `Delete` / `Backspace`、選択要素を背面へ 1 段移動 `Ctrl+[`、選択要素を前面へ 1 段移動 `Ctrl+]`、選択要素を最背面へ移動 `Ctrl+Shift+[`、選択要素を最前面へ移動 `Ctrl+Shift+]`、Undo/Redo は標準キー、ズームは標準 Zoom In/Out、ページ移動は `Alt+Left` / `Alt+Right`、ページ追加は `Ctrl+Shift+N`、ページ削除は `Ctrl+Shift+Backspace` とする。
- ツール選択、選択要素を背面または前面へ移動、ページ追加、ページ削除のショートカットは、macOS でも物理 Control キーで動作する。
- 操作選択ボタンの上にマウスカーソルが入った場合、2 秒後に 3 秒間ヘルプを表示する。
- ヘルプメニューに「ショートカットキー」を追加し、ショートカット一覧を表示する。

## 状態・処理の流れ

- 初期起動時は、採用デザインに沿った白いキャンバス、薄いトップバー、上部ツールバー、ボードタイトル、ページ番号を表示する。
- 保存済みの設定情報、ページ、描画内容がある場合は、起動時に読み込む。
- 保存済みのウィンドウサイズがある場合は、起動時に前回終了時のウィンドウサイズに復元する。
- 保存済みのウィンドウサイズがない場合は、ツールバーのボタンと操作部品がすべて表示される既定サイズで起動する。
- ツールを選択すると、現在の入力ツールが切り替わる。
- 描画操作を行うと、選択中のツールに応じて描画内容が更新される。
- 選択ツールで描画要素を選択すると、選択枠と角ハンドルを表示する。
- 選択済み描画要素を移動またはサイズ変更すると、描画内容が更新される。
- テキストオブジェクトのテキスト変更を確定すると、描画内容が更新される。
- 編集操作は Undo/Redo 履歴に反映される。
- フローティングアクションボタンから実行した操作も、同じ編集操作として扱い、履歴、選択状態、クリップボードに応じて有効・無効を切り替える。
- ページを追加すると、カレントページの次に新しい空のページが作成され、その新規ページへ移動する。最大 20 ページまで扱える。
- 最大 20 ページに達した場合、ページ追加ボタンを無効化し、それ以上ページを追加できないようにする。
- ページ削除を実行すると、削除前の確認後に対象ページを削除する。
- ページ数が 1 ページの場合、ページ削除ボタンを無効化し、最後の1ページは削除できないようにする。
- ズーム操作を行うと、10% から 400% の範囲にクランプして表示倍率を変更する。
- アプリ終了時に、設定情報、ページ、描画内容を保存する。

## インタラクション詳細確認

複雑な編集操作、図形・オブジェクト操作、ドラッグ操作、ショートカット、状態遷移があるため、ツールごとの操作と操作対象を整理する。

### 状態ごとの操作表

| 状態 | 操作 | 振る舞い | 優先順位・補足 |
| --- | --- | --- | --- |
| ペンツール選択中 | キャンバス上でドラッグ | ドラッグ軌跡を自由曲線として描画する | 描画後は選択状態を解除する |
| 消しゴムツール選択中 | 描画要素の上でドラッグ | ドラッグ位置に重なる描画要素を削除する | 削除後は選択状態を解除する |
| 選択ツール選択中 | 描画要素をクリック | クリック位置に重なる描画要素を選択する | 複数重なる場合は最前面の描画要素を選択する |
| 選択ツール選択中 | Ctrl を押したまま描画要素をクリック | クリック位置に重なる描画要素を既存の選択状態へ追加する | macOS は Control+クリックとする。折れ線またはベジェ曲線の端点延長操作を優先する |
| 選択ツール選択中 | 空白領域で左ボタンを押してドラッグ | ラバーバンドを表示し、範囲内のオブジェクトを選択状態表示にする | マウスボタンを離した時点で選択を確定する |
| 選択ツール選択中 | 選択済み描画要素の内側をドラッグ | 選択済み描画要素を移動する | 角ハンドル上のドラッグはサイズ変更を優先する |
| 選択ツール選択中 | 矢印キー | 選択済み描画要素を 1px 移動する | 描画要素選択中のみ有効 |
| 選択ツール選択中 | 選択済み描画要素の角ハンドルをドラッグ | 選択済み描画要素をサイズ変更する | 折れ線の頂点ハンドル上のドラッグは頂点変形を優先する |
| 選択ツール選択中 | 選択済み描画要素の回転ハンドルをドラッグ | 選択済み描画要素を回転する | Shift 押下中は 15 度単位。複数選択とグループはドラッグ開始時の選択範囲中心を固定して回転する |
| 選択ツール選択中 | 単一要素の回転ハンドルをダブルクリック | 回転角を 0 度へ戻す | 円は単体回転の対象外 |
| 折れ線オブジェクト選択中 | 端点または屈曲点の頂点ハンドルをドラッグ | 該当頂点だけを移動して折れ線を変形する | 頂点ハンドル操作は移動、サイズ変更より優先する |
| テキストオブジェクト選択中 | ダブルクリック | 既存テキストを初期値にしたその場編集欄を表示し、確定後にテキストを変更する | テキスト編集欄は複数行入力できる |
| テキスト編集中 | フォーカス移動、Ctrl+Enter、Ctrl+Return | 入力内容を確定する | 確定後にテキストオブジェクトへ反映する |
| 折れ線ツール選択中 | キャンバス上をクリック | 頂点を追加する | ダブルクリック、Enter、Esc、始点付近クリックの操作を優先して扱う |
| 折れ線作成中 | ダブルクリックまたは Enter | 入力済み頂点を折れ線として確定する | 3点以上入力済みで始点付近クリックまたは Ctrl+Enter の場合は閉じた折れ線として確定する |
| 折れ線作成中 | Esc | 作成中の折れ線をキャンセルする | 確定前の頂点は描画要素にしない |
| 開いた折れ線選択中 | 始点または終点を Ctrl+クリック | その折れ線を選択して端点から頂点を追加し、折れ線を延長する | macOS は Control+クリックとする。通常クリックは頂点移動や選択操作を優先する |
| 折れ線延長中 | 既存折れ線の反対側端点付近をクリック | 追加した線分を含めて閉じた折れ線として確定する | 反対側端点は重複頂点として追加せず、closed の閉じ線分として扱う |
| ベジェ曲線選択中 | 始点または終点を Ctrl+クリック | そのベジェ曲線を選択して端点から通過点を追加し、ベジェ曲線を延長する | macOS は Control+クリックとする。通常クリックは頂点移動や選択操作を優先する |
| ベジェ曲線延長中 | ダブルクリックまたは Enter | 追加した通過点を含むベジェ曲線として確定する | Esc で延長をキャンセルする |
| ベジェ曲線作成中 | 始点付近クリックまたは Ctrl+Enter | 入力済み通過点を滑らかな閉じたベジェ曲線として確定する | 3点以上入力済みの場合だけ有効 |
| 開いた折れ線選択中 | Ctrl+Shift+C | 始点と終点を結んだ閉じた折れ線にする |  |
| 閉じた折れ線選択中 | Ctrl+Shift+O | 閉じ線分を解除して開いた折れ線に戻す |  |
| 閉じた折れ線選択中 | 頂点を Ctrl+Shift+クリック | クリックした頂点と直前の頂点の間を開いて開いた折れ線に戻す |  |
| 開いたベジェ曲線選択中 | Ctrl+Shift+C | 滑らかな閉じたベジェ曲線にする | 端点矢印は解除する |
| 閉じたベジェ曲線選択中 | Ctrl+Shift+O | 開いたベジェ曲線に戻す |  |
| 描画要素選択中 | Delete または Backspace | 選択済み描画要素を削除する |  |
| 描画要素選択中 | Copy | 選択済み描画要素をコピー対象にする | macOS は Command-C |
| コピー対象あり | Paste | コピー対象を現在ページへ複製して選択状態にする | macOS は Command-V |
| ズーム倍率入力中 | Enter またはフォーカス移動 | 入力値を 10% から 400% にクランプして反映する | 値の変更中だけでは表示倍率へ反映しない |

### 操作対象の分類

| 対象 | 操作 | 振る舞い |
| --- | --- | --- |
| 描画要素の内部 | 選択ツールでドラッグ | 描画要素を移動する |
| 描画要素の角ハンドル | 選択ツールでドラッグ | 描画要素をサイズ変更する |
| 折れ線の端点 | 折れ線選択中にドラッグ | 対象頂点だけを移動する |
| 折れ線の屈曲点 | 折れ線選択中にドラッグ | 対象頂点だけを移動する |
| 開いた折れ線の始点または終点 | Ctrl+クリック | 端点から折れ線を延長する |
| ベジェ曲線の始点または終点 | Ctrl+クリック | 端点からベジェ曲線を延長する |
| 閉じた折れ線の頂点 | Ctrl+Shift+クリック | クリックした頂点と直前の頂点の間を開く |
| 直線または折れ線の線分中間点付近 | 選択ツールでクリック | 該当する直線または折れ線を選択する |
| テキストオブジェクト | 選択ツールでダブルクリック | その場編集欄を表示して文字列を変更する |
| 空白領域 | 選択ツールでクリック | 選択対象がない場合は未選択状態にする |
| 空白領域 | 選択ツールでドラッグ | ラバーバンド範囲に入ったオブジェクトを選択する |

### 往復操作・状態遷移

- 折れ線は、作成、延長、閉じる、開く、頂点変形、キャンセル、保存、読み込み後の描画と選択判定を扱う。
- 開いた折れ線は Ctrl+Shift+C または作成中の始点付近クリックで閉じた折れ線へ変更できる。
- 閉じた折れ線は Ctrl+Shift+O または頂点の Ctrl+Shift+クリックで開いた折れ線へ戻せる。
- ベジェ曲線は、作成、延長、閉じる、開く、通過点変形、キャンセル、保存、読み込み後の描画と選択判定を扱う。
- 開いたベジェ曲線は Ctrl+Shift+C または作成中の始点付近クリックで閉じたベジェ曲線へ変更できる。
- 閉じたベジェ曲線は Ctrl+Shift+O で開いたベジェ曲線へ戻せる。
- Undo/Redo、ページ移動、描画、消しゴム操作後は選択状態を解除する。
- 保存、読み込み後も closed の閉じ線分を描画、選択判定で扱う。
- 画像保存は文書、選択状態、Undo/Redo 履歴を変更しない。

### OS差分・入力デバイス差分

- Ctrl+クリックを使う折れ線延長操作は、macOS では Control+クリックとする。
- Ctrl+クリックを使うベジェ曲線延長操作は、macOS では Control+クリックとする。
- Delete または Backspace で選択済み描画要素を削除する。
- 対応する入力デバイスは、マウス、タッチ、ペンタブレットなどの一般的な入力デバイスとする。

## デザイン方針

- デザインは `design/whiteboard-concept-1-minimal.svg` を基準にする。
- 見た目はシンプル、すっきり、余白多めにする。
- キャンバスを主役にし、ツールバーや状態表示は控えめにする。
- 白いキャンバス、薄いトップバー、控えめなティールのアクセントを使う。
- ツールバー背景はチャコールグレー系の濃い色にし、下境界線と控えめな影でキャンバスから分離する。
- ツールバーのグループ区切りは細いセパレータで視覚的に分かるようにする。
- アイコンは `whiteboard-app/assets/icons/` 配下の 24x24 SVG を使う。
- アイコンは線色 `#344054` のシンプルな線画を基本とし、採用デザインに合わせる。
- 採用デザインにある「共有中」などの状態表示は表示しない。
- 採用デザインにある参加者カーソル風の表示は表示しない。
- エラーや確認表示は、作業を妨げすぎない控えめな表示にする。
- ページロック中はコピー用テンプレートとして扱い、選択、コピー、ページ移動、ズーム、スクロールだけを許可する。

## AI からの図作成

- 通常起動時は `127.0.0.1:8765/mcp` で Streamable HTTP MCP Server として動作する。
- MCP クライアントは起動済みアプリへ URL で接続し、アプリを自動起動しない。
- `--mcp` 付きで起動した場合は、互換用の標準入出力 MCP Server として動作する。
- HTTP 接続は loopback と localhost 系 Origin に限定し、セッション ID と protocol version を検証する。
- AI は現在状態とページ別要素の取得、図の一括反映、永続 ID による現在ページ要素の一括更新・
  削除、現在ページの PNG 取得、直前変更の Undo を行える。
- 図の一括反映は、新規ページ、現在ページへの追加、現在ページの置換から選ぶ。
- 一括反映は全要素を検証してから実行し、1 回の呼び出しを 1 回の Undo として扱う。
- ID 指定の一括更新・削除も全要求を検証してから実行し、1 回の呼び出しを 1 回の Undo として扱う。
- 要素一覧で文書 `revision` を取得し、更新・削除・統合変更では同じ値を `expectedRevision` に指定する。
  読み取り後に文書が変更されていれば、古い状態に基づく要求を拒否する。
- `whiteboard/elements/apply` は追加・更新・削除を一括処理し、追加用 `clientId` と永続 ID の対応を返す。
- 現在ページへの追加と置換はページロック中に拒否する。新規ページは最大 20 ページの範囲で現在ページの直後へ追加する。
- 図の反映と Undo は実行前にユーザーへ確認し、拒否された場合は状態を変更しない。
- 成功した変更は通常操作と同じ保存先へ自動保存する。保存 JSON の形式は変更しない。
- MCP では既存アプリの図形、画像要素、直線の追従コネクターを扱い、UML 専用要素は追加しない。

## 描画データの受け渡し

- File の描画データインポート／エキスポートから、編集可能な全ページまたは現在ページを
  `.whiteboard` ファイルで受け渡す。内容は形式識別子と形式バージョン付き JSON とする。
- 全要素、画像埋め込み、グループ、コネクター接続、重なり順、ページロック、ページ別表示位置を保持する。
- インポートは現在ページの直後へページ単位で追加し、既存ページ、表示中ページ、操作設定を維持する。
  新しい永続 ID と接続先への張り替えを一括実行し、1 回の Undo/Redo とする。
- 上限 20 ページ超過、不正な形式・要素・画像・接続は全体を拒否し、部分反映しない。
  旧自動保存 JSON は検証後に受け入れ、ID 欠落要素は取り込み時に採番する。
- ロック中のページからのインポートは無効。書き出しはロック中・空ページでも有効。
- ウィンドウサイズ、選択ツールなどの操作設定と Undo/Redo 履歴は交換ファイルに含めない。
  全文書置換、選択要素だけの書き出し、MCP tool 追加は初期範囲に含めない。

## 対象外

- 複数人同時編集。
- クラウド同期。
- アカウント管理。
- セミナー配信機能。
- チャット。
- 録画。
- 参加者管理。
- テンプレート管理。ただし、コピー専用ページを保護するページロックは対象内とする。
- アプリ内の AI 推論、チャット、プロンプト入力 UI。AI 連携は外部 MCP クライアントから行う。
- 実共有状態の実装。
- 参加者カーソル機能。
