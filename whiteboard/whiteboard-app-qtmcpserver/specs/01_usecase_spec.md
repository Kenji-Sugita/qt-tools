# ホワイトボードアプリ UC仕様書

## 1. 概要

本書は、オンラインセミナー向けホワイトボードアプリの UC(UseCase) を定義する。

## 2. アプリ種別

- 種別: エディタアプリ
- 補足: セミナー中にホワイトボード上へ描画、編集、確認を行う用途を主目的とする。

## 3. スコープ

対象:

- ホワイトボード画面の表示。
- 自由曲線、図形、折れ線、テキストの配置。
- ベジェ曲線、円弧、円の配置。
- 直線、開いた折れ線、ベジェ曲線、円弧の端点矢印設定。
- 描画要素の削除。
- 描画要素の選択、移動、サイズ変更、回転。
- ラバーバンドによる複数描画要素の選択。
- 複数選択された描画要素のまとめ移動、まとめ削除。
- 選択中描画要素のコピー、ペースト。
- 選択中描画要素の重なり順変更。
- 矩形、楕円、円の辺ハンドルによる直角方向サイズ変更。
- 円弧の角度変更。
- テキストオブジェクトのテキスト変更。
- テキストオブジェクトの色、フォント変更。
- 色、塗り潰し、線幅、線種、矢印、フォントの標準スタイルへのリセット。
- 複数行テキスト入力。
- Undo/Redo。
- ズーム。
- ショートカットキー。
- ヘルプメニューでのショートカットキー一覧表示。
- 複数ページの追加、削除、前後移動、ページ番号表示。
- 設定情報、ページ、描画内容の保存と読み込み。
- 現在ページの描画要素を PNG または SVG 画像として保存。
- 作成済み SVG アイコンを使ったツールバー表示。
- 外部 MCP クライアントからの状態取得、図の一括反映、PNG 確認、Undo。

対象外:

- 複数人同時編集。
- クラウド同期。
- アカウント管理。
- セミナー配信機能。
- チャット。
- 録画。
- 参加者管理。
- テンプレート管理。
- アプリ内の AI 推論、チャット、プロンプト入力 UI。
- 実共有状態の実装。
- 参加者カーソル機能。

前提:

- キャンバスサイズは幅 1920px、高さ 1080px とする。
- ページ数上限は最大 20 ページとする。
- ページ数下限は 1 ページとし、最後の1ページは削除できない。
- ズーム倍率は最小 10%、最大 400%、初期値 100% とする。
- 保存する設定情報は、ズーム倍率、選択中ツール、選択中の色、線幅、線種、フォント設定、ウィンドウサイズとする。

## 6. UC-001 ホワイトボードを編集する

### 6.1 アクター

| アクター | 説明 |
| --- | --- |
| 講師・進行役 | ホワイトボード上で編集操作を行う |

### 6.2 目的

セミナー中に説明内容を視覚化するため、キャンバス上へ自由曲線、図形、折れ線、ベジェ曲線、円弧、円、テキストを配置し、不要な描画要素を削除し、配置済みの描画要素を移動、サイズ変更、回転、円弧角変更、矢印変更、またはテキスト変更する。

### 6.3 前提条件

- ホワイトボード画面が表示されている。
- 入力デバイスが利用できる。
- UI 表示言語はシステムロケールに従い、日本語環境では日本語、それ以外では英語で表示されている。

### 6.4 開始条件

講師・進行役がツールバーから編集ツールを選ぶ。

### 6.5 基本フロー

1. 講師・進行役が選択、ペン、消しゴム、図形、テキストのいずれかを選ぶ。
2. アプリは選択中ツールを更新する。
3. 講師・進行役がキャンバス上で入力操作を行う。
4. アプリは選択中ツールに応じて描画内容を更新する。
5. アプリは編集操作を Undo/Redo 履歴へ反映する。

### 6.6 代替フロー

| ID | 条件 | 振る舞い |
| --- | --- | --- |
| AF-001 | ペンツールが選択されている | ドラッグ軌跡を自由曲線として描画する |
| AF-002 | 消しゴムツールが選択されている | ドラッグ位置に重なる描画要素を削除する |
| AF-003 | 図形ツールが選択されている | 直線、矩形、円のいずれかをキャンバス上に配置する |
| AF-004 | テキストツールが選択されている | クリック位置にその場編集用の複数行入力欄を出し、確定後に文字列を配置する |
| AF-005 | 選択ツールが選択されている | クリック位置に重なる描画要素を選択し、選択済み描画要素をドラッグで移動またはサイズ変更する |
| AF-005a | 選択済み描画要素の回転ハンドルをドラッグした | 単体は要素中心、複数選択またはグループはドラッグ開始時の選択範囲中心を基準に回転する。Shift 押下中は 15 度単位にする |
| AF-006 | 選択ツールでテキストオブジェクトをダブルクリックした | 既存テキストを初期値にしたその場編集用の複数行入力欄を表示し、確定後に文字列を更新する |
| AF-007 | テキストオブジェクトが選択されている状態で色またはフォントを変更した | 選択済みテキストオブジェクトの色またはフォントを更新する |
| AF-008 | 描画要素が選択されている状態で Delete または Backspace が押された | 選択済み描画要素を削除する |
| AF-009 | 折れ線ツールが選択されている | クリックごとに頂点を追加し、ダブルクリックまたは Enter で折れ線を配置する |
| AF-010 | 折れ線オブジェクト選択中に端点または屈曲点のハンドルをドラッグした | 対象頂点だけを移動して折れ線を変形する |
| AF-011 | 折れ線作成中に始点付近をクリック、または選択中折れ線で Ctrl+Shift+C を押した | 始点と終点を結んだ閉じた折れ線にする |
| AF-012 | 開いた折れ線の始点または終点を Ctrl+クリック（macOS は Control+クリック）した | クリックした折れ線を選択し、その端点側から頂点を追加して既存折れ線を延長する |
| AF-012a | 折れ線延長中に既存折れ線の反対側端点付近をクリックした | 追加した線分を含めて閉じた折れ線として確定する。反対側端点は重複頂点として追加しない |
| AF-013 | 閉じた折れ線を選択して Ctrl+Shift+O を押した、または閉じた折れ線の頂点を Ctrl+Shift+クリックした | 閉じ線分を解除して開いた折れ線にする。頂点クリック時はクリックした頂点と直前の頂点の間を開く |
| AF-014 | ベジェ曲線ツールが選択されている | クリックごとに通過点を追加し、ダブルクリックまたは Enter で2点以上の滑らかなベジェ曲線を配置する |
| AF-014a | ベジェ曲線の始点または終点を Ctrl+クリック（macOS は Control+クリック）した | クリックしたベジェ曲線を選択し、その端点側から通過点を追加して既存ベジェ曲線を延長する |
| AF-015 | 円弧ツールが選択されている | 長径と短径が同一の円弧を配置する |
| AF-016 | 円ツールが選択されている | 長径と短径が同一の円を配置する |
| AF-017 | 直線、開いた折れ線、ベジェ曲線、円弧の矢印形状を変更した | 開始端点と終了端点の矢印形状を更新する |
| AF-018 | 矩形、楕円、円の辺ハンドルをドラッグした | 掴んだ辺と直角方向のサイズを変更する |
| AF-019 | 円弧の角ハンドルをドラッグした | 円弧の開始角または終了角を変更する |
| AF-020 | 選択ツールで空白領域をドラッグした | ラバーバンドを表示し、範囲内の描画要素を複数選択する |
| AF-021 | 複数選択された描画要素をドラッグした | 選択済み描画要素をまとめて移動する |
| AF-022 | 複数選択状態で Delete または Backspace が押された | 選択済み描画要素をまとめて削除する |
| AF-022a | 選択ツールで Ctrl を押したまま描画要素をクリックした | クリックした描画要素を既存の選択状態へ追加する。macOS は Control+クリックで実行する |
| AF-023 | 選択済み描画要素に対して Copy が実行された | 選択済み描画要素をコピー対象にする。macOS では Command-C で実行する |
| AF-024 | コピー対象がある状態で Paste が実行された | コピー対象を現在ページへ複製し、複製した描画要素を選択状態にする。macOS では Command-V で実行する |
| AF-024a | 選択済み描画要素に対して前面または背面操作が実行された | 選択済み描画要素を前面方向または背面方向へ 1 段移動する |
| AF-025 | スタイルリセットが実行された | 選択済み描画要素がある場合は選択済み描画要素を標準スタイルへ戻し、テキスト要素はフォントも標準値へ戻す。未選択の場合は以後作成する描画要素の既定スタイルと既定フォントを標準値へ戻す |
| AF-026 | 操作選択ボタンにマウスカーソルが入った | 2 秒後に 3 秒間、対象操作のヘルプを表示する |

### 6.7 例外フロー

| ID | 条件 | 振る舞い |
| --- | --- | --- |
| EF-001 | 入力デバイスがない | 描画入力を受け付けない |
| EF-002 | 描画入力が中断された | 現在の描画操作を終了する |

### 6.8 事後条件

成功時:

- 描画内容が更新される。
- 編集操作が Undo/Redo 履歴へ反映される。

失敗時:

- 入力を受け付けない、または中断時点で描画操作を終了する。

### 6.9 確認観点

- ペン描画が自由曲線になること。
- 消しゴムが重なる描画要素を削除すること。
- 選択ツールで描画要素を選択、移動、サイズ変更、回転できること。
- 回転した矩形系描画要素を自身の辺に沿ってサイズ変更できること。
- 複数選択またはグループを、固定した選択範囲中心の周りに回転できること。
- 選択済み描画要素を矢印キーで 1px ずつ移動できること。
- 選択済み描画要素を Delete または Backspace で削除できること。
- ラバーバンドで複数描画要素を選択できること。
- 複数選択された描画要素をまとめて移動、削除できること。
- 選択済み描画要素をコピー、ペーストできること。
- 選択済み描画要素の重なり順を変更できること。
- テキストオブジェクトの文字列を変更できること。
- テキストオブジェクトの色とフォントを変更できること。
- テキストを複数行で入力できること。
- 図形ツールで直線、矩形、円を配置できること。
- 折れ線ツールで複数点の折れ線を配置できること。
- 折れ線を閉じられること。
- 既存の開いた折れ線を端点から延長できること。
- 直線オブジェクトを中間点付近でも選択できること。
- 折れ線の端点と屈曲点をドラッグして変形できること。
- ベジェ曲線、円弧、円を配置できること。
- 直線、開いた折れ線、ベジェ曲線、円弧に複数形状の端点矢印を設定できること。
- 矩形、楕円、円を辺ハンドルでサイズ変更できること。
- 円弧の角を変更できること。
- テキスト確定後に文字列が配置されること。

## 7. UC-002 編集操作を取り消し・やり直す

### 7.1 アクター

| アクター | 説明 |
| --- | --- |
| 講師・進行役 | 編集履歴を操作する |

### 7.2 目的

直前の編集操作を取り消し、必要に応じてやり直す。

### 7.3 前提条件

- ホワイトボード画面が表示されている。

### 7.4 開始条件

講師・進行役が Undo または Redo を実行する。

### 7.5 基本フロー

1. 講師・進行役が Undo または Redo を実行する。
2. アプリは対象履歴があるか確認する。
3. 対象履歴がある場合、描画内容を更新する。

### 7.6 代替フロー

| ID | 条件 | 振る舞い |
| --- | --- | --- |
| AF-001 | Undo/Redo の履歴が空 | 操作を無視し、描画内容を変更しない |

### 7.7 例外フロー

| ID | 条件 | 振る舞い |
| --- | --- | --- |
| EF-001 | なし | なし |

### 7.8 事後条件

成功時:

- 対象の編集操作が取り消される、または復元される。

失敗時:

- 履歴が空の場合は何も変更されない。

### 7.9 確認観点

- Undo で直前の編集操作が取り消されること。
- Redo で取り消した編集操作が復元されること。
- 空履歴では操作が無視されること。

## 8. UC-003 ページを管理する

### 8.1 アクター

| アクター | 説明 |
| --- | --- |
| 講師・進行役 | ページを管理する |

### 8.2 目的

セミナー内容を複数ページに分けて扱う。

### 8.3 前提条件

- ホワイトボード画面が表示されている。

### 8.4 開始条件

講師・進行役がページ操作を実行する。

### 8.5 基本フロー

1. 講師・進行役が前ページ、次ページ、ページ追加、ページ削除のいずれかを実行する。
2. アプリはページ状態を確認する。
3. アプリは操作に応じて現在ページを変更、ページを追加、またはページを削除する。
4. アプリはページ番号を更新する。

### 8.6 代替フロー

| ID | 条件 | 振る舞い |
| --- | --- | --- |
| AF-001 | ページ数が 20 ページに達している | ページ追加ボタンを無効化し、ページを追加しない |
| AF-002 | 2ページ以上でページ削除が実行された | 削除前に確認し、確認後に対象ページを削除する |
| AF-003 | ページ数が 1 ページである | ページ削除ボタンを無効化し、最後の1ページは削除しない |

### 8.7 例外フロー

| ID | 条件 | 振る舞い |
| --- | --- | --- |
| EF-001 | なし | なし |

### 8.8 事後条件

成功時:

- ページ状態とページ番号が更新される。

失敗時:

- ページ上限時はページ追加されない。

### 8.9 確認観点

- 最大 20 ページまで追加できること。
- 20 ページ到達時にページ追加ボタンが無効化されること。
- ページ削除前に確認されること。
- 1 ページだけの状態ではページ削除ボタンが無効化されること。

## 10. UC-005 保存済み内容を復元する

### 10.1 アクター

| アクター | 説明 |
| --- | --- |
| 講師・進行役 | 保存済み内容を利用する |

### 10.2 目的

前回終了時の設定情報、ページ、描画内容を次回起動時に復元する。

### 10.3 前提条件

- アプリを起動または終了する。

### 10.4 開始条件

起動時または終了時。

### 10.5 基本フロー

1. 起動時、アプリは保存済みの設定情報、ページ、描画内容を読み込む。
2. 保存済み内容がある場合、アプリはそれを画面へ反映する。
3. 保存済みウィンドウサイズがある場合、前回終了時のウィンドウサイズに復元する。
4. 終了時、アプリは設定情報、ウィンドウサイズ、ページ、描画内容を保存する。

### 10.6 代替フロー

| ID | 条件 | 振る舞い |
| --- | --- | --- |
| AF-001 | 保存済み内容がない | 初期状態で起動する |

### 10.7 例外フロー

| ID | 条件 | 振る舞い |
| --- | --- | --- |
| EF-001 | 保存失敗 | 扱わない |
| EF-002 | 読み込み失敗 | 扱わない |

### 10.8 事後条件

成功時:

- 起動時に保存済み内容が復元される。
- 終了時に設定情報、ページ、描画内容が保存される。

失敗時:

- 保存失敗、読み込み失敗は扱わない。

### 10.9 確認観点

- 保存する設定情報が、ズーム倍率、選択中ツール、選択中の色、線幅、線種、フォント設定、ウィンドウサイズであること。
- ページと描画内容が保存、読み込みされること。
- 初回起動時にツールバーのボタンと操作部品がすべて表示される幅で起動すること。
- 再起動時に前回終了時のウィンドウサイズが復元されること。
- システムロケールが日本語の場合は UI テキストが日本語で表示され、日本語以外の場合は英語で表示されること。
- フローティングアクションの子ボタンにホバーすると、子ボタン左横に操作名の吹き出しラベルが表示され、キャンバス右側のオブジェクト選択を妨げないこと。

## 13. 業務ルール

- キャンバスサイズは幅 1920px、高さ 1080px とする。
- ページ数上限は最大 20 ページとする。
- 20 ページに達した場合、ページ追加ボタンを無効化する。
- 1 ページだけの場合、ページ削除ボタンを無効化する。
- ズーム倍率は 10% から 400% にクランプする。
- ズーム倍率入力欄は、入力値の変更中ではなく確定時に表示倍率へ反映する。
- ショートカットキーは、選択 `Ctrl+1`、ペン `Ctrl+2`、消しゴム `Ctrl+3`、直線 `Ctrl+4`、矩形 `Ctrl+5`、円 `Ctrl+6`、テキスト `Ctrl+7`、折れ線 `Ctrl+8`、ベジェ曲線 `Ctrl+9`、円弧 `Ctrl+0`、選択要素削除 `Delete` / `Backspace`、Undo/Redo は標準キー、ズームは標準 Zoom In/Out、ページ移動は `Alt+Left` / `Alt+Right`、ページ追加は `Ctrl+Shift+N`、ページ削除は `Ctrl+Shift+Backspace` とする。
- Undo/Redo の履歴が空の場合は操作を無視する。
- 選択状態は保存対象に含めない。
- ズーム変更時はキャンバス表示サイズをズーム倍率に合わせて更新する。
- ページ削除は削除前に確認する。
- 保存失敗、読み込み失敗、エクスポート失敗は扱わない。

## 16. UC-007 現在ページを画像として保存する

### 16.1 アクター

| アクター | 説明 |
| --- | --- |
| 講師・進行役 | 現在ページの描画内容を画像ファイルとして保存する |

### 16.2 前提条件

- ホワイトボード画面が表示されている。
- 保存対象は現在表示しているページである。
- ページロック中でも実行できる。

### 16.3 基本フロー

1. 講師・進行役が「ファイル」メニューの「画像を保存...」を実行する。
2. アプリは編集途中のテキストがあれば確定する。
3. アプリは、描画要素が選択されていなければ現在ページ内の全描画要素、選択されていれば選択中の全描画要素を囲むバウンディングボックスを切り抜き範囲にする。
4. アプリは画像保存設定ダイアログを表示する。
5. 講師・進行役が PNG または SVG と、透明または白の背景を指定する。背景の既定値は透明とする。
6. 講師・進行役が「保存...」を実行する。
7. アプリは選択した画像形式を初期フィルターにした標準ファイルダイアログを表示する。
8. 講師・進行役が保存先とファイル名を指定する。
9. アプリはズーム倍率とスクロール位置に関係なく、指定した形式で画像を保存する。

### 16.4 出力ルール

- PNG と SVG は同じ切り抜き範囲を使う。
- 描画要素が選択されている場合は、選択中の描画要素だけを出力する。
- 線幅、矢印、回転後形状などを含めて画像が欠けないように、描画範囲から必要な余白を計算して切り抜き範囲へ加える。
- PNG はキャンバス座標 1 単位を 1px として出力する。
- SVG はラスター画像を埋め込まず、描画要素をベクターとして出力する。
- SVG 内の各描画要素には、分かりやすい一意な ID を付ける。
- 背景は透明を既定とし、キャンバス表示と同じ白を選択可能にする。
- 選択枠、リサイズハンドル、回転ハンドル、ラバーバンドは出力しない。
- 作成途中の図形プレビューは出力せず、作成を確定した描画要素だけを出力する。
- ファイル形式は保存ダイアログのフィルターまたはファイル名の拡張子で決定する。
- ファイル名に拡張子がない場合は、選択中の形式に応じて `.png` または `.svg` を自動付加する。
- 保存ダイアログのフィルターとファイル名の拡張子が異なる場合は、入力した拡張子を優先する。
- 既存ファイルの上書き確認は標準ファイルダイアログに従う。
- 画像保存によって文書、選択状態、Undo/Redo 履歴は変化しない。

### 16.5 代替フロー

- 現在ページに描画要素がない場合は画像保存を開始できない。
- 画像保存設定ダイアログまたは標準ファイルダイアログをキャンセルした場合は、画像を保存しない。
- 画像保存に失敗した場合は設定を保持してエラーを表示し、「再試行」または「キャンセル」を選択できるようにする。
