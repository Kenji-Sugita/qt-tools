# ホワイトボードアプリ UI仕様書

## 1. 概要

本書は、オンラインセミナー向けホワイトボードアプリの UI 仕様を定義する。

## 2. アプリ種別

- 種別: エディタアプリ
- 補足: セミナー中にホワイトボード上へ描画、編集、確認を行う用途を主目的とする。

## 3. 共通UI

- 単一画面構成とする。
- 大きな白いホワイトボードキャンバスを主表示領域にする。
- 上部に薄いトップバーとツールバーを配置する。
- メニューバーにヘルプメニューを配置し、ショートカットキー一覧を表示できるようにする。
- メニューバーに「ファイル」メニューを配置し、「画像を保存...」を表示する。
- ツールバーと操作部品には `whiteboard-app/assets/icons/` 配下の 24x24 SVG アイコンを使う。
- ツールバーは、基本ツール、図形ツール、テキスト関連、編集操作、スタイル設定、表示操作、ページ操作の順にグルーピングする。
- ページ操作グループは、ページ番号、前ページ、次ページ、ページ追加、ページ削除、ページロックの順に
  配置し、ページロックボタンをツールバーの末尾項目にする。
- ウィンドウ幅に収まらない項目がある場合はツールバー右端に拡張ボタンを表示する。拡張ボタンを
  クリックするたびに拡張パネルを開閉し、マウスカーソルが外へ移動しても自動では閉じない。
- 拡張パネル上でツールや設定を操作しても開いた状態を維持する。拡張パネルの表示領域以外は
  キャンバスのクリック、選択、ドラッグを妨げない。拡張行の最初の操作部品は通常行の左端に揃え、
  拡張パネルの背景は外側ツールバーの左端まで表示する。Qt が配置した後の先頭操作部品の左端と
  末尾操作部品の右端を基準に、パネル端までの背景の左右余白を同じ幅にする。
- ツールバーにはベジェ曲線、円弧、円の追加ツールを配置する。
- フォント設定ボタンは、テキストツールボタンの右横に配置する。
- コピー/ペーストボタンは、Undo/Redo と同じ編集操作グループに配置する。
- 直線、開いた折れ線、ベジェ曲線、円弧の開始端点と終了端点に付ける矢印形状を選択する操作部品を配置する。
- アプリケーションアイコンには `whiteboard-app/assets/appicon/` 配下の PNG と macOS 用 icns を使う。
- アプリケーションアイコンは、`design/whiteboard-concept-1-minimal.png` の白いボード画面を元にし、描画中の線とペンを重ねた見た目にする。
- アイコンは線色 `#344054` のシンプルな線画を基本とする。
- 控えめなティールのアクセントを使う。
- 「共有中」などの状態表示は表示しない。
- 参加者カーソル風の表示は表示しない。
- エラーや確認表示は、作業を妨げすぎない控えめな表示にする。

## 5. UI-001 ホワイトボード画面

### 5.1 画面の目的

オンラインセミナー中に、講師・進行役が説明内容をホワイトボード上で視覚化する。

### 5.2 初期表示

- 採用デザイン `design/whiteboard-concept-1-minimal.svg` を基準にした画面を表示する。
- 白いキャンバスを表示する。
- 薄いトップバーを表示する。
- ボードタイトルを表示する。
- 上部ツールバーを表示する。
- ページ番号を表示する。
- ズーム倍率は初期値 100% とする。
- 保存済みの設定情報、ページ、描画内容がある場合は読み込んで表示する。
- 保存済みのウィンドウサイズがある場合は、前回終了時のサイズで表示する。
- 保存済み内容がない場合は、初期状態の空ページを表示する。
- 保存済みのウィンドウサイズがない場合は、ツールバーのボタンと操作部品がすべて表示される既定幅で表示する。

| ウィンドウサイズ | 任意 | 幅、高さ | 終了時に現在のウィンドウサイズを保存し、次回起動時に復元する |
| 表示言語 | 任意 | 文字列 | システムロケールが日本語の場合は日本語で表示し、それ以外の場合は英語で表示する |

### 5.5 操作

| 操作 | 振る舞い |
| --- | --- |
| ツール選択 | 現在の入力ツールを切り替える |
| ペン描画 | ドラッグ軌跡を自由曲線として描画する |
| 消しゴム | ドラッグ位置に重なる描画要素を削除する |
| 選択 | クリック位置に重なる描画要素を選択し、選択枠と角ハンドルを表示する |
| ラバーバンド選択 | 選択ツールで空白領域を左ボタンドラッグし、範囲内の描画要素を選択状態表示にする。マウスボタンを離した時点で選択を確定する |
| 追加選択 | 選択ツールで Ctrl を押したまま描画要素をクリックし、クリックした描画要素を既存の選択状態へ追加する。macOS は Control+クリックとする |
| 移動 | 選択済み描画要素の内側をドラッグして移動する |
| キーボード移動 | 選択済み描画要素を矢印キーで 1px ずつ移動する |
| 複数移動 | 複数選択済み描画要素の内側をドラッグしてまとめて移動する |
| サイズ変更 | 選択済み描画要素の角ハンドルをドラッグしてサイズ変更する |
| 回転 | 回転ハンドルをドラッグして描画要素を回転する。単体は要素中心、複数選択またはグループはドラッグ開始時の選択範囲中心を基準にする |
| 折れ線頂点変形 | 選択済み折れ線の端点または屈曲点ハンドルをドラッグして該当頂点を移動する |
| 選択要素削除 | 描画要素選択中に Delete または Backspace を押して削除する |
| 複数選択要素削除 | 複数選択中に Delete または Backspace を押して選択済み描画要素をまとめて削除する |
| コピー | 選択済み描画要素をコピー対象にする。macOS は Command-C を使う |
| ペースト | コピー対象を現在ページへ複製して選択状態にする。macOS は Command-V を使う |
| テキスト変更 | 選択ツールでテキストオブジェクトをダブルクリックし、その場編集欄で複数行文字列を変更する |
| 選択テキストの色変更 | テキストオブジェクト選択中に色変更した場合、選択済みテキストオブジェクトの色を変更する |
| 選択テキストのフォント変更 | テキストオブジェクト選択中にフォント変更した場合、選択済みテキストオブジェクトのフォントを変更する |
| 図形配置 | 直線、矩形、円をキャンバス上に配置する |
| 折れ線配置 | 複数点の折れ線をキャンバス上に配置する |
| ベジェ曲線配置 | 2点以上の通過点を持つ滑らかなベジェ曲線をキャンバス上に配置する |
| 円弧配置 | 長径と短径が同一の円弧をキャンバス上に配置する |
| 円配置 | 長径と短径が同一の円をキャンバス上に配置する |
| 矢印形状変更 | 選択中設定に従い、直線、開いた折れ線、ベジェ曲線、円弧の開始端点または終了端点に矢印を表示する |
| 辺ハンドルサイズ変更 | 矩形、楕円、円の辺をドラッグし、その辺と直角方向のサイズを変更する |
| 円弧角変更 | 円弧の角ハンドルをドラッグし、開始角または終了角を変更する |
| 折れ線延長 | 開いた折れ線の始点または終点を Ctrl+クリック（macOS は Control+クリック）し、その折れ線を選択して端点側へ頂点を追加する。延長中に反対側端点付近をクリックすると閉じた折れ線として確定する |
| ベジェ曲線延長 | ベジェ曲線の始点または終点を Ctrl+クリック（macOS は Control+クリック）し、そのベジェ曲線を選択して端点側へ通過点を追加する。ダブルクリックまたは Enter で確定し、Esc でキャンセルする |
| 折れ線を閉じる | 折れ線作成中に始点付近をクリック、または選択中折れ線で Ctrl+Shift+C を押して始点と終点を結ぶ |
| 折れ線を開く | 閉じた折れ線選択中に Ctrl+Shift+O を押す、または閉じた折れ線の頂点を Ctrl+Shift+クリックして接続を解除する |
| テキスト配置 | クリック位置にその場編集欄を出し、フォーカス移動、Ctrl+Enter、Ctrl+Return で確定後に複数行文字列を配置する |
| 色変更 | 選択中の色を変更する |
| 線幅変更 | 選択中の線幅を 0 以上に変更する。0 の場合は輪郭線を描画しない。テキスト以外の描画要素選択中は選択済み描画要素へ反映する |
| 線種変更 | 選択中の線種を実線または点線に変更する。テキスト以外の描画要素選択中は選択済み描画要素へ反映する |
| 塗り潰し色変更 | 選択中の塗り潰し色を変更する。矩形、楕円、円、閉じた折れ線の選択中は選択済み描画要素へ反映する。透明の場合は塗り潰さない |
| スタイルリセット | 選択済み描画要素がある場合、選択済み描画要素の色、塗り潰し、線幅、線種、矢印を標準値へ戻し、テキスト要素はフォントも標準値へ戻す。選択済み描画要素がない場合、以後作成する描画要素の既定スタイルと既定フォントを標準値へ戻す |
| フォント設定変更 | フォント設定を変更する |
| 重なり順変更 | 選択済み描画要素を前面方向または背面方向へ 1 段移動する。複数選択時は選択グループの相対順を保って移動する |
| 操作選択ボタンヘルプ | 操作選択ボタンにマウスカーソルが入ってから 2 秒後に、対象操作のヘルプを 3 秒間表示する |
| Undo | 直前の編集操作を取り消す。履歴が空の場合は無視する |
| Redo | 取り消した編集操作を復元する。履歴が空の場合は無視する |
| ズーム変更 | ズーム倍率入力欄は Enter またはフォーカス移動で確定した時に 10% から 400% にクランプして表示倍率を変更する |
| ショートカットキー | 対応するツール選択、Undo/Redo、ズーム、ページ操作を実行する |
| ヘルプメニュー | ショートカットキー一覧を表示する |
| 前ページ | 前のページへ移動する |
| 次ページ | 次のページへ移動する |
| ページ追加 | 20ページ未満の場合、カレントページの次に新しい空ページを追加して、その新規ページへ移動する |
| ページ削除 | 削除前に確認し、確認後に対象ページを削除する |
| 画像保存 | 現在ページの描画要素を囲む範囲を、指定した PNG または SVG として保存する。ページロック中でも実行できる |
| アプリ終了 | 設定情報、ページ、描画内容を保存する |
| ウィンドウサイズ変更 | 利用者がウィンドウサイズを変更し、終了時にサイズを保存する |

### 5.6 入力変更時の挙動

- ツール選択時、現在の入力ツール表示を更新する。
- 描画要素の選択時、対象に選択枠と角ハンドルを表示する。
- ラバーバンドドラッグ中はラバーバンド矩形を表示し、範囲内の描画要素を選択状態表示にする。
- ラバーバンド確定後、範囲内の描画要素を複数選択状態にする。
- Ctrl を押したままクリックした描画要素は、既存の選択状態へ追加する。
- 選択ツール選択中に描画要素が選択されている場合、矢印キーで選択済み描画要素を 1px ずつ移動する。
- 選択済み描画要素の前面/背面操作時、ページ内の要素配列順を変更して描画順へ反映する。
- 描画、消しゴム、ページ移動、Undo/Redo 時、選択枠を解除する。
- 色、線幅、線種、フォント設定の変更時、以後の描画やテキスト配置に使う設定を更新する。
- テキストオブジェクト選択中の色、フォント変更時、選択済みテキストオブジェクトへ変更を反映する。
- スタイルリセット時、選択中の場合は選択済み描画要素へ、未選択の場合は既定スタイルと既定フォントへ標準値を反映する。
- ズーム倍率入力欄の変更中は表示倍率を更新せず、Enter またはフォーカス移動で確定した時に 10% から 400% の範囲へクランプして表示倍率を更新する。
- ズーム倍率の変更時、キャンバス表示サイズも倍率に合わせて更新する。
- ページ数が 20 ページに達した場合、ページ追加ボタンを無効化する。
- ページ数が 20 ページ未満になった場合、ページ追加ボタンを有効化する。
- ページ数が 1 ページの場合、ページ削除ボタンを無効化する。
- ページ数が 2 ページ以上になった場合、ページ削除ボタンを有効化する。
- 現在ページに描画要素がない場合は画像保存操作を無効化し、描画要素がある場合は有効化する。
- Undo/Redo 履歴が空の場合、Undo/Redo 操作は無視する。

### 5.7 成功時表示

- 描画、削除、図形配置、テキスト配置、選択済み描画要素の移動、サイズ変更、テキスト変更の結果をキャンバスへ反映する。
- ラバーバンド選択、複数移動、複数削除、コピー/ペーストの結果をキャンバスへ反映する。
- ベジェ曲線、円弧、円、矢印、辺ハンドルサイズ変更、円弧角変更の結果をキャンバスへ反映する。
- ページ操作後はページ番号を更新する。
- ズーム変更後はズーム倍率表示を更新する。
- 画像保存が成功した場合、標準ファイルダイアログで指定した場所にファイルを作成する。

### 5.8 失敗時表示

- 入力デバイスがない場合は描画入力を受け付けない。
- 描画入力が中断された場合は現在の描画操作を終了する。
- ページ上限時はページ追加ボタンを無効化し、ページを追加しない。
- ページ下限時はページ削除ボタンを無効化し、最後の1ページは削除しない。
- 保存失敗、読み込み失敗は扱わない。
- 画像保存に失敗した場合はエラーを表示し、同じ画像保存操作を再試行できるようにする。

### 5.9 エラーメッセージ

| エラー | 表示文言 |
| --- | --- |
| ページ削除確認 | このページを削除しますか |
| ページ上限 | なし。ページ追加ボタンを無効化する |
| ページ下限 | なし。ページ削除ボタンを無効化する |
| Undo/Redo 空履歴 | なし。操作を無視する |

### 5.10 空状態・未選択状態

- 保存済み内容がない場合は、空の1ページを表示する。
- 保存済みウィンドウサイズがない場合は、ツールバーのボタンと操作部品がすべて表示される既定サイズで表示する。
- ツール未選択状態は作らず、初期ツールを選択状態にする。
- 描画要素未選択状態では選択枠と角ハンドルを表示しない。

## 6. UIとビジネスレイヤーの境界

UIが行うこと:

- ツールバー、キャンバス、ページ番号、設定操作部品、右端の展開式フローティングアクションボタンを表示する。
- ユーザー入力を受け取り、ビジネスレイヤーへ渡す。
- ページ削除確認を表示する。
- ページ追加ボタンとページ削除ボタンの有効、無効を表示する。
- 選択枠と角ハンドルを表示する。
- ラバーバンドを表示する。
- アイコン画像を表示する。
- アプリケーションアイコンを設定する。
- ショートカットキーを QAction に割り当てる。
- ショートカットキーは、選択 `Ctrl+1`、ペン `Ctrl+2`、消しゴム `Ctrl+3`、直線 `Ctrl+4`、矩形 `Ctrl+5`、円 `Ctrl+6`、テキスト `Ctrl+7`、折れ線 `Ctrl+8`、ベジェ曲線 `Ctrl+9`、円弧 `Ctrl+0`、折れ線延長開始 `Ctrl+端点クリック`（macOS は `Control+クリック`）、折れ線を閉じる `Ctrl+Shift+C`、折れ線を開く `Ctrl+Shift+O`、選択要素削除 `Delete` / `Backspace`、Undo/Redo は標準キー、ズームは標準 Zoom In/Out、ページ移動は `Alt+Left` / `Alt+Right`、ページ追加は `Ctrl+Shift+N`、ページ削除は `Ctrl+Shift+Backspace` とする。
- コピー/ペーストは標準 Copy/Paste ショートカットを使う。macOS では Command-C / Command-V とする。
- ヘルプメニューにショートカットキー一覧を表示する QAction を追加する。
- 「ファイル」メニューに「画像を保存...」を表示する。
- 「画像を保存...」の実行時に画像保存設定ダイアログを表示する。
- 画像保存形式、背景、保存先を受け取り、ビジネスレイヤーへ渡す。

UIが行わないこと:

- 描画要素のデータ構造や保存形式を決める。
- Undo/Redo 履歴の中身を管理する。
- 選択対象の移動量やサイズ変更結果を独自に決める。
- ズーム倍率の範囲判定やクランプ結果を独自に決める。
- ページ上限や保存対象の仕様を独自に決める。

## 7. 種別別の任意UIパターン

| パターン | 採用有無 | UI内容 |
| --- | --- | --- |
| 対象データの追加・削除 | 採用 | ページ追加、ページ削除、描画要素削除を行う |
| 一覧・詳細 | なし | 一覧画面、詳細画面は作らない |
| 管理画面 | なし | 管理画面は作らない |
| 状態表示 | 採用 | ページ番号、ページロック状態、ズーム倍率、選択中ツール、ページ追加ボタンとページ削除ボタンの無効状態を表示する |
| 集計・結果表示 | なし | 集計や結果表示は行わない |
| 進行状態・ログ表示 | なし | 進行状態やログ表示は行わない |

## 8. デザイン方針

- デザインは `design/whiteboard-concept-1-minimal.svg` を基準にする。
- 見た目はシンプル、すっきり、余白多めにする。
- キャンバスを主役にし、ツールバーや状態表示は控えめにする。
- 白いキャンバス、薄いトップバー、控えめなティールのアクセントを使う。
- ツールバー背景はチャコールグレー系の濃い色にし、下境界線と控えめな影でキャンバスから分離する。
- ツールバーのグループ区切りは細いセパレータで視覚的に分かるようにする。
- アイコンは `whiteboard-app/assets/icons/` 配下の 24x24 SVG を使う。
- アイコンは線色 `#344054` のシンプルな線画を基本とする。
- 使用するアイコンは `select.svg`, `pen.svg`, `eraser.svg`, `line.svg`, `rectangle.svg`, `ellipse.svg`, `polyline.svg`, `text.svg`, `undo.svg`, `redo.svg`, `copy.svg`, `paste.svg`, `send-backward.svg`, `bring-forward.svg`, `zoom-in.svg`, `zoom-out.svg`, `page-prev.svg`, `page-next.svg`, `page-add.svg`, `page-delete.svg`, `page-lock.svg`, `page-unlock.svg`, `color.svg`, `fill-color.svg`, `stroke-width.svg`, `font.svg` とする。
- ページ操作グループにはページロックのトグルボタンを置く。ロック中のページでは選択、コピー、ページ移動、ズーム、スクロールのみ許可し、描画追加、削除、貼り付け、移動、リサイズ、回転、頂点編集、テキスト編集、スタイル変更、グループ化、Undo/Redo、ページ削除は無効化する。
- 追加ツールのアイコンは `bezier.svg`, `arc.svg`, `circle.svg` とする。
- アプリケーションアイコンは `assets/appicon/whiteboard-app-icon.png` と `assets/appicon/WhiteboardApp.icns` とする。
- アプリケーションアイコンは、`design/whiteboard-concept-1-minimal.png` の白いボード画面を元にし、描画中の線とペンを重ねた見た目にする。
- 採用デザインにある「共有中」などの状態表示は表示しない。
- 採用デザインにある参加者カーソル風の表示は表示しない。

## 9. MCP 実行確認

- MCP の図反映要求では、反映モードとオブジェクト数を確認ダイアログへ表示する。
- MCP の Undo 要求では、直前変更を元に戻すことを確認ダイアログへ表示する。
- 既定ボタンは拒否とし、拒否時はキャンバス、ページ、履歴、保存内容を変更しない。
- 状態取得と PNG 取得は読み取り専用のため確認ダイアログを表示しない。
- 通常起動時にローカル MCP HTTP Server を開始できない場合は警告ダイアログを表示するが、
  ホワイトボード画面は閉じず通常操作を継続できる。
- MCP 専用の常設ツールバー、チャット欄、進捗欄は追加しない。

## 10. 画像保存

- 画像保存操作の入口は、メニューバーの「ファイル」メニューに置く「画像を保存...」とする。上部ツールバーには画像保存ボタンを追加しない。
- 「画像を保存...」を実行すると、画像保存設定ダイアログを表示する。
- 画像保存設定ダイアログには、PNG または SVG を選ぶ画像形式と、透明または白を選ぶ背景を表示する。
- 背景は透明を既定の選択状態とする。
- 画像保存設定ダイアログには「保存...」と「キャンセル」を表示する。
- 「保存...」を実行すると、選択した画像形式を初期フィルターにした標準ファイルダイアログを表示する。
- 画像保存設定ダイアログまたは標準ファイルダイアログで「キャンセル」を実行した場合は、画像を保存しない。
- 保存に失敗した場合は画像形式、背景、保存先を保持してエラーを表示し、「再試行」または「キャンセル」を選択できるようにする。
- 現在表示しているページだけを対象とする。
- 描画要素が未選択の場合は現在ページ内の全描画要素、選択中の場合は選択中の全描画要素を囲むバウンディングボックスを切り抜き範囲にする。
- 描画要素が選択されている場合は、選択中の描画要素だけを保存画像へ表示する。
- 線幅、矢印、回転後形状などを含めて画像が欠けないように、描画範囲から必要な余白を計算して切り抜き範囲へ加える。
- 現在のズーム倍率とスクロール位置は保存画像に影響させない。
- PNG と SVG の切り抜き範囲は同一にする。
- PNG はキャンバス座標 1 単位を 1px として保存する。
- SVG はラスター画像を埋め込まず、描画要素をベクターとして保存し、各描画要素に分かりやすい一意な ID を付ける。
- 背景は透明を既定とし、キャンバス表示と同じ白を選択可能にする。
- 選択枠、リサイズハンドル、回転ハンドル、ラバーバンドは保存画像へ表示しない。
- 編集中のテキストは確定してから保存し、作成途中の図形プレビューは表示しない。
- ページロック中でも画像保存操作を有効にする。
- ファイル形式は保存ダイアログのフィルターまたはファイル名の拡張子で決定する。
- ファイル名に拡張子がない場合は、選択中の形式に応じて `.png` または `.svg` を自動付加する。
- 保存ダイアログのフィルターとファイル名の拡張子が異なる場合は、入力した拡張子を優先する。
- 既存ファイルの上書き確認は標準ファイルダイアログに従う。

## 11. 対象外

- クラウド同期。
- アカウント管理。
- セミナー配信機能。
- チャット。
- 録画。
- 参加者管理。
- テンプレート管理。ただし、コピー専用ページを保護するページロックは対象内とする。
- アプリ内の AI 推論、チャット、プロンプト入力 UI。
- 実共有状態の実装。
- 参加者カーソル機能。
