# ホワイトボードアプリ 実装プロンプト

以下を上位仕様として扱い、対象アプリを実装してください。

実装時の作業ディレクトリは `whiteboard-app` としてください。

- `source_memo.md`
- `specs/01_usecase_spec.md`
- `specs/02_ui_spec.md`
- `specs/03_business_spec.md`
- `implementation_constraints.md`
- `implementation_design.md`

## 仕様要約

- 仕様上のアプリ種別: エディタアプリ
- オンラインセミナーで講師または進行役が使うホワイトボードアプリを実装する。
- 白いキャンバス、薄いトップバー、上部ツールバー、控えめなティールのアクセントを持つシンプルな UI にする。
- ペン、消しゴム、選択による移動とサイズ変更、テキスト変更、選択済みテキストの色とフォント変更、複数行テキスト、図形、折れ線、テキスト、Undo/Redo、ズーム、ショートカットキー、ページ操作、保存・読み込みを実装する。
- デフォルトのウィンドウ幅は、ツールバーのボタンと操作部品がすべて表示される幅にする。
- 直線、開いた折れ線、ベジェ曲線、円弧の端点矢印、ベジェ曲線、円弧、円、矩形・楕円・円の辺ハンドルサイズ変更を実装する。
- 直線の端点を図形へ接続し、接続先図形の移動、サイズ変更、回転、スケールに追従するコネクターを実装する。
- 選択ツールでのラバーバンド複数選択、複数移動、複数削除、選択オブジェクトのコピー/ペーストを実装する。
- 現在ページの全描画要素または選択要素だけを、描画範囲へ切り抜いた PNG/SVG として保存する。
- PNG、JPEG、BMP、SVG の画像ファイルを、画像要素として現在ページへ取り込む。
- ツールバーと操作部品には `assets/icons/` 配下の SVG アイコンを使う。
- アプリケーションアイコンには `assets/appicon/whiteboard-app-icon.png` と `assets/appicon/WhiteboardApp.icns` を使う。

## 実装方式

- 言語: C++。
- フレームワーク: Qt Widgets。
- ビルド方式: CMake。
- macOS では `arm64;x86_64` の universal binary を既定でビルドしてください。
- テスト方式: Qt Test による業務ロジック単体テストと CanvasWidget 操作・描画テスト。
- MCP は WhiteboardApp 専用の最小 JSON-RPC 実装とし、外部 qtmcpserver ソースツリーへ依存しないでください。
  通常起動時は `127.0.0.1:8765/mcp` で Streamable HTTP Server を開始してください。
  loopback 接続と localhost 系 Origin だけを許可し、ポート競合時は警告を表示して GUI 本体は継続してください。
- `--mcp` 起動時は互換用の標準入出力 Server だけを開始してください。
- バージョンは `VERSION` を正本とし、CMake project version、アプリケーションバージョン、
  MCP `serverInfo.version` と一致させてください。リリース内容は `CHANGELOG.md` に記録してください。
- リポジトリ直下の `whiteboard-app.zip` は Git 管理外のローカル確認用生成物にしてください。
  正式な source release ZIP は `release/whiteboard-app-<version>-source.zip` に作成し、ZIP 内トップ階層は
  `whiteboard-app-<version>/` にしてください。`DECISIONS.md`、`NEXT.md`、`backlog.md`、`docs/`、
  `release/` は source release ZIP に含めないでください。
- 公開 MCP tool は `whiteboard/state`、`whiteboard/elements/list`、`whiteboard/elements/update`、
  `whiteboard/elements/delete`、`whiteboard/pages/list`、`whiteboard/page/navigate`、
  `whiteboard/elements/apply`、
  `whiteboard/page/add`、`whiteboard/page/delete`、`whiteboard/page/lock`、
  `whiteboard/diagram/apply`、`whiteboard/page/render`、`whiteboard/image/export`、
  `whiteboard/image/save`、`whiteboard/history/undo`、`whiteboard/history/redo` の 16 件だけにしてください。

## 実装条件

- UI とビジネスロジックを分離してください。
- ビジネスロジックは UI に依存しない形で実装してください。
- 入力検証はビジネスレイヤー仕様書に従ってください。
- エラー表示は UI仕様書の文言に従ってください。
- 対象外に記載された機能は実装しないでください。
- ソースコードは対象アプリ用ディレクトリ配下に置いてください。
- `src` と `include` ディレクトリの構成を維持し、必要に応じて新しいファイルを追加してください。
- ひとつのファイルに複数のクラスを定義しないでください。
- `CMakeLists.txt` を作成または修正する前に、`~/AGENTS.cmake.md` を読んで従ってください。
- プロジェクト共通の実装制約は `implementation_constraints.md` に従ってください。
- 再生成時に維持すべき実装設計契約は `implementation_design.md` に従ってください。
- 三点セットにない便利機能を追加しないでください。

## UI条件

- UI仕様書に従ってください。
- デザイン方針に従ってください。
- 採用デザインは `../design/whiteboard-concept-1-minimal.svg` です。
- ツールバー背景はチャコールグレー系の濃い色にし、下境界線と控えめな影でキャンバスから分離してください。
- ツールバーのグループ区切りは細いセパレータで視覚的に分かるようにしてください。
- 保存済みウィンドウサイズがある場合、起動時に前回のウィンドウサイズで表示してください。
- 保存済みウィンドウサイズがない場合、ツールバーのボタンと操作部品がすべて表示されるデフォルトサイズで表示してください。
- アイコンは `assets/icons/` 配下の 24x24 SVG を使ってください。
- アイコンは線色 `#344054` のシンプルな線画を基本にしてください。
- 使用するアイコンは `select.svg`, `pen.svg`, `eraser.svg`, `line.svg`, `rectangle.svg`, `rounded-rectangle.svg`, `ellipse.svg`, `polyline.svg`, `text.svg`, `undo.svg`, `redo.svg`, `copy.svg`, `paste.svg`, `send-backward.svg`, `bring-forward.svg`, `zoom-in.svg`, `zoom-out.svg`, `page-prev.svg`, `page-next.svg`, `page-add.svg`, `page-delete.svg`, `page-lock.svg`, `page-unlock.svg`, `color.svg`, `fill-color.svg`, `reset-style.svg`, `stroke-width.svg`, `font.svg` です。
- 追加ツールのアイコンは `bezier.svg`, `arc.svg`, `circle.svg` です。
- ツールバーは、基本ツール、図形ツール、テキスト関連、編集操作、スタイル設定、表示操作、ページ操作の順にグルーピングしてください。
- ウィンドウ幅に収まらないツールバー項目は独自の拡張パネルへ表示してください。拡張ボタンの
  クリックで開閉し、マウスカーソルがパネル外へ移動した場合やパネル内の操作後は閉じないでください。
  同じ拡張ボタンを再度クリックした場合、または全項目が通常行へ収まった場合に閉じてください。
- Qt の内部拡張ボタンや内部メニューを後から制御せず、同じ操作部品を通常行と拡張パネルの間で
  再配置してください。拡張パネルの表示領域以外でキャンバス入力を妨げないでください。
- 拡張パネルの左右背景余白は、Qt が配置した後の先頭操作部品の左端と末尾操作部品の右端を測り、
  両側が同じ幅になるようにパネル幅を決めてください。固定ピクセル値では補正しないでください。
- ページ操作グループにはページロックのトグルボタンを追加してください。ロック中ページでは選択、コピー、ページ移動、ズーム、スクロールのみ許可し、描画追加、削除、貼り付け、移動、リサイズ、頂点編集、テキスト編集、スタイル変更、グループ化、Undo/Redo、ページ削除を無効化してください。
- ページ操作グループはページ番号、前ページ、次ページ、ページ追加、ページ削除、ページロックの順に
  配置し、ページロックボタンをツールバーの末尾項目にしてください。
- フォント設定ボタンは、テキストツールボタンの右横に配置してください。
- コピー/ペーストボタンは、Undo/Redo と同じ編集操作グループに配置してください。
- 直線、開いた折れ線、ベジェ曲線、円弧の開始端点と終了端点に矢印を付けられるようにしてください。矢印形状は、なし、三角、開いた矢印、ひし形から選択できるようにしてください。
- 直線の開始点または終了点が矩形、角丸矩形、楕円、円、テキスト、画像の上にある場合、その端点を対象描画要素へ接続してください。
  接続済み端点は対象図形の境界上に配置し、対象図形の移動、サイズ変更、回転、スケール、テキストサイズ変更、角丸変更に追従してください。
  接続済み直線または接続解除済み直線の端点を手動で移動して図形外で離した場合は、操作対象端点の接続を解除したままにし、図形上で離した場合はその図形へ再接続してください。
  直線をリサイズした場合は、操作対象端点の接続を解除してください。
  接続先図形を削除した場合、直線は残し、削除された接続先への接続だけを解除してください。
  接続済み直線と接続先図形をまとめてコピー、ペースト、MCP 図反映した場合、接続先 ID は新しい図形 ID へ張り替えてください。
- ベジェ曲線オブジェクトを追加してください。
- ベジェ曲線ツールはクリックごとに通過点を追加し、ダブルクリックまたは Enter で確定、Esc でキャンセルできるようにしてください。ベジェ曲線は2点以上の通過点列を持ち、通過点列から滑らかな曲線として描画してください。
- ベジェ曲線の始点または終点を Ctrl+クリック（macOS は Control+クリック）した場合、そのベジェ曲線を選択して端点から通過点を追加し、既存ベジェ曲線を延長できるようにしてください。ダブルクリックまたは Enter で確定し、Esc でキャンセルできるようにしてください。
- 円弧オブジェクトを追加してください。円弧は長径と短径を常に同一にし、円弧の角を変更できるようにしてください。
- 円オブジェクトを追加してください。円は長径と短径を常に同一にしてください。
- 角丸矩形ツールを追加し、ドラッグした矩形領域に角丸矩形を作成できるようにしてください。
- 角丸矩形の丸みは 0 以上の値で調整できるようにしてください。角丸矩形選択中に変更した場合は選択済み角丸矩形へ反映し、未選択時は以後作成する角丸矩形の既定丸みへ反映してください。
- 矩形、角丸矩形、楕円、円は、辺を掴んでその辺と直角方向のサイズを変更できるようにしてください。
- ペン、直線、折れ線、ベジェ曲線、円弧、矩形、角丸矩形、楕円、円は、線種を実線または点線から選べるようにしてください。
- 線幅、角丸矩形の丸み、線種は近くに配置し、テキスト以外の描画要素選択中に変更した場合は選択済み描画要素へ反映してください。ただし丸みは角丸矩形にだけ反映してください。
- 選択ツールでオブジェクトがない場所を左ボタンドラッグした場合、ラバーバンドを表示してください。
- ラバーバンド内に入ったオブジェクトは、ドラッグ中に選択状態表示にしてください。
- マウスボタンを離した時点で、ラバーバンド内のオブジェクトを選択確定してください。
- 選択ツールで Ctrl を押したまま描画要素をクリックした場合、クリックした描画要素を既存の選択状態へ追加してください。macOS は Control+クリックとしてください。
- 選択済み描画要素を前面方向または背面方向へ 1 段移動し、重なり順を変更できるようにしてください。複数選択時は選択グループの相対順を保ってください。
- 選択ツールで描画要素が選択されている場合、矢印キーで選択済み描画要素を 1px ずつ移動できるようにしてください。
- ラバーバンドで選択した複数オブジェクトは、まとめて移動できるようにしてください。
- ラバーバンドで選択した複数オブジェクトは、Delete / Backspace でまとめて削除できるようにしてください。
- 選択状態のオブジェクトをコピー/ペーストできるようにしてください。複数選択時は複数オブジェクトを対象にしてください。
- macOS では Command-C / Command-V のショートカットキーでコピー/ペーストできるようにしてください。
- 操作選択ボタンにマウスカーソルが入った場合、2 秒後に対象操作のヘルプを表示し、3 秒後に非表示にしてください。
- アプリケーションアイコンは、`../design/whiteboard-concept-1-minimal.png` の白いボード画面を元にし、描画中の線とペンを重ねた見た目にしてください。
- Qt のウィンドウアイコンには `assets/appicon/whiteboard-app-icon.png` を設定してください。
- macOS アプリケーションバンドルには `assets/appicon/WhiteboardApp.icns` を設定してください。
- 「共有中」などの状態表示は表示しないでください。
- 参加者カーソル風の表示は表示しないでください。
- ホワイトボード右端に初期状態では丸いフローティングアクションボタンを 1 つ配置してください。ユーザーはボタンを上下ドラッグで移動でき、クリックすると位置に応じて上方向または下方向へ展開して、選択、リセット、Undo、Redo、コピー、貼り付けをすぐ実行できるようにしてください。フローティングアクションボタンの上下位置は設定情報として保存してください。
  「選択」子ボタンを常に親 FAB の隣に配置するため、上方向へ展開する場合は子ボタンの表示順とタブ移動順を反転してください。展開中のドラッグで画面中央をまたいだ場合も、展開方向と順番を更新してください。
  子ボタン群の開閉は、スライドと透明度変化で滑らかに表示・非表示してください。
  フローティングアクションの Undo と Redo は、クリック後も展開状態を維持してください。
  展開中の子ボタンにマウスカーソルを置いたときは、子ボタン左横に黒系の吹き出しラベルで操作名を表示してください。
  子ボタン自体は拡大せず、ボタン列がガタつかないようにしてください。
  吹き出しラベルは右端に子ボタンへ向いた尖りを持ち、マウス操作を受け取らないようにしてください。
  吹き出しラベルの幅は長い日本語表示名が欠けないよう、固定上限で切らずに子ボタン左側の空き幅に応じて決めてください。
  FAB 子ボタンでは標準ツールチップを操作名表示に使わず、吹き出しラベルに一本化してください。
  吹き出し表示のためにフローティングアクションの前面パネル幅を広げず、見えない領域がキャンバス右側のオブジェクト選択を妨げないようにしてください。
- 上部ツールバー背景はチャコールグレー系の濃い色にし、色分けしたボタンのアクセントが落ち着いて見えるようにしてください。
- 上部ツールバーのボタン背景は、基本ツールはシアン系、図形はグリーン系、テキストはイエロー系、編集操作はブルー系、スタイル設定はオレンジ系、ズームはシアン系、ページ操作はローズ系、削除など破壊的操作はより強い赤系で色分けしてください。
- ツールバー上のスピンボックスとコンボボックスは、薄灰背景、角丸、控えめな枠線の入力ピルとして統一してください。
  スピンボックスは中央に値表示、左右に減少/増加ボタンを持つ分割ボタン型にしてください。
  コンボボックスは分割ボタン型スピンボックスと見た目の高さのバランスをそろえてください。
- ページ数が 20 ページに達した場合、ページ追加ボタンを無効化してください。
- UI テキストは英語をソース上の基準文字列とし、日本語環境では日本語、それ以外では英語を表示してください。
  日本語翻訳は `translations/whiteboard_ja.ts` に定義し、CMake の `LinguistTools` と `qt_add_translations()` で `:/i18n/whiteboard_ja.qm` として埋め込んでください。
  起動時に `QLocale::system()` を見て、日本語ロケールの場合だけ `QTranslator` で日本語翻訳を読み込んでください。
- ページ追加では、カレントページの次に新しい空ページを挿入し、その新規ページへ移動してください。
- ページ数が 1 ページの場合、ページ削除ボタンを無効化してください。
- 選択ツールでは、描画要素をクリック選択し、選択枠と角ハンドルを表示してください。
- 選択済み描画要素の内側ドラッグで移動し、角ハンドルのドラッグでサイズ変更してください。
- 選択枠の外側に回転ハンドルを表示し、ドラッグで回転できるようにしてください。Shift 押下中は 15 度単位にスナップし、ドラッグ中は角度を表示してください。単一要素は要素中心、複数選択またはグループはドラッグ開始時の選択範囲中心を固定して回転してください。
- 回転した矩形系描画要素のリサイズは要素自身の辺に沿って行い、選択、消しゴム、範囲選択、円弧ハンドル、コピー・貼り付け、Undo/Redo、ページロック、保存・復元も回転後の位置と角度へ対応してください。JSON の `rotationDegrees` がない既存データは 0 度として扱ってください。
- 回転済みテキストの編集時は元の描画を一時的に隠し、回転後の範囲に水平なその場編集欄を表示し、確定後も角度を維持してください。
- 直線オブジェクトと折れ線オブジェクトは、端点だけでなく線分の中間点付近でも選択できるようにしてください。
- 直線オブジェクト選択時は実際の 2 端点にハンドルを表示し、端点ハンドルのドラッグでドラッグした端点だけを移動できるようにしてください。矩形 bounds の正規化で端点の向きや対応を入れ替えないでください。
- 折れ線ツールを追加し、クリックごとに頂点追加、ダブルクリックまたは Enter で確定、Esc でキャンセルできるようにしてください。
- 折れ線ツールで3点以上入力済みの場合、始点付近クリックまたは Ctrl+Enter で閉じた折れ線として確定できるようにしてください。
- 選択済みの開いた折れ線は Ctrl+Shift+C で閉じられるようにしてください。
- 選択済みの閉じた折れ線は Ctrl+Shift+O で開いた折れ線に戻せるようにしてください。
- 閉じた折れ線の頂点を Ctrl+Shift+クリックした場合、その折れ線を選択し、クリックした頂点と直前の頂点の間を開いて開いた折れ線に戻せるようにしてください。
- 開いた折れ線の始点または終点を Ctrl+クリックした場合、その折れ線を選択して端点から既存折れ線を延長できるようにしてください。通常クリックは頂点移動や選択操作を優先してください。
- 折れ線延長中に既存折れ線の反対側端点付近をクリックした場合、追加した線分を含めて閉じた折れ線として確定できるようにしてください。反対側端点は重複頂点として追加せず、closed の閉じ線分として扱ってください。
- 閉じた折れ線は保存、読み込み、描画、選択判定で最後の頂点から最初の頂点への線分を扱ってください。
- 折れ線オブジェクト選択時は端点と屈曲点に頂点ハンドルを表示し、頂点ハンドルのドラッグで該当頂点だけを移動できるようにしてください。
- ベジェ曲線ツールで3点以上入力済みの場合、始点付近クリックまたは Ctrl+Enter で滑らかな閉じたベジェ曲線として確定できるようにしてください。
- 選択済みの開いたベジェ曲線は Ctrl+Shift+C で閉じ、選択済みの閉じたベジェ曲線は Ctrl+Shift+O で開いたベジェ曲線に戻せるようにしてください。
- 閉じたベジェ曲線では端点矢印を表示せず、矢印形状変更の対象外にしてください。
- 矩形、角丸矩形、楕円、円、閉じた折れ線、閉じたベジェ曲線は内部を塗り潰せるようにしてください。塗り潰し色は透明を指定でき、透明の場合は塗り潰さないでください。
- 塗り潰し色の変更は、矩形、角丸矩形、楕円、円、閉じた折れ線、閉じたベジェ曲線の選択中は選択済み描画要素へ反映し、選択中でない場合は以後作成する閉じた図形の既定塗り潰し色にしてください。
- 色の変更は、テキスト以外の描画要素選択中は選択済み描画要素の描画色または輪郭線色へ反映し、選択中でない場合は以後作成する描画要素の既定描画色にしてください。
- スタイルリセットボタンをスタイル設定グループに配置してください。選択済み描画要素がある場合は選択済み描画要素の色、塗り潰し、線幅、角丸矩形の丸み、線種、矢印を標準値へ戻し、テキスト要素はフォントも標準値へ戻してください。選択済み描画要素がない場合は以後作成する描画要素の既定スタイルと既定フォントを標準値へ戻してください。標準値は、描画色 `#344054`、塗り潰し透明、線幅 `3`、角丸矩形の丸み `24`、線種 `solid`、開始端点矢印なし、終了端点矢印なし、フォント `Sans Serif 18pt` です。
- 線幅 0 を許可し、線幅 0 の場合は Qt の 0 幅ペンではなく輪郭線なしとして描画してください。
- テキストはダイアログではなく、キャンバス上のその場編集欄で入力、変更できるようにしてください。
- テキスト入力欄は複数行入力に対応してください。
- テキスト入力欄はフォーカス移動、Ctrl+Enter、Ctrl+Return で確定できるようにしてください。
- 選択ツールでテキストオブジェクトをダブルクリックした場合、既存テキストを初期値にしたその場編集欄でテキスト変更できるようにしてください。
- テキストオブジェクト選択中に色またはフォントを変更した場合、選択済みテキストオブジェクトへ反映してください。
- ズーム変更時はキャンバス表示サイズを倍率に合わせて更新してください。
- ズーム倍率入力欄は、値の変更中ではなく Enter またはフォーカス移動で確定した時だけ表示倍率へ反映してください。
- ショートカットキーは、ツール選択、Undo/Redo、ズーム、ページ移動、ページ追加、ページ削除へ割り当ててください。
- ショートカットキーは、選択 `Ctrl+1`、ペン `Ctrl+2`、消しゴム `Ctrl+3`、直線 `Ctrl+4`、矩形 `Ctrl+5`、円 `Ctrl+6`、テキスト `Ctrl+7`、折れ線 `Ctrl+8`、ベジェ曲線 `Ctrl+9`、円弧 `Ctrl+0`、選択要素削除 `Delete` / `Backspace`、選択要素を背面へ 1 段移動 `Ctrl+[`、選択要素を前面へ 1 段移動 `Ctrl+]`、選択要素を最背面へ移動 `Ctrl+Shift+[`、選択要素を最前面へ移動 `Ctrl+Shift+]`、Undo/Redo は標準キー、ズームは標準 Zoom In/Out、ページ移動は `Alt+Left` / `Alt+Right`、ページ追加は `Ctrl+Shift+N`、ページ削除は `Ctrl+Shift+Backspace` としてください。
- ツール選択、選択要素を背面または前面へ移動、ページ追加、ページ削除のショートカットは、macOS でも物理 Control キーで動作するようにしてください。
- ヘルプメニューを追加し、ショートカットキー一覧を表示できるようにしてください。
- メニューバーの File に `Import Image...` と `Save Image...` を追加し、ツールバーには画像取り込み・画像保存ボタンを追加しないでください。
- `Import Image...` では PNG、JPEG、BMP、SVG を標準ファイルダイアログで選び、SVG はベクター分解せず PNG 化して画像要素として保存してください。
- OS クリップボードに画像がある場合は、貼り付け操作で画像要素として追加してください。対応画像ファイルのキャンバスへのドラッグ＆ドロップでも画像要素として追加してください。アプリ内コピーがある場合は従来のオブジェクト貼り付けを優先してください。
- 画像要素は選択、移動、サイズ変更、回転、コピー、ペースト、グループ化、削除に対応し、線幅、線種、塗り潰し、矢印、フォント、スタイルリセットの対象外にしてください。
- `Save Image...` では、PNG/SVG と透明/白背景を選ぶ画像保存設定ダイアログを先に表示し、
  `Save...` の後に標準ファイルダイアログを表示してください。既定値は PNG と透明背景です。
- 空ページでは画像保存を無効にし、ページロック中でも描画要素があれば有効にしてください。
- 保存失敗時は画像形式、背景、保存先を保持し、Retry または Cancel を選べるようにしてください。

## 画像保存条件

- 現在表示しているページだけを対象とし、ズーム倍率とスクロール位置は出力へ影響させないでください。
- 未選択時は現在ページの全描画要素、選択時は選択中の描画要素だけを出力してください。
- 線幅、矢印、回転後形状、アンチエイリアス画素が欠けないように必要な余白を計算し、
  PNG と SVG で同じ切り抜き範囲を使ってください。
- PNG はキャンバス座標 1 単位を 1px とし、背景は透明または白で出力してください。
- SVG は通常の描画要素を SVG 図形、path、text として出力し、取り込み画像だけを Base64 data URI の `<image>` として埋め込んでください。
  各描画要素には保存 JSON と共通の永続 ID を付け、ID がない直接生成要素だけ要素種別が分かる一意なフォールバック ID を付けてください。
- 選択枠、リサイズ・回転・頂点・円弧角ハンドル、ラバーバンド、作成途中プレビューは
  出力しないでください。編集中のテキストは確定してから出力してください。
- 拡張子がない場合は選択形式の `.png` または `.svg` を付けてください。
  フィルターと入力拡張子が異なる場合は入力拡張子を優先してください。
- 上書き確認は標準ファイルダイアログに従い、画像保存で文書、選択状態、Undo/Redo 履歴を
  変更しないでください。

## 描画データ交換条件

- File に描画データのインポート／エキスポートを追加する。全ページまたは現在ページを
  `.whiteboard`（形式識別子 `WhiteboardApp.DrawingData`、形式バージョン1、pagesを持つJSON）で書き出す。
- `BoardDocumentExchange` で全体検証とファイル入出力を行い、旧自動保存JSONも検証後に受理する。
- `BoardModel::importPages()` で現在ページの直後へ追加し、全要素の永続IDとコネクター参照を
  張り替える。現在ページと操作設定は維持し、1回のUndo/Redoに対応する。
- ページロック、合計20ページ超過、破損要素・画像・接続を反映前に拒否する。
  書き出しは空ページ・ロック中も可能とし、QSaveFileで書き込みとcommit成功を確認する。
- 未確定テキストは書き出し前／取り込み反映前に確定する。既存のPNG/SVG保存と自動保存は維持する。
- `WhiteboardDocumentExchangeTest` で往復・旧形式・ID非衝突・接続・Undo/Redo・不正入力の無変更を確認する。

## 保存・永続化条件

- 保存が必要か: 必要。
- 保存が必要な場合の保存方式: ローカルファイル保存。
- 保存対象: 設定情報、ページ、描画内容。
- 保存する設定情報: ズーム倍率、選択中ツール、選択中の色、線幅、角丸矩形の丸み、線種、フォント設定、ウィンドウサイズ。
- 保存する描画内容には、各描画要素の永続 ID と次に使う要素 ID 採番値を含めてください。
- 保存する描画内容には、直線端点の接続先描画要素 ID を含めてください。
- 既存保存ファイルに描画要素 ID がない場合、または ID が重複する場合は読み込み時に一意な ID を補完し、図形の見た目、座標、重なり順は変更しないでください。
- コピー、貼り付け、MCP 図反映で新しく作成される描画要素には、入力元とは異なる新しい永続 ID を割り当ててください。
- 選択状態は保存対象に含めないでください。
- 起動時に保存済み内容がある場合は読み込んで表示してください。
- 保存済み内容がない場合は、空ページ 1 件で起動してください。
- 終了時に現在のウィンドウサイズを設定情報へ保存し、次回起動時に復元してください。
- 保存失敗、読み込み失敗は仕様上扱わないため、独自の復旧機能や通知を追加しないでください。
- 仕様にない外部連携やクラウド同期は追加しないでください。
