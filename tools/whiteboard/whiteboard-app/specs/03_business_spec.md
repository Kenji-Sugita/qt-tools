# ホワイトボードアプリ ビジネスレイヤー仕様書

## 1. 概要

本書は、オンラインセミナー向けホワイトボードアプリのビジネスレイヤー仕様を定義する。

## 2. アプリ種別

- 種別: エディタアプリ
- 補足: セミナー中にホワイトボード上へ描画、編集、確認を行う用途を主目的とする。

## 3. 用語

| 用語 | 意味 |
| --- | --- |
| ホワイトボード | 幅 1920px、高さ 1080px の描画可能領域 |
| ページ | ホワイトボードの1枚分の描画内容 |
| 描画要素 | 自由曲線、直線、矩形、楕円、折れ線、ベジェ曲線、円弧、円、テキスト、画像 |
| 設定情報 | ズーム倍率、選択中ツール、選択中の色、線幅、線種、フォント設定、ウィンドウサイズ |
| ツール | ペン、消しゴム、図形、テキストなどの入力モード |
| 選択状態 | 現在ページ上で選択されている描画要素を示す一時状態 |
| ラバーバンド | 複数選択のためにドラッグ中に表示される矩形範囲 |
| コピー対象 | Copy 操作で記録された描画要素 |
| コネクター | 直線の開始端点または終了端点を描画要素の永続 ID へ接続し、接続先の変更に追従する線 |
| Undo/Redo 履歴 | 編集操作の取り消し、やり直しに使う履歴 |

## 4. 処理一覧

| 処理ID | 処理名 | 概要 |
| --- | --- | --- |
| BL-001 | ツール選択 | 現在の入力ツールを更新する |
| BL-002 | 描画更新 | 選択中ツールに応じて描画内容を更新する |
| BL-003 | 選択編集 | 描画要素を選択し、移動、サイズ変更、円弧角変更、削除、矢印変更、スタイルリセット、テキスト変更、または選択済みテキストの色とフォントを変更する |
| BL-003a | ラバーバンド選択 | 矩形範囲に入った描画要素を複数選択する |
| BL-003b | コピー・ペースト | 選択中描画要素をコピーし、現在ページへ複製する |
| BL-004 | Undo/Redo | 編集履歴に基づいて描画内容を戻す、または復元する |
| BL-005 | ページ管理 | ページ追加、削除、前後移動、ページ番号更新を行う |
| BL-006 | ズーム変更 | ズーム倍率を範囲内にクランプして更新する |
| BL-007 | 保存・読み込み | 設定情報、ページ、描画内容を保存、読み込みする |
| BL-009 | 画像保存 | 現在ページの描画要素を囲む範囲を PNG または SVG として保存する |
| BL-010 | 画像取り込み | PNG、JPEG、BMP、SVG の画像ファイル、または OS クリップボード画像を現在ページへ画像要素として追加する |

## 5. データモデル

### 5.1 BoardDocument

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| pages | Page[] | 必須 | 1 から 20 件のページ |
| currentPageIndex | integer | 必須 | 現在ページのインデックス |
| nextElementId | integer | 必須 | 次に作成する描画要素 ID の採番値 |
| revision | integer | 必須 | 文書変更ごとに単調増加するリビジョン。0以上 |
| settings | BoardSettings | 必須 | 保存対象の設定情報 |

### 5.2 Page

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| elements | DrawingElement[] | 必須 | ページ上の描画要素 |

`elements` 配列の後ろにある描画要素ほど前面に描画する。

### 5.3 DrawingElement

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | string | 必須 | ドキュメント内で一意な描画要素 ID |
| type | enum | 必須 | freehand, line, rectangle, ellipse, polyline, bezier, arc, circle, text, image |
| geometry | object | 必須 | 種別ごとの座標情報 |
| color | color | 必須 | 描画色 |
| strokeWidth | number | 必須 | 線幅。0 の場合は輪郭線なし |
| strokeStyle | enum | 必須 | 線種。solid または dotted |
| fillColor | color | 任意 | 塗り潰し色。transparent または alpha 0 の場合は塗り潰さない |
| font | font | 条件付き | テキスト要素の場合に使うフォント設定 |
| text | string | 条件付き | テキスト要素の場合の文字列 |
| imageData | string | 条件付き | 画像要素の場合の PNG Base64 データ |
| imageMimeType | string | 条件付き | 画像要素の場合の MIME type。通常は image/png |
| closed | boolean | 任意 | 折れ線の場合、始点と終点を結ぶかどうか |
| startArrowHead | enum | 任意 | 直線、開いた折れ線、ベジェ曲線、円弧の開始端点矢印形状 |
| endArrowHead | enum | 任意 | 直線、開いた折れ線、ベジェ曲線、円弧の終了端点矢印形状 |
| startConnectionElementId | string | 任意 | 直線の開始端点が接続する描画要素 ID |
| endConnectionElementId | string | 任意 | 直線の終了端点が接続する描画要素 ID |
| arcStartAngle | integer | 条件付き | 円弧の開始角 |
| arcSpanAngle | integer | 条件付き | 円弧の角度幅 |

### 5.4 SelectionState

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| selectedElementIndex | integer | 任意 | 現在ページで選択されている描画要素のインデックス。未選択時は -1 |
| selectedElementIndexes | integer[] | 任意 | 複数選択時の描画要素インデックス一覧 |

選択状態は UI 操作用の一時状態であり、保存対象には含めない。

### 5.5 BoardSettings

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| zoomPercent | number | 必須 | ズーム倍率 |
| selectedTool | enum | 必須 | 選択中ツール |
| selectedColor | color | 必須 | 選択中の色 |
| strokeWidth | number | 必須 | 選択中の線幅。0 の場合は輪郭線なし |
| strokeStyle | enum | 必須 | 選択中の線種。solid または dotted |
| fillColor | color | 必須 | 選択中の塗り潰し色。transparent の場合は塗り潰さない |
| font | font | 必須 | フォント設定 |
| startArrowHead | enum | 必須 | 新規線系要素の開始端点矢印形状 |
| endArrowHead | enum | 必須 | 新規線系要素の終了端点矢印形状 |
| windowWidth | integer | 必須 | 保存するウィンドウ幅 |
| windowHeight | integer | 必須 | 保存するウィンドウ高さ |

標準スタイルは、描画色 `#344054`、塗り潰し透明、線幅 `3`、線種 `solid`、開始端点矢印 `none`、終了端点矢印 `none`、フォント `Sans Serif 18pt` とする。

### 5.6 初期値

| 対象 | 初期値 | 説明 |
| --- | --- | --- |
| pages | 空ページ 1 件 | 保存済み内容がない場合の初期ページ |
| currentPageIndex | 0 | 先頭ページ |
| zoomPercent | 100 | 初期ズーム倍率 |
| windowSize | 1700 x 900 | 保存済みウィンドウサイズがない場合の初期ウィンドウサイズ |
| selectedTool | pen | 初期ツール |
| strokeStyle | solid | 初期線種 |
| fillColor | transparent | 初期塗り潰し色 |
| selectedElementIndex | -1 | 初期状態は描画要素未選択 |
| pageLimit | 20 | 最大ページ数 |
| canvasSize | 1920 x 1080 | 描画可能範囲 |

### 6.2 入力

| 項目 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| tool | enum | 必須 | 選択するツール |

### 6.3 出力

- 選択中ツールが更新される。

失敗時:

- なし。

### 6.4 検証ルール

| ID | ルール | エラー |
| --- | --- | --- |
| VR-001 | tool は対応するツールである | ValidationError |

### 6.5 正規化ルール

- なし。

### 6.6 処理ルール

### 6.7 状態変更ルール

| 現在状態 | 条件 | 次状態 | 結果 |
| --- | --- | --- | --- |

## 7. BL-002 描画更新

### 7.1 目的

選択中ツールに応じてページ上の描画内容を更新する。

### 7.2 入力

| 項目 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| tool | enum | 必須 | 現在の入力ツール |
| input | object | 必須 | 座標列、図形座標、テキストなど |
| settings | BoardSettings | 必須 | 色、線幅、線種、フォント設定 |

### 7.3 出力

成功時:

- ページ上の描画要素が追加、更新、または削除される。
- 編集操作が Undo/Redo 履歴へ反映される。

失敗時:

- 入力デバイスがない場合は描画入力を受け付けない。
- 描画入力が中断された場合は現在の描画操作を終了する。

### 7.4 検証ルール

| ID | ルール | エラー |
| --- | --- | --- |
| VR-001 | 描画座標はキャンバス範囲内で扱う | ValidationError |
| VR-002 | 図形種別は直線、矩形、円のいずれかである | ValidationError |
| VR-003 | テキスト要素は文字列を持つ | ValidationError |

### 7.5 正規化ルール

- 描画可能範囲はキャンバス全体とする。
- キャンバスサイズは幅 1920px、高さ 1080px とする。

### 7.6 処理ルール

- ペンツールはドラッグ軌跡を自由曲線として描画する。
- 消しゴムツールはドラッグ位置に重なる描画要素を削除する。
- 図形ツールは直線、矩形、円を扱う。
- 折れ線ツールは複数点の線分列を扱う。
- 折れ線は open/closed 状態を持ち、closed の場合は最後の頂点から最初の頂点へ線分を追加して扱う。
- 開いた折れ線は、始点または終点側へ頂点を追加して延長できる。
- ベジェ曲線は、2点以上の通過点列を持ち、通過点列から滑らかな曲線として描画する。
- 円弧と円は長径と短径を常に同一にする。
- 円弧は開始角と角度幅を持つ。
- 直線、開いた折れ線、ベジェ曲線、円弧は開始端点と終了端点に矢印形状を持てる。
- 矢印形状は、なし、三角、開いた矢印、ひし形とする。
- 直線の開始点または終了点が矩形、角丸矩形、楕円、円、テキスト、画像の上にある場合、その端点は対象描画要素の永続 ID へ接続できる。
- 接続済み直線の端点座標は、接続先描画要素の境界上に正規化する。矩形、角丸矩形、テキスト、画像は矩形境界、楕円と円は楕円境界を使う。
- テキストツールは確定した文字列をクリック位置に配置する。
- 直線、折れ線、ベジェ曲線、円弧の選択判定は、端点だけでなく線または曲線からの距離で判定する。
- 描画要素の追加または削除時、選択状態を解除する。

### 7.7 状態変更ルール

| 現在状態 | 条件 | 次状態 | 結果 |
| --- | --- | --- | --- |
| ページ表示中 | 描画入力 | 描画更新済み | ページの描画要素が更新される |
| ページ表示中 | 消しゴム入力 | 描画更新済み | 重なる描画要素が削除される |

### 7.8 エラー種別

| エラー種別 | 意味 | UIでの扱い |
| --- | --- | --- |
| ValidationError | 入力値が不正 | 入力を受け付けない |

### 7.9 代表例・期待結果

| 例 | 入力・状態 | 期待結果 |
| --- | --- | --- |
| ペン描画 | ペンツール、ドラッグ座標列 | 自由曲線要素が追加される |
| 消しゴム | 消しゴムツール、描画要素と重なる座標 | 重なる描画要素が削除される |
| 図形配置 | 図形ツール、矩形 | 矩形要素が追加される |
| 折れ線配置 | 折れ線ツール、複数点 | 折れ線要素が追加される |
| 閉じた折れ線 | 折れ線、closed=true | 始点と終点が結ばれて描画、選択判定される |
| 折れ線延長 | 開いた折れ線、Ctrl+クリックされた端点、新しい頂点列 | 既存折れ線の端点側に頂点が追加される |
| 折れ線延長から閉じる | 延長中の折れ線、既存折れ線の反対側端点 | 追加した線分を含む閉じた折れ線として確定される。反対側端点は重複頂点として追加しない |
| 折れ線を開く | 閉じた折れ線、closed=false、開く頂点 | 閉じ線分が解除され、開いた折れ線として扱われる。開く頂点が指定された場合は、その頂点と直前の頂点の間を開く |
| ベジェ曲線配置 | ベジェ曲線ツール、2点以上の通過点列 | 滑らかなベジェ曲線要素が追加される |
| ベジェ曲線延長 | ベジェ曲線、Ctrl+クリックされた端点、新しい通過点列 | 既存ベジェ曲線の端点側に通過点が追加される |
| 円弧配置 | 円弧ツール、外接矩形 | 長径と短径が同一の円弧要素が追加される |
| 円配置 | 円ツール、外接矩形 | 長径と短径が同一の円要素が追加される |
| 矢印付き線 | 線系要素、矢印形状 | 開始端点または終了端点に指定形状の矢印が設定される |
| コネクター付き直線 | 直線、端点が接続対象図形上 | 接続対象図形の ID が直線へ保存され、端点が接続対象図形の境界上に配置される |
| テキスト配置 | テキストツール、文字列 | テキスト要素が追加される |

### 7.10 テスト観点

- ツール別に描画内容が更新されること。
- 編集操作が Undo/Redo 履歴へ反映されること。

## 8. BL-003 選択編集

### 8.1 目的

現在ページ上の描画要素を選択し、選択済み描画要素を移動、サイズ変更、回転、削除、テキスト変更、または選択済みテキストの色とフォント変更を行う。

### 8.2 入力

| 項目 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| point | point | 条件付き | 選択または操作位置 |
| delta | point | 条件付き | 移動量 |
| rect | rect | 条件付き | サイズ変更後の外接矩形 |
| rotationDegrees | number | 条件付き | 描画要素の回転角。未設定時は 0 度 |
| vertexIndex | integer | 条件付き | 折れ線で変更する頂点インデックス |
| point | point | 条件付き | 折れ線頂点の変更後座標 |
| text | string | 条件付き | テキストオブジェクトの変更後テキスト |
| color | color | 条件付き | 選択済みテキストオブジェクトの変更後色 |
| font | font | 条件付き | 選択済みテキストオブジェクトの変更後フォント |

### 8.3 出力

成功時:

- 選択対象が更新される。
- 移動、サイズ変更または回転時は描画要素の座標または回転角が更新される。
- 折れ線頂点変形時は、対象頂点だけが更新される。
- テキスト変更時は描画要素の文字列が更新される。
- 選択済みテキストの色またはフォント変更時は描画要素の表示属性が更新される。
- 移動、サイズ変更、回転、テキスト変更、選択済みテキストの色またはフォント変更は Undo/Redo 履歴へ反映される。

失敗時:

- 対象がない場合は未選択状態にする、または操作を無視する。

### 8.4 処理ルール

- クリック位置に重なる描画要素を選択する。
- 複数の描画要素が重なる場合は、最前面の描画要素を選択する。
- ラバーバンド矩形に入った描画要素を複数選択できる。
- 選択済み描画要素の内側をドラッグした場合、その描画要素を移動する。
- 選択済み描画要素がある状態で矢印キーを押した場合、その描画要素を 1px 移動する。
- 複数選択済み描画要素の内側をドラッグした場合、選択済み描画要素をまとめて移動する。
- 接続先描画要素を移動、サイズ変更、回転、スケール、テキストサイズ変更、角丸変更した場合、接続済み直線の端点を再計算する。
- 選択済み描画要素の角ハンドルをドラッグした場合、その描画要素をサイズ変更する。
- 選択済み描画要素の回転ハンドルをドラッグした場合、その描画要素を回転する。複数選択またはグループでは、ドラッグ開始時の選択範囲中心と各要素の初期状態を固定して再計算する。
- 回転した矩形系描画要素のサイズ変更は、要素自身のローカル座標で計算する。
- 選択済み描画要素が折れ線の場合、端点と屈曲点の頂点ハンドルをドラッグして該当頂点だけを移動できる。
- 選択済み描画要素が開いた折れ線の場合、閉じた折れ線へ変更できる。
- 選択済み描画要素がベジェ曲線の場合、通過点をドラッグして曲線を変更できる。
- 選択済み描画要素が円弧の場合、角ハンドルをドラッグして開始角または終了角を変更できる。
- 選択済み描画要素が矩形、楕円、円の場合、辺ハンドルをドラッグしてその辺と直角方向のサイズを変更できる。
- 選択済み描画要素が直線、開いた折れ線、ベジェ曲線、円弧の場合、開始端点と終了端点の矢印形状を変更できる。
- 選択済み描画要素がある状態で Delete または Backspace が押された場合、その描画要素を削除する。
- 複数選択済み描画要素がある状態で Delete または Backspace が押された場合、選択済み描画要素をまとめて削除する。
- 選択済み描画要素がある状態で Copy を実行した場合、選択済み描画要素をコピー対象にする。
- コピー対象がある状態で Paste を実行した場合、コピー対象を現在ページへ複製し、複製した描画要素を選択状態にする。
- コピーまたは貼り付けで複製した描画要素には、コピー元とは異なる新しい永続 ID を付ける。
- 接続済み直線と接続先図形をまとめてペーストする場合、接続先 ID は複製後の図形 ID へ張り替える。接続先図形を含まない場合、その接続は解除する。
- 接続先描画要素を削除した場合、直線自体は残し、削除された接続先への接続だけを解除する。
- 接続済み直線の端点を手動で移動して図形外で離した場合、操作した端点の接続を解除する。図形上で離した場合は、その図形へ再接続する。
- 接続済み直線をリサイズした場合、操作した端点の接続を解除する。
- 選択済み描画要素がテキストの場合、文字列を変更できる。
- 選択済み描画要素がテキストの場合、色とフォントを変更できる。
- テキストは複数行文字列を保持できる。
- 描画、消しゴム、ページ移動、Undo/Redo、保存読み込み時は選択状態を解除する。
- 選択状態は保存対象に含めない。

## 15. BL-008 MCP 図反映

- 通常起動時の HTTP 接続は loopback と localhost 系 Origin に限定し、initialize 後の要求では
  session ID と交渉済み protocol version が一致することを要求する。
- 入力は反映モードと 1 から 500 件の描画要素である。
- 対応モードは、新規ページ、現在ページへの追加、現在ページの置換である。
- 対応要素は直線、折れ線、ベジェ、矩形、角丸矩形、楕円、円、円弧、テキストである。
- 入力要素の `id` は一時参照用として受け付け、反映時に新しい永続 ID へ置き換える。
- 直線要素は `startConnectionElementId` と `endConnectionElementId` で接続先要素を指定できる。新規ページと置換では同じ入力内の一時 ID、現在ページへの追加では同じ入力内の一時 ID または既存ページ上の永続 ID を接続先として扱う。
- 座標、矩形、点列、色、線、フォント、矢印、閉曲線、回転角を検証し、全要素が
  1920x1080 キャンバス内へ収まる場合だけ一括反映する。
- 一部だけを反映しない。成功した一括反映は文書全体の Undo スナップショット 1 件とする。
- 追加時は入力内の同一グループ関係を維持しつつ、既存グループ ID と衝突しない ID へ置き換える。
- 接続先 ID は反映後の永続 ID へ張り替える。接続先が存在しない場合、その端点の接続は解除する。
- 新規ページは現在ページの直後へ追加する。追加と置換は現在ページがロック中の場合に拒否する。
- MCP 変更後は画面状態を更新し、既存の保存処理を呼ぶ。保存形式には MCP 専用フィールドを追加しない。
- 状態取得と PNG 描画はモデルを変更しない。Undo は履歴がない場合に拒否する。

## 15A. BL-008A MCP 要素参照・更新・削除

- `whiteboard/elements/list` は現在ページ、または `pageIndex` で指定した既存ページの要素と永続 ID を返し、表示ページを変更しない。
- 画像要素の一覧では埋め込み画像データ本体を返さず、MIME type と画像データの有無を返す。
- `whiteboard/elements/update` は現在ページ上の 1 から 500 要素を永続 ID で一括更新する。
- `whiteboard/elements/delete` は現在ページ上の 1 から 500 要素を永続 ID で一括削除する。
- 状態取得と要素一覧は文書全体の `revision` を返す。更新・削除は `expectedRevision` を必須とし、
  現在値と一致しない要求を変更せずに拒否する。
- `whiteboard/elements/apply` は追加・更新・削除を合計 1 から 500 操作まで受け取り、全内容を
  検証してから 1 回の Undo 単位として一括反映する。`expectedRevision` が現在値と一致しない場合は拒否する。
- 統合変更の追加要素は要求内で一意な `clientId` を持ち、応答は `clientId` と採番済み永続 ID の
  対応を返す。更新と削除は現在ページの永続 ID を指定する。
- 更新で `id` と `type` は変更できない。画像要素は矩形、回転角、グループ ID だけを更新できる。
- 存在しない ID、重複 ID、不正な属性、キャンバス外の結果、未対応の接続先が一つでも含まれる場合は要求全体を拒否する。
- 更新と削除はページロック中に拒否し、成功した 1 呼び出しを 1 Undo とする。
- 接続先図形の更新後はコネクター端点を再計算する。接続先を削除した場合はコネクターを残し、失効した接続だけを解除する。
- 更新と削除は実行前に利用者の承認を得て、成功後は画面更新と通常の保存処理を行う。

## 16. BL-009 画像保存

### 16.1 入力

- 現在表示しているページ。
- 現在の選択状態。
- 出力形式。PNG または SVG。
- 背景。透明または白。既定値は透明。
- 保存先のファイルパス。

### 16.2 処理ルール

- 現在表示しているページだけを対象とする。
- 描画要素が選択されていない場合は、現在ページ内の全描画要素を囲むバウンディングボックスを切り抜き範囲とする。
- 描画要素が選択されている場合は、選択中の全描画要素を囲むバウンディングボックスを切り抜き範囲とする。
- 描画要素が選択されている場合は、選択中の描画要素だけを出力する。
- 現在ページに描画要素がない場合は処理を実行できない。
- 線幅、矢印、回転後形状などを含めて画像が欠けないように、描画範囲から必要な余白を計算して切り抜き範囲へ加える。
- PNG と SVG は同一の切り抜き範囲を使う。
- ズーム倍率とスクロール位置は出力結果に影響させない。
- PNG はキャンバス座標 1 単位を 1px として出力する。
- SVG は通常の描画要素をベクターとして出力し、取り込み画像だけを Base64 data URI の `<image>` として埋め込む。
- SVG の各描画要素には、保存 JSON と共通の永続 ID を付ける。
- 背景は透明を既定とし、白を指定した場合はキャンバス表示と同じ白で出力する。
- 選択枠、リサイズハンドル、回転ハンドル、ラバーバンドは出力しない。
- 編集中のテキストは確定してから処理し、作成途中の図形プレビューは出力しない。
- ページロック中でも処理できる。
- ファイル形式は保存ダイアログのフィルターまたはファイル名の拡張子で決定する。
- ファイル名に拡張子がない場合は、選択中の形式に応じて `.png` または `.svg` を自動付加する。
- 保存ダイアログのフィルターとファイル名の拡張子が異なる場合は、入力した拡張子を優先する。
- 既存ファイルの上書き確認は標準ファイルダイアログに従う。

### 16.3 状態変更ルール

- 画像保存によって文書、選択状態、Undo/Redo 履歴を変更しない。

### 16.4 エラー処理

- 現在ページに描画要素がない場合は、UI で画像保存操作を無効にして処理要求を発生させない。
- 画像保存に失敗した場合はエラーを返し、同じ入力条件で再試行できる状態を維持する。
- UI が画像保存設定ダイアログまたは標準ファイルダイアログのキャンセルを受けた場合は、画像保存処理を呼び出さない。

### 16.5 テスト観点

- 現在ページだけが対象になること。
- 未選択時と複数選択時に、それぞれの規則どおり切り抜き範囲を計算すること。
- 選択時は選択中の描画要素だけが出力されること。
- 空ページでは画像保存操作が無効になること。
- 線幅、矢印、回転後形状などが切り抜き範囲で欠けないこと。
- ズーム倍率とスクロール位置を変えても出力範囲と内容が変わらないこと。
- PNG がキャンバス座標 1 単位を 1px として出力されること。
- SVG では通常の描画要素がベクターで出力され、取り込み画像は `<image>` として埋め込まれ、各描画要素に保存 JSON と共通の永続 ID が付くこと。
- PNG と SVG の切り抜き範囲が同じであること。
- 透明背景が既定で、白背景も選べること。
- 編集補助表示と作成途中のプレビューが出力されないこと。
- ページロック中でも出力できること。
- 拡張子のないファイル名へ選択形式の拡張子が自動付加されること。
- フィルターと拡張子が異なる場合は入力した拡張子の形式で出力されること。
- 保存失敗時にエラーが返り、再試行できること。
- 画像保存後も文書、選択状態、Undo/Redo 履歴が変わらないこと。

## 17. BL-010 画像取り込み

### 17.1 入力

- 画像ファイルのパス、または OS クリップボード画像。
- 現在表示しているページ。
- ドラッグ＆ドロップの場合はキャンバス上のドロップ位置。

### 17.2 処理ルール

- 対応形式は PNG、JPEG、BMP、SVG とする。
- PNG、JPEG、BMP は画像として読み込み、SVG はベクター分解せず PNG 画像へ変換する。
- OS クリップボード画像は PNG 画像へ変換する。
- 画像要素の内部保存形式は PNG Base64 とし、`imageMimeType` は `image/png` とする。
- 画像要素は、ファイル選択と貼り付けでは表示中範囲の中央、ドラッグ＆ドロップではドロップ位置を基準に配置する。
- 画像がキャンバス内に収まらない場合は縦横比を保って縮小する。小さい画像は拡大しない。
- 画像要素は選択、移動、サイズ変更、回転、コピー、ペースト、グループ化、削除の対象にする。
- 画像要素は線幅、線種、塗り潰し、矢印、フォント、スタイルリセットの対象外にする。
- ページロック中は画像取り込みを実行できない。

### 17.3 状態変更ルール

- 画像取り込みに成功した場合、現在ページへ画像要素を追加し、Undo/Redo 履歴へ反映する。
- 画像取り込みに失敗した場合、文書、選択状態、Undo/Redo 履歴を変更しない。

### 17.4 エラー処理

- ファイルを読み込めない場合、または画像として解釈できない場合はエラーを返す。
- UI がファイル選択をキャンセルした場合は、画像取り込み処理を呼び出さない。
- クリップボードに画像がない場合、またはドロップ対象が対応画像でない場合は処理しない。

### 17.5 テスト観点

- PNG 画像を画像要素として取り込めること。
- SVG 画像を PNG 化した画像要素として取り込めること。
- OS クリップボード画像を画像要素として貼り付けられること。
- 対応画像ファイルをキャンバスへドラッグ＆ドロップできること。
- 画像要素が保存 JSON へ Base64 で保存され、読み込み後に復元されること。
- 画像要素が PNG/SVG 書き出しに含まれること。
- ページロック中は画像取り込みを実行できないこと。

## 描画データ交換

- 交換形式は UTF-8 JSON、拡張子 `.whiteboard`、ルートは
  `format: "WhiteboardApp.DrawingData"`、`formatVersion: 1`、`pages` とする。
  形式バージョンはアプリバージョンと独立させる。自動保存形式は変更しない。
- `pages` は既存のページ・描画要素の保存形式を用いる。操作設定、現在ページ番号、revision、
  nextElementId、選択状態、Undo/Redo 履歴は交換対象に含めない。
- 旧形式のルート `pages` 配列も受理する。旧 settings のズームはページ別値がない場合だけ補完する。
  それ以外の取り込み元操作設定は反映しない。
- JSON 構造、既知の要素型・線種・矢印、数値、色、PNG画像、ページ内 ID の重複と接続参照を検証する。
  参照先は同ページ内の接続可能な図形でなければならない。欠落 ID は許可し、取り込み先で採番する。
- 全体検証後、現在ページの直後へ挿入する。全要素の ID を新規採番し、ページごとに接続先を張り替える。
  グループ ID はページ内で有効なのでページ単位で維持し、要素の順序・座標・ロック・表示位置も維持する。
- 取り込み先の revision を 1 進め、取り込み全体を 1 Undo とする。取り込み元 revision は使用しない。
  Undo/Redo における既存の ID 非再利用と revision 単調増加を維持する。
- 追加後20ページ超過、現在ページロック、不正データは文書・選択・履歴を変更せず拒否する。
- 書き出しは `QSaveFile` による置き換え保存とし、書き込み・commit の結果を確認する。
