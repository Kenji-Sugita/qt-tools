# アプリ名 ビジネスレイヤー仕様書

## 1. 概要

本書は、対象アプリのビジネスレイヤー仕様を定義する。

## 2. アプリ種別

仕様化前ノート、UC仕様書、UI仕様書で整理したアプリ種別を記載する。
ビジネスレイヤー仕様では、種別に応じて UI に依存しない処理、検証、状態変化、入出力を定義する。

- 種別:
- 補足:

種別別の主な処理観点:

| 種別 | ビジネスレイヤーで重視する内容 |
| --- | --- |
| 入力・計算・結果表示アプリ | 入力検証、正規化、計算、結果生成 |
| データ管理アプリ | 登録、更新、削除、検索、状態変更 |
| ビューアアプリ | 読み込み、絞り込み、並べ替え、表示用データ生成 |
| エディタアプリ | 編集内容の検証、差分、保存、取り消し対象 |
| 変換ツール | 入力解析、変換、出力生成、変換失敗 |
| ゲーム / インタラクティブアプリ | 状態遷移、ルール判定、スコア、終了条件 |
| その他 | UIに依存しない中核処理 |
