# Laser Pointer 利用ガイド

Laser Pointer は、画面上にレーザー光点を重ねて表示する Qt Widgets アプリケーションです。プレゼンテーション、セミナー、画面共有中に、注目してほしい場所を視覚的に示すために使います。

このアプリの特徴は、一般的な「マウスカーソル追従」だけでなく、光点を左ドラッグで任意の場所に置けることです。必要に応じてマウスポインター追従、点滅、軌跡、虹色表示、波紋、プリセットなどを切り替えられます。

## 起動

ビルド済みの場合は、次のアプリケーションを起動します。

```text
build/LaserPointer.app
```

初回起動時は、赤色の標準レーザー、サイズ 96、透明度 100%、軌跡オフ、マウスポインター追従オフで表示されます。メニューはレーザーポインターの右クリック、または macOS のメニューバーアイコン / Windows のタスクトレイアイコンから開けます。メニューの上部には、初回だけおすすめプリセットの案内が表示されます。

## 基本操作

| 操作 | 内容 |
| --- | --- |
| 左ドラッグ | レーザーポインターを移動 |
| 左クリック | 白いリング状の波紋を表示 |
| マウスホイール | サイズ変更 |
| 右クリック | メニューを表示 |
| メニューバー / タスクトレイアイコン | メニューを表示。macOS / Windows ではポインターの表示 / 非表示も可能 |
| Esc / Q | 終了 |

左ドラッグで移動すると、ブリンク中でも移動中は一時的に不透明表示になります。軌跡がオンの場合は、移動中に軌跡が表示されます。

## メニュー構成

メニューは、設定が多くても見通しを保てるように分類されています。

| メニュー | 内容 |
| --- | --- |
| Status | 現在の色、形状、透明度、軌跡、追従状態の要約 |
| Show Pointer / Hide Pointer | macOS / Windows のメニューバー / タスクトレイメニューでポインター表示を切り替え |
| Display | 表示、色、形状、点滅、透明度、自動フェードなど |
| Motion | マウスポインター追従、滑らか追従、画面内制限 |
| Trail | 軌跡のオン/オフ、軌跡スタイル、表示時間 |
| Preset | 用途別プリセット |
| Reset | 表示、移動、軌跡、全体のリセット |
| Help | 操作とショートカットの一覧 |
| Quit | 終了 |

メニューと Help は、システム言語が日本語の場合は日本語で表示されます。それ以外の場合は英語で表示されます。

# Display

Display メニューでは、レーザーポインター本体の見た目を調整します。

## サイズ

`Larger` と `Smaller` でサイズを変更します。マウスホイールでも変更できます。

| 項目 | 内容 |
| --- | --- |
| Larger | 大きくする |
| Smaller | 小さくする |
| マウスホイール | 細かくサイズ変更 |

サイズの範囲は 24 から 260 です。ただし、`Space` による一時拡大中は表示だけ一時的に大きくなります。

## 透明度

`Opacity` サブメニューで透明度を直接選択できます。

| 値 | 用途 |
| --- | --- |
| 25% | かなり控えめ |
| 50% | 背景を邪魔しにくい |
| 75% | 見やすさと控えめさの中間 |
| 100% | 最も目立つ |

ショートカットでは `O` で濃く、`P` で薄くできます。

## 形状

`Shape` サブメニューで形状を直接選択できます。

| 形状 | 内容 |
| --- | --- |
| Glow | 標準の光点 |
| Ring | 中央にリングを重ねた光点 |
| Cross | 十字を重ねた光点 |
| Star | 星形を重ねた光点 |

`S` キーで形状を順番に切り替えることもできます。

## 色と虹色

`Color...` で任意の色を選べます。`Rainbow` をオンにすると虹色表示になります。

虹色のときは、色変更はできません。`Color...` は無効になり、`C` キーでも色選択ダイアログは開きません。

## 点滅

`Blink` で点滅をオン/オフできます。点滅は透明度アニメーションで滑らかに変化します。

`Blink Interval` サブメニューでは、点滅間隔を直接選択できます。

| 間隔 | 内容 |
| --- | --- |
| 0.2 s | 速い |
| 0.5 s | やや速い |
| 0.9 s | 標準 |
| 1.2 s | ゆっくり |
| 1.6 s | かなりゆっくり |

ショートカットでは `,` で遅く、`.` で速くできます。

## 波紋

左クリックすると、中心から白いリング状の波紋が短く表示されます。レーザー本体が通常色でも虹色でも、波紋は常に白です。

## 一時拡大

`Space` を押している間だけ、一時的にレーザーポインターが大きく表示されます。キーを離すと元のサイズに戻ります。設定値として保存されるサイズは変わりません。

## 自動フェード

`Auto Fade` をオンにすると、一定時間マウスが動かない場合にレーザーポインターが薄くなります。マウスを動かすと元の濃さに戻ります。

## Hold H to Show

`Hold H to Show` をオンにすると、`H` キーを押している間だけレーザーポインターが表示されます。必要な瞬間だけ表示したい場合に使います。

# Motion

Motion メニューでは、レーザーポインターの動き方を調整します。

## Follow Cursor

`Follow Cursor` をオンにすると、レーザーポインターの中心がマウスポインター位置に追従します。

追従中は左ドラッグによる移動は開始されません。追従をオフにすると、再び左ドラッグで任意位置に置けます。

## Smooth Follow

`Smooth Follow` をオンにすると、マウスポインターに少し遅れて滑らかについていきます。

この項目は `Follow Cursor` がオンのときに有効です。

## Keep On Screen

`Keep On Screen` をオンにすると、レーザーポインターが画面外に出すぎないように位置を制限します。

# Trail

Trail メニューでは、移動時の軌跡を調整します。デフォルトでは軌跡はオフです。

## 軌跡のオン/オフ

`Trail` で軌跡をオン/オフします。オフにした瞬間、残っている軌跡は消去されます。

## 軌跡スタイル

`Trail Style` サブメニューで軌跡の見た目を選択できます。

| スタイル | 内容 |
| --- | --- |
| Glow | フェードする光点 |
| Dots | 軽量な点 |

`Y` キーで軌跡スタイルを順番に切り替えることもできます。

## 軌跡表示時間

`Trail Duration` サブメニューで軌跡が残る時間を選択できます。

| 時間 |
| --- |
| 0.5 s |
| 1.0 s |
| 1.5 s |
| 2.0 s |
| 2.5 s |
| 3.0 s |
| 4.0 s |
| 5.0 s |
| 6.0 s |

ショートカットでは `[` で短く、`]` で長くできます。

## 負荷を抑える制限

軌跡オンで大サイズ、または虹色と滑らか追従を組み合わせた場合、軌跡表示時間は最大 3.0 秒に制限されます。実機での重さを抑えるための制限です。

# Preset

Preset メニューでは、用途別の設定をまとめて適用できます。

| プリセット | 用途 |
| --- | --- |
| Standard | 標準の赤レーザー |
| Noticeable | 目立つ青系グロー |
| Follow | マウスポインター追従向け |
| Subtle | 控えめな表示 |
| Large Seminar | セミナーや大画面向け |

プリセットを適用しても、後から個別の項目を変更できます。

# Reset

Reset メニューでは、設定を部分的に戻せます。

| 項目 | 戻す内容 |
| --- | --- |
| Reset Display | 色、虹色、透明度、形状、サイズ、自動フェード、Hold H to Show |
| Reset Motion | 追従、滑らか追従、画面内制限 |
| Reset Trail | 軌跡オン/オフ、軌跡スタイル、軌跡表示時間 |
| Reset All | すべての設定 |

`R` キーは Reset All と同じです。

# ショートカット一覧

| キー | 内容 |
| --- | --- |
| B | 点滅 |
| A | 自動フェード |
| E | 画面内制限 |
| F | マウスポインター追従 |
| G | 滑らか追従 |
| M | Hold H to Show |
| H | Hold H to Show が有効なとき、押している間だけ表示 |
| O / P | 濃く / 薄く |
| S | 形状切り替え |
| Space | 押している間だけ一時拡大 |
| V | 虹色 |
| C | 色選択 |
| T | 軌跡 |
| Y | 軌跡スタイル切り替え |
| R | すべてリセット |
| + / - | 大きく / 小さく |
| , / . | 点滅を遅く / 速く |
| [ / ] | 軌跡を短く / 長く |
| Esc / Q | 終了 |

# 設定の保存

次の設定は `QSettings` に保存され、次回起動時に復元されます。

- 色
- 虹色状態
- サイズ
- 透明度
- 形状
- 点滅状態
- ブリンク間隔
- マウスポインター追従
- 滑らか追従
- 画面内制限
- 自動フェード
- Hold H to Show
- 軌跡状態
- 軌跡スタイル
- 軌跡表示時間

位置は保存されません。起動時は従来どおり画面中央に表示されます。

# ヘルプ

`Help` サブメニューには、操作とショートカットの一覧が表示されます。ヘルプは別ウィンドウではなく、メニュー内のサブメニューとして表示されます。

ヘルプ項目は選択対象ではなく、説明表示用です。

# トラブルシュート

## 軌跡が表示されない

`Trail` がオンになっているか確認してください。デフォルトではオフです。

## 色を変更できない

`Rainbow` がオンのときは色変更できません。`Rainbow` をオフにしてから `Color...` を選択してください。

## 動作が重い

軌跡をオフにする、軌跡スタイルを Dots にする、軌跡表示時間を短くする、サイズを小さくする、滑らか追従をオフにする、の順で試してください。

## ポインターをドラッグできない

`Follow Cursor` がオンの場合、左ドラッグでの移動は開始されません。任意位置に置きたい場合は `Follow Cursor` をオフにしてください。

## ポインターが薄い

`Opacity`、`Auto Fade`、`Hold H to Show` の設定を確認してください。
