# 09 .ui 編集時の案内

## このレッスンで学ぶこと

`.ui` だけを Designer で編集した場合に、icpp が「評価する C++ ファイルがない」ことを案内する動きを学びます。

このレッスンは成功させるための手順ではなく、つまずいたときのメッセージを理解するための練習です。

## 事前確認

このディレクトリには `form.ui` だけがあります。

```text
form.ui
```

## 操作

```text
icpp[qtcling]> .designer form.ui
```

## 期待される結果

次のような案内が出ます。

```text
警告: Qt 生成物が必要な可能性があります。.gen で moc/uic/rcc を再生成して再起動してください。
評価する C++ ファイルまたは編集バッファがありません。.e <file.cpp> または .add <file.cpp> の後に .gen を実行してください。
```

## なぜそうするか

`.designer` は `.ui` を編集するためのコマンドで、C++ の評価対象は作りません。`.ui` は `uic` の入力として使い、生成された `ui_form.h` を `.cpp` から include します。

## よくある失敗

- `.ui` を Designer で編集すれば、そのまま実行できると思ってしまう
- `.gen` だけ実行して、評価対象の `.cpp` がない
- `No files or edit buffer to run.` のような汎用エラーだけでは次に何をすればよいか分からない

## 発展

`widget.cpp` を追加し、`.add widget.cpp`、`.gen` の順に進めると `02 .ui Only` の形になります。
