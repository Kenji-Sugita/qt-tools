# 1. 概要

`now` は、現在の日付や時刻を手早く表示する小さなコマンドラインツールです。

既定では時刻を `HH:MM` 形式で表示します。日付のみ、秒を含む時刻、ISO 8601 形式、Unix 秒、ファイル名に使いやすい形式にも切り替えられます。UTC や指定したタイムゾーンで表示することもでき、`+N` または `-N` によって日付を前後にずらせます。

# 2. 動作環境と準備

`now` は Python 3 で動作します。配布ファイルをダウンロードしたら、実行権限を付けて使います。

```text
$ chmod +x now
$ ./now
```

任意のディレクトリーから呼び出す場合は、`PATH` の通った場所へ置きます。

```text
$ cp now ~/bin/
$ chmod +x ~/bin/now
```

Python 3 が実行できる環境では、直接 Python から起動することもできます。

```text
$ python3 ./now
```

# 3. 基本的な使い方

引数を付けない場合は、ローカルタイムゾーンの現在時刻を分単位で表示します。

```text
$ now
19:30
```

バージョンは次のように確認できます。

```text
$ now --version
now 1.2.0
```

使い方の一覧は `--help` で表示します。

```text
$ now --help
```

# 4. 表示形式

表示形式は一度に一つだけ指定できます。

## 4.1 秒を含む時刻

```text
$ now --time
19:30:45
```

`--time` は時、分、秒を `HH:MM:SS` 形式で表示します。

## 4.2 日付

```text
$ now --date
2026-09-01
```

`--date` は日付だけを `YYYY-MM-DD` 形式で表示します。

## 4.3 ISO 8601 形式

```text
$ now --iso
2026-09-01T19:30:45+09:00
```

`--iso` はタイムゾーンを含む ISO 8601 形式で表示します。`--utc` と組み合わせた場合は、末尾を `Z` として表示します。

```text
$ now --iso --utc
2026-09-01T10:30:45Z
```

## 4.4 Unix 秒

```text
$ now --unix
1788268245
```

`--unix` は Unix epoch からの秒数を表示します。

## 4.5 ファイル名向け形式

```text
$ now --filename
20260901-193045
```

`--filename` は、ファイル名に使いやすい `YYYYMMDD-HHMMSS` 形式で表示します。

## 4.6 任意の形式

```text
$ now --format '%Y/%m/%d %H:%M'
2026/09/01 19:30
```

`-f FORMAT` または `--format FORMAT` で、Python の `strftime` 形式を指定できます。

# 5. 日付の前後指定

先頭に `+N` または `-N` を指定すると、現在日付から N 日後または N 日前の日時を表示します。

```text
$ now +1 --date
2026-09-02

$ now -7 --date
2026-08-25
```

日付の前後指定は一度だけ指定できます。

# 6. タイムゾーン

`--utc` を付けると UTC で表示します。

```text
$ now --time --utc
10:30:45
```

`--tz ZONE` を付けると、IANA タイムゾーン名で指定した地域の日時を表示します。

```text
$ now --time --tz Asia/Tokyo
19:30:45

$ now --date --tz America/New_York
2026-09-01
```

`Asia/Tokyo`、`JST`、`UTC`、`GMT` も使用できます。`--utc` と `--tz` は同時に指定できません。

# 7. 利用上の注意

表示形式のオプションは一つだけ指定してください。たとえば `--date --iso` のように複数指定するとエラーになります。

`--tz` には有効なタイムゾーン名を指定してください。環境によっては、追加のタイムゾーンデータが必要になる場合があります。
