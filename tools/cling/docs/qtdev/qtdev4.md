# Cling を使った Qt 単体テスト支援サンプル 20案

承知しました。
では、**Cling を使った Qt 単体テスト支援サンプル 20案** を、実際に題材として使いやすい形で整理します。

単なる列挙ではなく、各案について

* 何を検証するか
* どの種類の単体テストにつながるか
* Cling を使う意味は何か

が分かるようにします。

---

# 7. 次に具体化するとよいもの

この先に進めるなら、実用性が高いのは次のどちらかです。

1. **この20案を、Cling でそのまま試せる最小コード断片付きにする**
2. **この20案のうち特に重要な10案を、Qt Test の正式テスト雛形まで含めて示す**

特に価値が高いのは、
**`deleteLater` / `QTimer` / `QSignalSpy` / `QAbstractListModel` / `QML binding`** の5系統です。

必要でしたら次に、
**この20案の中から重要な10案を選び、Cling 実験コードと Qt Test 化の対応表** を作成します。
