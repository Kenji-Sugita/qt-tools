# ターゲット層メモ

## 結論

この製品の初期ターゲットは、単に「ニッチな開発者」ではなく、
「探索的に学ぶ人」と「探索的に作る人」の交差点にいる層である。

一般的な Qt 開発者全体を広く狙うよりも、次のような人たちに焦点を当てた方がよい。

- Qt を試しながら学びたい C++ 初学者
- Qt を教える教育者、講師、教材作成者
- Qt GUI を対話的に実験したい探索型の開発者

## この製品が提供する中心価値

この製品の価値は、一般的な GUI 開発環境の置き換えではなく、次の 3 点にある。

- ビルドせずにその場で試せる
- GUI を出したまま挙動を変えられる
- サンプル、REPL、観察を往復できる

したがって、ターゲットは「Qt 開発者」全体ではなく、
「探索的に試したい人」「対話的に理解したい人」である。

## 向いている対象作業

この製品は、アプリケーション全体を動かす用途ではなく、部品単位の試行と確認を速くする用途に向く。

- ウィジェット開発
- ウィジェットの UI 調整
- signal/slot の試行
- property の確認と変更
- 小さな再現コードの作成
- 学習用の試行
- サンプルコード作成

特に、単体のウィジェットを表示して挙動を変えながら確認する作業と相性がよい。

## 向いていない対象作業

次のような用途は初期段階では主対象にしない方がよい。

- アプリケーション全体の実行
- 大規模な統合確認
- 配布前提の最終確認
- 複数画面や多数の依存関係をまたぐ動作確認

要するに、「アプリを動かす道具」ではなく、「部品を試す道具」として位置づけるのが自然である。

## 主要ペルソナ

### 1. Qt を学んでいる C++ 初学者

特徴:

- Qt と C++ の両方、またはいずれかに不慣れ
- 通常の `編集 -> ビルド -> 実行 -> 修正` サイクルを重く感じやすい
- 小さく試しながら理解したい

刺さる価値:

- サンプルをその場で動かせる
- 少し変更してすぐ結果を見られる
- GUI を見ながら `QObject` や property の概念を理解しやすい

### 2. Qt を教える教育者、講師、教材作成者

特徴:

- 概念を段階的に見せたい
- 静的なコード例だけでなく、その場で動く教材を求める
- 学習者がつまずくポイントを小さな実験で見せたい

刺さる価値:

- サンプル、説明、実行を一体化しやすい
- 1 行ずつ試す、少し変える、結果を見る、を教材化しやすい
- ドキュメントとサンプルを育てるほど製品価値が上がる

### 3. Qt GUI を対話的に実験したい探索型の開発者

特徴:

- API や widget の挙動を素早く確かめたい
- 小さな再現や仮説検証をすぐ行いたい
- 完成品よりも実験速度を重視する場面がある
- ウィジェット単位で見た目や振る舞いを調整したい

刺さる価値:

- ビルドなしでその場で試せる
- GUI を出したまま挙動を変えられる
- signal/slot、property、widget の状態を観察しながら試せる
- ウィジェットの UI 調整を短い手順で繰り返せる

## 初期採用者になりやすい層

次の層は人数は多くないが、初期の強い利用者になりやすい。

- デバッグ、試作、再現実験を素早く回したい Qt 開発者
- Cling や REPL 的な作業に価値を感じる技術者
- ライブラリーや framework の挙動をその場で調べたい人

この層は製品の意図を理解しやすいが、人数はかなり限られる。
そのため、製品メッセージの中心ではなく、初期採用者として意識するのがよい。

## 優先度が低い層

次の層を初期から広く狙うと、価値がぼやけやすい。

- 一般的な業務 Qt 開発者全体
- 完成した IDE 体験を最初から強く期待する人
- 大規模アプリ設計や保守を主眼に置く人
- REPL や対話実験に興味が薄い人

これらの層に合わせすぎると、製品の強みである「探索」「対話」「学習」の軸が弱くなる。

## ターゲット整理

### コアターゲット

- Qt を試しながら学びたい C++ 初学者
- Qt を教える教育者
- Qt GUI を対話的に実験したい探索型の開発者

### 初期採用者

- デバッグ、試作、再現実験を素早く回したい Qt 開発者
- Cling や REPL 的な作業に価値を感じるニッチな技術者

## 外向きメッセージへの含意

外向きの説明では、「ニッチな開発者向け」と言うより、どの痛みを減らすかで表現した方がよい。

表現例:

- Qt を試しながら学べる対話環境
- Qt GUI を動かしたまま実験できる CLI
- サンプルと REPL で Qt と C++ を理解しやすくするツール

## まとめ

この製品は、広い意味での一般開発者向けツールというより、
探索的に学ぶ人と探索的に作る人に強く刺さる道具である。

したがって初期の戦略としては、

1. 学習
2. 実験
3. 探索的な試作

を中心価値として据えるのが自然である。
