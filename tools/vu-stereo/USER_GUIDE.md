# 1. 概要

`VuStereo` は、macOS で再生中のシステム音声を左右 2 チャンネルで表示する、デスクトップ用のステレオ VU メーターです。

Music などで音楽を再生しているときに、デスクトップ上へアナログ VU メーター風の表示を置くことを目的にしています。

このアプリは、音声レベルを厳密に測定する計器ではありません。オーディオ機器や VU メーターの見た目が好きな人が、音楽再生中に針の動きを眺めて楽しむためのアクセサリです。

そのため、計器としての正確性よりも、自然で気持ちよく見える針の動きと見栄えを優先しています。機能も、日常的に使うための最低限に絞っています。

主な特徴は次の通りです。

- 左右 2 つの VU メーター表示
- macOS のシステム音声レベルのモニター
- フレームレスで背景が透過するウィンドウ
- ドラッグによるウィンドウ移動
- ウィンドウ位置の保存
- 常に前面表示の切り替え
- 円弧目盛りと直線目盛りの切り替え
- ピークホールド表示
- 入力レベル、針の太さ、支点表示の調整
- 日本語と英語の表示切り替え

`VuStereo` は音量を変更するアプリではありません。音声を録音したり保存したりすることもありません。再生中の音声レベルを視覚的に楽しく表示するための小さな常駐ツールです。

# 2. 動作環境

本アプリは Qt 6 Widgets を使った macOS 向けアプリケーションです。

音声の取得には macOS の ScreenCaptureKit を使用します。そのため、実行には次の環境が必要です。

- macOS 13 以降
- 画面収録権限
- 安定したコード署名

ソースからビルドする場合は、少なくとも次が必要です。

- CMake
- C++17 対応コンパイラ
- Qt 6
- Qt Widgets
- Qt Svg
- Qt LinguistTools

# 3. インストール

配布された `VuStereo.dmg` を使う場合は、次の手順でインストールします。

1. `VuStereo.dmg` をダブルクリックして開く
2. 表示された `VuStereo.app` を `アプリケーション` フォルダへドラッグしてコピーする
3. コピーが完了したら、Finder のサイドバーまたはデスクトップから `VuStereo` のディスクイメージを取り出す
4. `アプリケーション` フォルダ内の `VuStereo.app` を Finder から起動する

初回起動時は、macOS の画面収録権限を許可する必要があります。権限を許可した後は、`VuStereo` を完全に終了してから再起動してください。

`VuStereo.dmg` から起動することもできますが、通常は `アプリケーション` フォルダへコピーしてから使います。

# 4. 起動

ビルド済みのアプリを使う場合は、`VuStereo.app` を Finder から起動します。

ソースからビルドする場合の一例です。

```bash
cmake -S . -B build
cmake --build build
open build/VuStereo.app
```

このアプリは画面収録権限に依存するため、開発ビルドでも `.app` として Finder から起動する運用を基本にします。

# 5. 初回起動と画面収録権限

初回起動時、macOS から画面収録権限を求められることがあります。

画面収録権限を許可する手順は次の通りです。

1. `VuStereo.app` を Finder から起動する
2. 権限ダイアログが表示されたら、システム設定を開く
3. `プライバシーとセキュリティ` の `画面収録` を開く
4. 一覧の `VuStereo` を ON にする
5. `VuStereo` を完全に終了する
6. Finder から `VuStereo.app` を再起動する

許可した直後は、アプリを再起動するまで音声モニターが有効にならないことがあります。

コード署名や配布時の注意点は `SIGNING.md` を参照してください。

# 6. 音声入力方式

`VuStereo` は、マイク入力やオーディオインターフェースの入力を直接開くのではなく、macOS の ScreenCaptureKit を使ってシステム音声をモニターします。

この方式では、Music などで再生している音声を macOS 側から取得し、左右チャンネルのレベルを dBFS として計算します。計算した値だけを VU メーター表示へ渡します。

重要な点は次の通りです。

- 音声入力デバイスを選択する機能はありません
- 特定のアプリだけを選択してモニターする機能はありません
- システム音声のサンプルはレベル計算にだけ使います
- 音声データを録音、保存、送信しません

macOS では ScreenCaptureKit による音声取得にも画面収録権限が必要です。そのため、初回起動時や署名を変更した後に、画面収録権限の許可を求められることがあります。

アプリ内でも次のメニューから同じ説明を確認できます。

```text
VuStereo > 音声入力とプライバシー...
```

# 7. 画面の見方

起動すると、左右 2 つの VU メーターが表示されます。

- `L`: 左チャンネル
- `R`: 右チャンネル
- 黒い針: 現在の音声レベル
- 赤い針: ピークホールド表示
- 下部の数値: 現在の左右レベル

下部の数値は dBFS 表示です。たとえば次のように表示されます。

```text
L -30.9 dBFS   R -30.9 dBFS
```

無音に近いほど値は小さくなり、最大に近いほど 0 dBFS に近づきます。

# 8. 基本操作

日常的な操作は次の通りです。

```text
ドラッグ: ウィンドウ移動
アプリケーションメニュー > 設定...: 設定を開く
アプリケーションメニュー > 音声入力とプライバシー...: 音声入力方式と権限説明を表示
アプリケーションメニュー > 音声モニターを再起動: 音声モニターを再起動
通常の macOS 操作: アプリ終了
```

ウィンドウはタイトルバーを持たないため、台座部分をそのままドラッグして移動します。

ウィンドウ位置は保存され、次回起動時に復元されます。

# 9. 設定

設定は macOS のアプリケーションメニューから開きます。

```text
VuStereo > 設定...
```

設定は変更するとすぐに表示へ反映され、`QSettings` に保存されます。

## 9.1 入力レベル

入力レベルを dB 単位で補正します。

設定範囲は `-24 dB` から `+24 dB` です。

音楽を再生したときに針が動きすぎる場合は小さくし、動きが小さい場合は大きくします。実際の再生環境に合わせて調整してください。

## 9.2 針の太さ

針の太さを変更します。

設定範囲は `1` から `30` です。既定値は `6` です。

## 9.3 目盛り

メーター画像と針の動きを切り替えます。

- `円弧`: 円弧状の目盛りを使う表示
- `直線`: 直線状の目盛りを使う表示

`円弧` では針が支点を中心に回転します。`直線` では垂直な針が左右に移動します。

## 9.4 言語

表示言語を切り替えます。

- `システム`: macOS の言語設定に従う
- `英語`: 英語
- `日本語`: 日本語

変更は実行中の画面へ反映されます。

## 9.5 支点の黒丸を表示

円弧表示で、針の支点にある黒丸を表示するかどうかを切り替えます。

OFF にすると黒丸は表示されません。針そのものの動きは変わりません。

## 9.6 針の支点を下げる

円弧表示で、針の支点を下げるかどうかを切り替えます。

既定では ON です。ON のときは本物のメーター針に近い見た目になるよう、支点をメーター画像の下側へ置き、針の下部は黄色い領域内に収まるように描画します。

OFF にすると、背景画像の黒丸付近を支点にした表示になります。

## 9.7 ピークホールドを表示

ピークホールド針を表示するかどうかを切り替えます。

既定では OFF です。ON にすると、現在の針とは別に赤いピークホールド針が表示されます。

## 9.8 常に前面に表示

`VuStereo` を他のウィンドウより前面に表示するかどうかを切り替えます。

ON にすると、音楽再生中や他の作業中でもメーターが隠れにくくなります。OFF にすると通常のウィンドウと同じように、他のウィンドウの背面へ移動します。

# 10. メーターの動き

内部では、音声レベルを dBFS として扱います。

`setValue()` に渡される値の想定範囲は、無音側が `-60 dBFS`、最大側が `0 dBFS` です。範囲外の値は表示用にクリップされます。

VU 目盛りへの変換は、次のような使い方を想定した近似です。

- `-60 dBFS` 付近: 左端
- `-18 dBFS` 付近: `0` 目盛り
- `-9 dBFS` 以上: `+3` 目盛り付近

大きい音量では `+3` で止まるため、クリップしたような表示になります。実際の再生環境で自然に見えるように、`入力レベル` で調整してください。

# 11. 円弧目盛りと直線目盛り

`VuStereo` には 2 種類の背景画像があります。

- `images/vu-background.svg`
- `images/vu-linear-background.svg`

`円弧` は `vu-background.svg` を使います。目盛りは背景 SVG に合わせて補間され、針は支点を中心に回転します。

`直線` は `vu-linear-background.svg` を使います。目盛りが直線なので、針は垂直のまま左右に移動します。

どちらも同じ音声レベルを表示しますが、見た目と針の動きが異なります。

# 12. 設定の保存

設定は `QSettings` に保存されます。

保存している主なキーは次の通りです。

- `audio/inputLevelDb`
- `meter/needleWidth`
- `meter/pivotVisible`
- `meter/needlePivotLowered`
- `meter/peakHoldEnabled`
- `meter/scaleStyle`
- `window/alwaysOnTop`
- `window/position`
- `ui/language`

次回起動時には、これらの設定が復元されます。

ウィンドウ位置も保存されます。次回起動時は、前回移動した位置へ復元されます。

# 13. プライバシーポリシー

`VuStereo` は、音声を録音、保存、送信しません。

ScreenCaptureKit から取得した音声サンプルは、左右チャンネルの dBFS レベルを計算するためだけに使い、計算後に保持しません。

詳しくは `PRIVACY.md` を参照してください。

# 14. 署名と配布

macOS の画面収録権限は、アプリの bundle identifier とコード署名に依存します。

このため、`VuStereo` では開発ビルドでも安定したローカルコード署名証明書で署名する運用にしています。

署名、`macdeployqt`、`.zip`、`.dmg` に関する具体的な手順は `SIGNING.md` を参照してください。

重要な点は次の通りです。

- `macdeployqt` した後に `.app` を署名する
- `.zip` や `.dmg` にする前に `.app` を署名する
- `.app` の中身を変更したら再署名する
- 他の Mac では、その Mac で画面収録権限を許可する

# 15. トラブルシューティング

## 15.1 針が動かない

次を確認してください。

- Music などで実際に音が鳴っているか
- macOS の画面収録権限で `VuStereo` が ON になっているか
- 権限を変更した後に `VuStereo` を完全に終了して再起動したか
- `音声モニターを再起動` を実行して変化があるか
- `.app` が正しく署名されているか

## 15.2 画面収録を許可しても効かない

画面収録権限は、同じアプリ名だけでなく、bundle identifier とコード署名にも関係します。

ビルドし直した後に権限が効かない場合は、`SIGNING.md` の手順に従って署名状態を確認してください。

## 15.3 アプリを開けない

Finder から「破損しているか不完全である可能性がある」と表示される場合は、ビルド途中の `.app` や署名が壊れた `.app` を起動している可能性があります。

クリーンビルド後、正しく署名された `.app` を起動してください。

## 15.4 表示言語が変わらない

設定の `言語` を確認してください。

`システム` の場合は macOS の言語設定に従います。すぐに切り替えたい場合は、`英語` または `日本語` を選んでください。

# 16. まとめ

`VuStereo` は、macOS で再生中の音楽を左右 2 チャンネルの VU メーターとして眺めるための小さなアプリです。

正確な測定器ではなく、オーディオ機器らしい見た目と針の動きを楽しむためのデスクトップアクセサリとして使うことを想定しています。

実用上は、まず画面収録権限を許可し、音楽を再生しながら `入力レベル` を調整してください。その後は、好みに応じて目盛り、針の太さ、支点表示、ピークホールド、表示言語を変更して使います。
