# 1. はじめに

`SeminarTimer` は、セミナー、ハンズオン、演習、休憩時間の進行管理に使うデスクトップ用タイマーです。

一般的な多機能タイマーではなく、**画面上に常駐して残り時間を見やすく示すこと** に重点を置いています。

主な特徴は次の通りです。

- タイトルバーのないコンパクトな常時前面表示ウィンドウ
- 円形リングによる残り時間の視覚表示
- `5 / 10 / 20 / 30` 分のプリセット切り替え
- `SET` による任意時間設定
- `BREAK` モード切り替え
- `START` / `PAUSE` / `RESET` のシンプルな操作
- 残り 10 秒時点と終了時の通知音

# 2. 動作環境

本アプリは Qt 6 Widgets を使ったデスクトップアプリケーションです。

配布物は macOS 向けアプリケーションを想定しています。

ソースからビルドする場合は、少なくとも次が必要です。

- CMake 3.21 以上
- C++17 対応コンパイラ
- Qt 6.5 以上

# 3. インストール

## 3.1 DMG からインストールする場合

配布された `SeminarTimer.dmg` を開き、`SeminarTimer.app` を `Applications` フォルダへコピーしてください。

## 3.2 ZIP からソース一式を展開する場合

配布された `.zip` ファイルには、ビルド済みの `.app` ではなく、ビルドに必要なソース一式が含まれています。

展開後の主な内容は次の通りです。

- `main.cpp`
- `CMakeLists.txt`
- `Info.plist.in`
- `SeminarTimer.icns`
- `assets/`
- `USER_GUIDE.md`

ZIP 配布物を利用する場合は、まず展開し、そのディレクトリでビルドを行ってください。

1. `seminartimer-release-YYYYMMDD.zip` を展開する
2. 展開してできたフォルダへ移動する
3. CMake と Qt が使える環境でビルドする
4. 生成されたアプリケーションを起動する

この ZIP は、ソース配布やビルド用ファイルの受け渡しに使用します。

## 3.3 ソースからビルドする場合

プロジェクトディレクトリで次を実行します。

```bash
cmake -S . -B build
cmake --build build
```

生成されたアプリを起動してください。

# 4. 起動

`SeminarTimer.app` を起動すると、タイマーウィンドウが画面右上付近に表示されます。

ウィンドウは次の性質を持ちます。

- 常に前面に表示される
- タイトルバーは表示されない
- マウスドラッグで好きな位置へ移動できる

# 5. 画面の見方

タイマー画面には次の情報が表示されます。

- 上部タイトル: `SEMINAR TIMER`
- 中央: 残り時間
- 中央下: 状態表示
- 外周リング: 残り時間の進み具合
- 下部ボタン: `START` または `PAUSE`、`RESET`
- 上部チップ: プリセット時間、`SET`、`BREAK`

状態表示は状況に応じて切り替わります。

- `READY`: 停止中
- `IN PRACTICE`: 通常モードで計測中
- `ON BREAK`: BREAK モードで計測中
- `WRAP UP`: 残り 10 秒以下

`BREAK` モードが有効なときは、画面内に `BREAK MODE` バッジが表示されます。

# 6. 基本操作

## 6.1 開始と一時停止

`START` を押すとカウントダウンを開始します。

動作中は同じ位置のボタンが `PAUSE` に変わり、押すと一時停止します。

## 6.2 リセット

`RESET` を押すと、現在選択されている時間に戻ります。

- プリセット選択中であれば、そのプリセット時間に戻る
- `SET` で任意時間を設定したあとであれば、その設定値に戻る

## 6.3 ウィンドウ移動

ボタンやチップ以外の領域をドラッグすると、ウィンドウを移動できます。

# 7. 時間の設定

## 7.1 プリセット時間を使う

画面上部のチップから、次の時間をすぐに選べます。

- `5 min`
- `10 min`
- `20 min`
- `30 min`

プリセットを選ぶと、その時間が新しい基準時間になります。

## 7.2 任意時間を設定する

`SET` を押すと時間設定ダイアログが開きます。

設定方法は次の通りです。

1. `-` または `+` ボタンで分数を変更する
2. `OK` を押して確定する

設定可能な範囲は **1 分から 180 分まで** です。

確定後は、その値が現在の基準時間になり、`RESET` を押したときもその値へ戻ります。

`Cancel` を押すと変更せずに閉じます。

# 8. BREAK モード

`BREAK` を押すと BREAK モードのオンとオフを切り替えられます。

BREAK モードはタイマーの長さそのものを変える機能ではなく、**表示上のモード切り替え** です。

主な変化は次の通りです。

- 配色が休憩向けの色味に変わる
- 計測中の状態表示が `ON BREAK` になる
- `BREAK MODE` バッジが表示される

# 9. 通知と表示変化

残り時間が少なくなると、表示と通知音が変化します。

## 9.1 残り 10 秒以下

残り 10 秒以下になると次の動作になります。

- 状態表示が `WRAP UP` になる
- 色調が警告寄りに変化する
- 画面が点滅演出を始める
- 通知音が 1 回鳴る

## 9.2 時間切れ

残り時間が 0 になると、タイマーは自動停止します。

時間切れ時は通知音が 3 回鳴ります。

# 10. キーボード操作

キーボードから次の操作が行えます。

- `Space`: 開始 / 一時停止
- `R`: リセット
- `T`: 時間設定ダイアログを開く
- `B`: BREAK モード切り替え
- `0`: 5 分を選択
- `1`: 10 分を選択
- `2`: 20 分を選択
- `3`: 30 分を選択
- `Esc`: ダイアログを閉じる、ダイアログが開いていなければアプリを終了する

# 11. 時間設定ダイアログ

時間設定ダイアログはメイン画面中央に重ねて表示されます。

このダイアログの仕様は次の通りです。

- 分数は直接入力ではなく `-` / `+` で変更する
- 表示は右寄せ
- `OK` で反映する
- `Cancel` で破棄する
- ダイアログ外をクリックすると閉じる
- `Esc` でも閉じる

# 12. 終了方法

アプリを終了するには次のいずれかを行います。

- `Esc` キーを押す
  ただし時間設定ダイアログが開いている場合は、最初の `Esc` はダイアログを閉じる動作になります。
- macOS の通常のアプリ終了操作を行う

# 13. 利用例

`SeminarTimer` は、たとえば次のような用途に向いています。

- オンラインセミナーで演習時間を共有する
- ハンズオンで残り時間を画面共有する
- 休憩時間を見える形で案内する
- 講師や進行役が自分用の進行管理として使う

# 14. 使い方の流れ

通常は次の流れで使います。

1. アプリを起動する
2. プリセットまたは `SET` で時間を決める
3. 必要に応じて `BREAK` モードを切り替える
4. `START` で計測を開始する
5. 必要なら `PAUSE` や `RESET` を使う
6. 時間切れまたは作業終了後にアプリを閉じる

# 15. 補足

本アプリはシンプルな運用を重視しているため、次のような設計になっています。

- 秒単位の細かい設定は行わない
- 複数タイマーの同時管理は行わない
- BREAK モードは表示モードとして扱う

セミナー進行中に迷わず使える、軽量で見やすいタイマーとして利用してください。
