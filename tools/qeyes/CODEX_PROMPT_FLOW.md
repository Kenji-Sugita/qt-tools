# Codex Prompt Flow

## 1. 最初のプロンプト

```text
X Window System で有名な xeyes を Qt で作ってください。
```

## 2. ウィンドウ仕様を固定する

```text
フレームレス、透過背景、最前面表示にしてください。
左ドラッグで移動、左ダブルクリックで終了できるようにしてください。
```

## 3. ビルドが通らない場合

```text
cmake でビルドが通るところまで進めてください。
ビルドエラーが出たら、その場で修正してください。
```

## 4. 起動確認まで進めたい場合

```text
起動して確認できる状態まで進めてください。
確認したいのは、表示、マウス追従、左ドラッグ移動、左ダブルクリック終了です。
```

## 5. 思う通りのデザインにならない場合

```text
思う通りのデザインにならない場合でも、まずは動く実装を完成させてください。
その後、必要に応じて xeyes のスクリーンショットを表示して見た目を確認し、差分を踏まえて調整してください。
```

## 6. デザインが思うとおりでない場合

```text
デザインが思うとおりでない場合は、
1. 目を今より縦長にしてください
2. 輪郭線を今より太くしてください
3. 白目の余白を今より増やしてください
4. 瞳が白目の外へ飛び出さないようにしてください
5. 2つの目の間隔を見直し、離れすぎたり詰まりすぎたりしないように調整してください

デザインの指示にはスクリーンショットを使うのがよいです。
例えば xeyes のスクリーンショットを見せて、それに寄せてください。
最初のプロンプトの段階で xeyes のスクリーンショットを見せると、より意図が伝わりやすかったです。
```

## 7. 色を変更できるようにする場合

```text
次に、目の色を変更できるようにしてください。
現在ある色要素と、この変更のために追加した色要素を変更できるようにしてください。
ダイアログで設定できるようにしてください。
右ボタンクリックで色選択ダイアログを表示してください。
```

## 8. 虹彩の追加に気づいた

```text
虹彩が追加されていることに気がつき、なぜ虹彩を追加したか理由を訊いた。
その理由は納得できるものだった。
```

## 10. 色設定ダイアログのデザイン

```text
色をクリックしたら色選択ダイアログで編集できるようにしてください。
macOS ならば OK ボタンを右側に表示してください。
```
