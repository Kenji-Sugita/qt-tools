# 1. 概要

`qeyes` は、マウスポインターの位置を追いかける 2 つの目を常時最前面に表示する小さな Qt アプリケーションです。

ウィンドウ装飾を持たない軽量なツールとして動作し、次の特徴を持ちます。

- 透明背景の小さなウィンドウとして表示される
- 黒目がマウスポインターの方向を向く
- 最前面表示で他のウィンドウの上に置ける
- ドラッグで好きな位置へ移動できる
- ダブルクリックで終了できる

# 2. 何をするアプリか

`qeyes` が行う処理はシンプルです。

- 2 つの白目を楕円で描画する
- 各目の中心からマウスポインターへの方向を求める
- 黒目が白目の内側からはみ出さない範囲で移動する
- 一定間隔で再描画して追従を滑らかに見せる

アニメーション専用の物理モデルや画像アセットに依存せず、Qt の `QPainter` によるベクター描画だけで構成されています。

# 3. 起動方法

ビルド済みバイナリーをそのまま起動します。

```text
$ ./build/qeyes
```

ソースからビルドする場合の一例です。

```text
$ cmake -S . -B build
$ cmake --build build
$ ./build/qeyes
```

macOS ではアプリバンドルとして生成される構成にも対応しています。

# 4. 基本操作

## 4.1 ウィンドウを動かす

左ボタンでドラッグすると、ウィンドウ全体を移動できます。

```text
左ドラッグ: ウィンドウ移動
```

## 4.2 終了する

左ボタンでダブルクリックすると終了します。

```text
左ダブルクリック: 終了
```

ウィンドウを閉じた場合もアプリケーション全体が終了します。

# 5. 表示の仕組み

`qeyes` の見た目はコード内で動的に描画されています。

## 5.1 目の形

左右の目は、ウィンドウの大きさから次のように計算されます。

- 外側に余白をとる
- 左右 2 つの楕円領域を作る
- それぞれの内部に黒目を描く

## 5.2 黒目の追従

黒目の中心位置は、各目の中心と現在のマウスポインター座標から求めます。

ただし、そのままポインター方向へ無制限に移動させるのではなく、白目の内側に収まる範囲で制限しています。

## 5.3 再描画

約 16 ミリ秒ごとに再描画しているため、おおむね 60fps 相当で追従します。

# 6. ウィンドウの性質

`qeyes` は通常のアプリウィンドウとは少し性質が異なります。

- フレームレスウィンドウ
- ツールウィンドウ
- 常に最前面
- 透過背景
- 起動時にアクティブ化しない設定

# 7. 実装上のポイント

## 7.1 透過描画

背景は透明で、描画のたびに一度ウィンドウ全体を透明で塗り直しています。

## 7.2 物理寸法ベースの余白

黒目と輪郭の間隔は、単純な固定ピクセル値だけでなく、ミリメートルからピクセルへ換算した値も使って決めています。

## 7.3 依存ライブラリー

使用している Qt モジュールは次の通りです。

- `Qt6::Core`
- `Qt6::Gui`
- `Qt6::Widgets`

# 8. 想定している使い方

`qeyes` は高機能なデスクトップユーティリティではなく、次のような軽量用途を想定しています。

- デスクトップ上の遊び心のある常駐表示
- Qt Widgets での透過描画の最小実装例
- マウス追従 UI のサンプル
- 配布用の小さなデモアプリ

# 9. 制約と注意点

現状の実装では、次の点に注意が必要です。

- ウィンドウサイズの変更 UI はない
- 位置やサイズの永続化はしない
- 目の色や形は変更できない
- 複数モニター環境での細かな挙動調整機能はない
- 終了操作はダブルクリック前提

# 10. まとめ

`qeyes` は、マウスポインターを見つめる目を最前面に表示する単機能な Qt Widgets アプリです。

コード量を抑えつつ、透過ウィンドウ、カスタムペイント、マウス追従、ドラッグ移動、タイマー駆動の再描画をひと通り含んでいます。
