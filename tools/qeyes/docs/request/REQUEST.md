# 要望書

## 背景

デスクトップ上に小さく常駐し、マウスポインターの動きに反応する遊び心のあるアプリケーションが欲しい。

同時に、Qt Widgets による透過描画や追従 UI の実装例としても扱える、小さくまとまった題材にしたい。

## 欲しいもの

- デスクトップ上に 2 つの目を表示する小さなアプリ
- 目がマウスポインターの方向を向くこと
- 軽量に動作すること
- 目立ちすぎず、ちょっとしたアクセサリーとして使えること

## 期待する体験

- 起動するとすぐに目が表示される
- マウスポインターを動かすと自然に視線が追従する
- 邪魔にならない小さな常駐ツールとして使える
- 見た目を少しだけ調整できる

## 必須の希望

- 2 つの目を表示したい
- マウスポインター追従を実現したい
- ウィンドウをドラッグで移動したい
- 簡単に終了できるようにしたい

## あるとよい希望

- 目の色を変えられるようにしたい
- 小さな設定ダイアログを持たせたい
- 設定を次回起動時にも保持したい

## 今は不要なこと

- 複雑なテーマ機能
- 多数の設定項目
- トレイ常駐
- 高度なアニメーション
- 大規模な UI

## 成果イメージ

- 小さな `qeyes` アプリがデスクトップ上に表示されている
- 目がマウスポインターを追って動く
- 必要最小限の操作だけで扱える
- コードと文書が整理され、継続的に改善できる状態になっている
