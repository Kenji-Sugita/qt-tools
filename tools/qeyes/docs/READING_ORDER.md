# 読む順番ガイド

## 目的

この資料は、`qeyes` の文書群を他の人が確認するときに、どこからどの順に読めばよいかを示すための入口資料である。

この資料は、`docs/pdf` にある PDF を読む順番だけを示す。

## docs/pdf にある PDF の読む順番

### 最初に読む PDF

1. `README.pdf`
2. `READING_ORDER.pdf`
3. `EXPERIMENT_PROCEDURE.pdf`

### 工程を追う PDF

1. `request-complete-from-pdfs.pdf`
2. `requirements-complete-from-pdfs.pdf`
3. `architecture-complete-from-pdfs.pdf`
4. `design-complete-from-pdfs.pdf`

### 補助資料 PDF
