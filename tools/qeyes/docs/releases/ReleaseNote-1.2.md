# qeyes 1.2 リリースノート

`qeyes` 1.2 では、色設定ダイアログの視認性を改善し、文書構成を整理しました。

## 追加した機能

- ルート `README.md` を追加しました
- 版付き利用ガイドと版付きリリースノートの導線を整理しました

## 改善点

- 色プレビューの文字を等幅フォントにしました
- 色プレビューの文字サイズをボタン文字の寸法感に合わせました
- `docs/README.md` を `docs/` ディレクトリの案内に整理しました
- `AGENTS.md` にアプリ実装方針、リソース運用方針、README 運用ルール、文書追加時の更新ルールを追加しました

## 操作方法

- 左ドラッグ: ウィンドウ移動
- 左ダブルクリック: 終了
- 右クリック: 色設定ダイアログを開く

## ビルドと起動

```text
$ cmake -S . -B build
$ cmake --build build
$ ./build/qeyes
```

詳しい使い方は `docs/guides/USER_GUIDE-1.2.md` を参照してください。
