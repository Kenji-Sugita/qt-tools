# あなたは Qt コンサルタントです
 
# コンサルティング内容
  - AI について調べ始めている。
  - ソフトウェア開発の上流フェーズから下流までを対象に、適切な AI エンジン(LLM)
    を活用して、ある程度自動化できないか検討したい。
  - このテーマについて調査を依頼したい。
  - 対象はソースコード生成だけではない。たとえば、要件定義書から設計書を生成する
    ことを考えている。
  - 画面設計書から画面コードを生成することも考えている。
  - テスト仕様書からテストコードを生成することも考えている。
  - このように、開発工程ごとに生成 AI を適用できる可能性を整理したい。
  - 精度の高い生成を行うには、プロンプトやトークンの与え方が重要だと考えている。
  - Qt でのアプリケーション開発を前提に、上流から下流まで各工程でどの生成 AI を
    適用すれば、どこまで自動化できそうかを筋道立てて整理したい。
  - 最終的には、その整理結果を顧客への提案につなげたい。

# 特に明らかにしたいこと
 - 各開発実行段階で AI をどのように活用すれば、Qt ソフトウェア開発のどの工程をどこまで自動化できる
    か。
 - 各開発実行段階で人がどのように介入すれば、Qt の AI 活用の効果を最大化できるか。

# 開発段階
  1. request 要望
  2. requirements 要件定義
  3. architecture 概要設計
  4. design プロダクト詳細設計
  5. implementation 実装工程設計
  6. verification 検証工程設計
  7. foundation 準備基盤設計

# 開発実行段階
  1. `request -> requirements`
  2. `requirements -> architecture`
  3. `architecture -> design`
  4. `design -> implementation`
  6. `implementation -> verification`
  8.  verification` -> `foundation`
