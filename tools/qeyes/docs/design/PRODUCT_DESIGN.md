# プロダクト詳細設計

## 目的

`qeyes` が提供する機能、操作、状態、設定対象を定義する。

## 対象機能

- 目の常時表示
- マウスポインター追従
- ウィンドウ移動
- 終了操作
- 色設定ダイアログ
- 色設定の永続化

## 機能要件

### 1. 常時表示

- 2 つの目を持つ小さなウィンドウを表示する
- ウィンドウは最前面表示とする
- 背景は透明とする

### 2. 視線追従

- 目はマウスポインターの方向を向く
- 虹彩と瞳孔は白目の範囲内で移動する

### 3. 基本操作

- 左ドラッグでウィンドウを移動する
- 左ダブルクリックでアプリケーションを終了する
- 右クリックで色設定ダイアログを開く

### 4. 色設定

- 輪郭、白目、虹彩、瞳孔の色を個別に設定できる
- 色プレビューをクリックすると色選択ダイアログを開く
- `Reset` で対象項目を既定値に戻す
- `OK` で保存する
- `Cancel` で破棄する

### 5. 永続化

- 色設定は `QSettings` に保存する
- 次回起動時に復元する

## 状態

### 保持する状態

- ウィンドウ位置
  - 現状では保持しない
- 色設定
  - 輪郭
  - 白目
  - 虹彩
  - 瞳孔

## 対象外

- ウィンドウサイズ変更 UI
- トレイ常駐
- クリック透過
- 複数テーマ管理
- 高度なアニメーション設定
