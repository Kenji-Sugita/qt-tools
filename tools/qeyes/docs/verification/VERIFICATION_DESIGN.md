# 検証工程設計

## 目的

`qeyes` の実装成果物が、設計書と実装方針に沿って正しく生成されたことを確認する工程を定義する。

## 入力

- `CMakeLists.txt`
- `main.cpp`
- `qeyes.rc`
- `assets/`
- `AGENTS.md`

## 出力

- `BUILD_RESULT.md`
- `VERIFICATION_RESULT.md`
- `ISSUES.md`

## 役割

- ビルド定義が成立していることを確認する。
- アプリが起動し、基本操作が成立していることを確認する。
- リソース参照が壊れていないことを確認する。
- 設定や描画が主要仕様を満たしていることを確認する。
- ビルド結果、実行結果、修正事項を所定の成果物ファイルへ記録する。

## 確認対象

- `cmake` による構成生成
- アプリのビルド
- 起動可否
- マウス追従
- ウィンドウ移動
- 終了操作
- 色設定ダイアログ
- 設定保存と再読み込み

## 対象外

- 詳細な性能測定
- 自動 UI テストの整備
- 配布パッケージの検証

## 完了条件

- ビルドが通る。
- アプリが起動する。
- 主要操作が仕様通りに動く。
- `BUILD_RESULT.md` にビルド確認結果が記録されている。
- `VERIFICATION_RESULT.md` に実行確認結果が記録されている。
- 既知の不整合があれば `ISSUES.md` に記録されている。

## 将来拡張

次のような検証が必要になった場合は、この工程の下で文書を分割する。

- 自動テスト
- プラットフォーム別検証
- 配布物検証
