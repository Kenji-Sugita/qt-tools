# ワリカンアプリ UI仕様書

## 1. 目的

本書は、ワリカンアプリの画面、表示項目、入力項目、操作、エラー表示を定義する。
UI は UC仕様書に定義されたユースケースを実行できることを目的とする。

## 2. 画面一覧

| 画面ID | 画面名 | 概要 |
| --- | --- | --- |
| SCR-1 | ワリカン計算画面 | 会計総額、丸め単位、負担区分を入力し、計算結果を表示する。 |
| SCR-2 | 集金管理画面 | 計算結果から生成された対象者の集金状況を管理する。 |

## 3. 共通UI

### 3.1 アプリヘッダー

画面上部に次の情報を表示する。

- ラベル: `WARIKAN SPA`
- タイトル: `ワリカンアプリ`
- 説明文: `会計総額と負担区分を入力すると、比率按分・丸め・差額調整まで含めてワリカン額を計算し、そのまま集金状況の管理まで行えます。`

### 3.2 タブ

画面切り替え用に次のタブを表示する。

| タブ名 | 遷移先 |
| --- | --- |
| ワリカン計算 | SCR-1 |
| 集金管理 | SCR-2 |

初期表示は `ワリカン計算` タブとする。

### 3.3 通知エリア

入力、計算、集金管理に関するメッセージを表示する。

表示例:

- `ワリカン額を計算しました`
- `入力内容を変更すると、計算結果と集金記録はリセットされます。`
- `入力内容を確認してください`

## 4. SCR-1 ワリカン計算画面

### 4.1 画面目的

幹事がワリカン計算条件を入力し、区分ごとの金額を確認できるようにする。

### 4.2 レイアウト

デスクトップ幅では、入力エリアと計算結果エリアを 2 カラムで表示する。
狭い画面幅では、入力エリア、計算結果エリアの順に 1 カラムで表示する。

```text
[入力エリア] [計算結果エリア]
```

### 4.3 入力エリア

入力エリアの見出しは `SCR-1 ワリカン計算画面` とする。

#### 4.3.1 会計総額

| 項目 | 内容 |
| --- | --- |
| ラベル | 会計総額 |
| 入力種別 | 数値 |
| 初期値 | `50000` |
| 必須 | 必須 |
| 補足 | 0 より大きい整数を入力する。 |

#### 4.3.2 丸め単位

| 項目 | 内容 |
| --- | --- |
| ラベル | 丸め単位 |
| 入力種別 | 数値 |
| 初期値 | `500` |
| 必須 | 必須 |
| 補足 | 1 以上の整数を入力する。 |

#### 4.3.3 負担区分

負担区分はカード形式で複数表示する。
各カードには次の項目を表示する。

| 項目 | 内容 |
| --- | --- |
| 区分見出し | `区分 1`、`区分 2` のように表示順を示す。 |
| 区分名 | テキスト入力。 |
| 比率 | 数値入力。0 より大きい値。 |
| 人数 | 数値入力。1 以上の整数。 |
| 削除 | 対象区分を削除するボタン。 |

初期表示の負担区分は次の 3 件とする。

| 区分名 | 比率 | 人数 |
| --- | ---: | ---: |
| 多め | 1.5 | 2 |
| 普通 | 1.0 | 6 |
| 少なめ | 0.5 | 2 |

#### 4.3.4 区分を追加

| 項目 | 内容 |
| --- | --- |
| 表示名 | 区分を追加 |
| 動作 | 新しい負担区分を末尾に追加する。 |
| 初期値 | 区分名は空、比率は `1.0`、人数は `1` とする。 |

#### 4.3.5 計算する

| 項目 | 内容 |
| --- | --- |
| 表示名 | 計算する |
| 動作 | 入力値を検証し、ワリカン計算を実行する。 |

### 4.4 計算結果エリア

計算結果エリアの見出しは `計算結果` とする。

計算済みの場合、次の表を表示する。

| 列 | 内容 |
| --- | --- |
| 区分名 | 負担区分名。 |
| 1人あたり | 区分ごとの 1 人あたり金額。 |
| 人数 | 区分の人数。 |
| 小計 | 1 人あたり金額 × 人数。 |

計算結果表の下に合計検証を表示する。

| 項目 | 内容 |
| --- | --- |
| 合計検証 | 会計総額と計算結果合計が一致していれば `OK`、一致しなければ `差額あり`。 |
| 結果: 合計 | 計算結果合計を円表記で表示する。 |

計算済みの場合、`集金管理へ進む` ボタンを表示する。

### 4.5 初期表示

初期表示時は、初期値を入力済みの状態で表示する。
初期表示時点では計算結果を未計算として扱ってよい。

### 4.6 入力変更時の挙動

計算済みの状態で入力内容が変更された場合、既存の計算結果と集金管理情報はリセットする。
通知エリアに `入力内容を変更すると、計算結果と集金記録はリセットされます。` を表示する。

### 4.7 バリデーション

計算実行時に次を検証する。

| 対象 | 条件 | エラー |
| --- | --- | --- |
| 会計総額 | 1 以上の整数 | `会計総額は1以上の整数で入力してください。` |
| 丸め単位 | 1 以上の整数 | `丸め単位は1以上の整数で入力してください。` |
| 区分名 | 空でない | `区分名を入力してください。` |
| 比率 | 0 より大きい数値 | `比率は0より大きい数値で入力してください。` |
| 人数 | 1 以上の整数 | `人数は1以上の整数で入力してください。` |

複数のエラーがある場合は、確認しやすい形でまとめて表示する。

## 5. SCR-2 集金管理画面

### 5.1 画面目的

計算結果から生成された対象者について、集金済み / 未集金の状態を管理する。

### 5.2 表示条件

計算結果が存在しない場合、集金管理画面には計算が必要である旨を表示する。
計算結果が存在する場合、集金対象者一覧を表示する。

### 5.3 集金対象者一覧

次の列を表示する。

| 列 | 内容 |
| --- | --- |
| 名前 / 区分 | 対象者名。区分名と連番で生成する。例: `多め 1`。 |
| 金額 | 対象者が支払う金額。 |
| 状態 | `未集金` または `集金済み`。 |
| 操作 | 状態切り替えボタン。 |

### 5.4 状態切り替え

対象者が未集金の場合、操作ボタンは `集金済みにする` とする。
対象者が集金済みの場合、操作ボタンは `未集金に戻す` とする。

### 5.5 集金サマリー

一覧の上部または下部に次を表示する。

| 項目 | 内容 |
| --- | --- |
| 合計予定額 | 集金対象者全員の金額合計。 |
| 集金済み | 集金済み対象者の金額合計。 |
| 未集金 | 未集金対象者の金額合計。 |

状態切り替え時、集金サマリーを即時更新する。

## 6. デザイン方針

### 6.1 全体

- 画面全体はワリカン管理に集中できる、落ち着いた業務ツール寄りの見た目とする。
- 背景は淡いベージュ系を基調とする。
- 入力欄や結果表示は白または淡色の面で区切る。
- 主操作ボタンは茶系、完了や正常状態は緑系で示す。

### 6.2 表示形式

- 金額は 3 桁区切りの円表記とする。例: `50,000円`
- 比率は入力値の数値をそのまま表示する。
- 人数は `2人` のように表示する。
