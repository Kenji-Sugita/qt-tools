# warikan

`warikan` は、会計総額と負担区分からワリカン額を計算し、計算結果をもとに集金状況を管理する静的 Web アプリです。

この配布物には、動作する Web アプリ本体、三点セットの仕様書、実装指示書、参考資料が含まれています。

## 配布ファイル

- `warikan-release-20261108.zip`: Web アプリ、仕様書、ユーザーガイド、参考資料を含む配布アーカイブです。

文書・配布版 1.0.1 は、現行ガイドにそろえた配布版です。アプリ本体と仕様書は変更していません。

## 含まれるもの

- `src/index.html`: ブラウザで開くアプリ本体です。
- `src/style.css`: アプリの見た目を定義するスタイルです。
- `src/app.js`: ワリカン計算、集金管理、画面操作を実装する JavaScript です。
- `docs/01_usecase_spec.md`: UC 定義書 / UC 仕様書です。
- `docs/02_ui_spec.md`: UI 仕様書です。
- `docs/03_business_spec.md`: ビジネスレイヤー仕様書です。
- `codex_prompt_without_zip.md`: 三点セットを Codex に適用して実装するための指示書です。
- `USER_GUIDE.md`: このユーザーガイドの Markdown 版です。
- `USER_GUIDE.pdf`: このユーザーガイドの PDF 版です。
- `warikan.txt`: 元になった説明メモです。
- `warikan.png`: 参考画面イメージです。

## 前提

アプリを使うだけなら、次のものがあれば動作します。

- Web ブラウザ

サーバー、データベース、外部ライブラリは不要です。

開発者が JavaScript の構文確認を行う場合は、次のものが必要です。

- Node.js

## 確認の流れ

配布アーカイブを確認する場合は、次の順に進めます。

1. `warikan-release-20261108.zip` を展開します。
2. 展開された `warikan/` ディレクトリを開きます。
3. `USER_GUIDE.md` または `USER_GUIDE.pdf` を読みます。
4. `docs/01_usecase_spec.md`、`docs/02_ui_spec.md`、`docs/03_business_spec.md` で三点セットを確認します。
5. `src/index.html` をブラウザで開きます。
6. 代表例で計算結果を確認します。
7. `集金管理へ進む` を押して、集金状況の切り替えを確認します。

## 実行

ブラウザで次のファイルを開きます。

```text
src/index.html
```

ローカルファイルとして開けば動作します。開発用サーバーは不要です。

## 画面

アプリには次の 2 画面があります。

- `ワリカン計算`: 会計総額、丸め単位、負担区分を入力し、区分別の 1 人あたり金額と小計を計算します。
- `集金管理`: 計算結果から人数分の集金対象者を生成し、集金済み / 未集金を切り替えます。

## 操作手順

### ワリカン計算

1. `ワリカン計算` タブを開きます。
2. `会計総額` を入力します。
3. `丸め単位` を入力します。
4. 負担区分ごとに `区分名`、`比率`、`人数` を入力します。
5. 必要に応じて `区分を追加` または `削除` を使います。
6. `計算する` を押します。
7. `計算結果` で区分ごとの金額と合計検証を確認します。

### 集金管理

1. ワリカン計算後に `集金管理へ進む` を押します。
2. `集金管理` 画面で対象者一覧を確認します。
3. 対象者ごとに `集金済みにする` または `未集金に戻す` を押します。
4. 合計予定額、集金済み、未集金の金額が更新されることを確認します。

## 代表例

初期値は次の代表例になっています。

- 会計総額: 50000 円
- 丸め単位: 500 円
- 多め: 比率 1.5、人数 2
- 普通: 比率 1.0、人数 6
- 少なめ: 比率 0.5、人数 2

期待結果は次の通りです。

- 多め: 7500 円 x 2 = 15000 円
- 普通: 5000 円 x 6 = 30000 円
- 少なめ: 2500 円 x 2 = 5000 円
- 合計: 50000 円
- 合計検証: OK

## 保存と入力変更時の注意

計算結果と集金記録はページ内のメモリーで管理し、ブラウザーを閉じたり再読み込みしたりした後の保存・復元は行いません。実務で使う場合は必要な記録を別途残してください。

計算後に次の内容を変更すると、既存の計算結果と集金記録はリセットされます。

- 会計総額
- 丸め単位
- 負担区分の追加
- 負担区分の削除
- 区分名
- 比率
- 人数

## 開発者向け確認

JavaScript の構文確認は、リポジトリ直下で次のように実行します。

```sh
node --check src/app.js
```

代表例のロジック確認を行う場合は、`src/app.js` が CommonJS の `module.exports` で主要関数を公開しているため、Node.js から `calculateWarikan`、`createCollectionMembers`、`summarizeCollection` を呼び出して確認できます。

## 三点セットから再生成する場合

同梱の `warikan.txt` は過去の個別試行についてのメモです。記載された所要時間や評価を、現在の全環境・再生成結果の保証として扱わないでください。

三点セットからアプリを再生成または更新する場合は、`codex_prompt_without_zip.md` の指示を Codex に渡します。

その指示では、実装対象を `src/` 配下に限定し、`docs/` 配下の三点セットを変更しないこと、配布用 zip を作成しないことを明記しています。
