# Codex 実装指示書

docs/01_usecase_spec.md、docs/02_ui_spec.md、docs/03_business_spec.md に従って、ワリカン計算アプリを実装してください。

## 要件

- HTML/CSS/JavaScript のみで実装する
- src/index.html をブラウザで開けば動作する
- サーバー、データベース、外部ライブラリは使わない
- 仕様にない機能追加はしない
- warikan.png は見た目の参考としてのみ使う
- docs 配下の三点セットは変更しない
- 既存の src/index.html / src/style.css / src/app.js がある場合は、三点セットに従って必要最小限で更新する
- 配布用 zip は作成しない
- 実装後、代表値で動作確認する
- 実装後、JavaScript の構文確認を行う

## 代表値

- 会計総額: 50000
- 丸め単位: 500
- 多め: 比率 1.5、人数 2
- 普通: 比率 1.0、人数 6
- 少なめ: 比率 0.5、人数 2

## 期待結果

- 多め: 7,500円 x 2人 = 15,000円
- 普通: 5,000円 x 6人 = 30,000円
- 少なめ: 2,500円 x 2人 = 5,000円
- 合計: 50,000円
- 合計検証: OK

## 報告内容

実装後、作成・変更したファイルと、動作確認結果を報告してください。
