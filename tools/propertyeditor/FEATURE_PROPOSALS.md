# 機能提案

## 提案一覧

1. オブジェクトツリーとプロパティーエディターの選択同期（実装済み）
   オブジェクトツリーで選んだ対象と、現在 inspected 中の対象を相互に同期して、どこを見ているか分かりやすくする。
2. オブジェクトツリーの検索フィルタ（実装済み）
   `objectName` やクラス名でツリーを絞り込み、大きい画面や複合ウィジェットでも対象をすぐ見つけられるようにする。
3. 現在選択中オブジェクトのパンくず表示（実装済み）
   `MainWindow > centralWidget > panel > applyButton` のように親子パスを表示し、選択対象の位置関係を把握しやすくする。
4. デフォルト値や初期値との差分ハイライト
   現在値が初期値やデフォルト値から変わっているプロパティーを色分けし、どこが変更されたかを素早く確認できるようにする。
5. signal 監視パネル
   選択中オブジェクトの代表的な signal 発火を簡易ログとして表示し、プロパティー変更とイベント発生を合わせて追えるようにする。
6. レイアウト詳細表示（実装済み）
   `spacing`、`contentsMargins`、`sizeConstraint`、管理アイテム数などを一覧表示し、レイアウト状態を別途把握しやすくする。
7. オーバーレイの固定モード
   現在の選択変更に関係なくハイライトを残し、複数対象の位置や大きさを比較できるようにする。
8. 親子兄弟への移動ショートカット
   現在選択中オブジェクトから親、最初の子、次の兄弟などへキーボードで移動できるようにし、ツリー探索を高速化する。
9. read-only / hidden プロパティーの表示切替
   通常は編集対象中心に表示しつつ、必要時だけ read-only や hidden なプロパティーも表示できるようにする。
10. スナップショットと差分比較
   ある時点のオブジェクトツリーとプロパティー値を保存し、別時点との違いを比較できるようにする。
