# Roadmap

## 目的

この文書は、`qmlprofileranalyzer` の残作業を

- 優先順位
- 目的
- 段階

で整理するためのメモである。

## 現在地

現時点でできていること:

- `.qtd` / `.qzt` の読み込み
- `summary`, `types`, `events`, `events-aggregated`, `notes`
- `PixmapCache`, `SceneGraph`, `MemoryAllocation`, `DebugMessage` の比較用集約
- Qt Creator 比較向けの補助ラベル付け
- 最小デモ、`qml` デモ、実行形式デモ
- `samegame.qzt` を使った評価文書と手順書

現時点で不足していること:

- 機械可読出力
- 詳細なフィルタと統計
- Qt Creator 比較のさらなる整備

## 優先度 A

### 1. JSON 出力

目的:

- 解析結果を機械可読にする
- 評価文書の再利用をしやすくする
- 将来の半自動レポート作成につなげる

入れたい内容:

- `summary` 相当
- `types` 相当
- `events` 相当
- `events-aggregated` 相当
- `notes` 相当

期待する効果:

- 人手での転記を減らせる
- 集約結果を他ツールから使いやすくなる

### 2. 集約結果の summary 連携

目的:

- `events-aggregated` を見なくても主要な比較情報を把握しやすくする

入れたい内容:

- `PixmapCache` の代表例
- `SceneGraph` の主要ピーク
- `MemoryAllocation` の種別 summary
- `DebugMessage` の level summary

期待する効果:

- 評価文書の骨子を `summary` から作りやすくなる

## 優先度 B

### 3. フィルタ機能

目的:

- 大きいトレースを絞って読みやすくする

候補:

- 時間範囲フィルタ
- type フィルタ
- file / line フィルタ

期待する効果:

- `samegame.qzt` より大きい実トレースでも使いやすくなる

### 4. 詳細統計

目的:

- 重い処理をより定量的に把握する

候補:

- 上位 N 件
- file / line 単位の集計
- 関数単位の集計
- フェーズ別集計

期待する効果:

- 評価文書の具体性が上がる
- 手作業の集計を減らせる

## 優先度 C

### 5. Qt Creator 比較の追加整備

目的:

- 比較時の迷いをさらに減らす

候補:

- 表示名の追加調整
- 分類ラベルの追加調整
- `SceneGraph` の stage 表現改善
- 他の `.qzt` を使った比較例の追加

期待する効果:

- 人間向けの比較作業がさらにやりやすくなる

### 6. 書き出し対応

目的:

- 将来の相互運用を見据える

候補:

- `.qtd` 書き出し
- `.qzt` 書き出し

備考:

- 現時点では優先度は低い
- まずは read / analyze を強くする方が妥当

## 推奨順

今の流れからの推奨順:

1. JSON 出力
2. 集約結果の summary 連携
3. フィルタ機能
4. 詳細統計
5. Qt Creator 比較の追加整備
6. 書き出し対応

## 補足

- 人間向けの比較と評価文書作成は、すでにかなり進めやすい状態にある
- 次に効くのは、人間向け改善よりも再利用性の向上である
- そのため、次の本命は `JSON 出力` と考える
