# 付録 A. よく使うコマンド

| コマンド | 用途 |
|---|---|
| `.e <file>` | ファイルをエディタで開き、閉じた後に再評価します |
| `.i <path>` | 必要な場合に include path を追加します |
| `.gen` | `run_all` を実行し、生成物更新後に再評価します |
| `.autogen on` | `.e` / `.r` の前に必要なら自動生成します |
| `.status` | 現在状態を表示します |
| `.files` | 登録ファイルを表示します |
| `.defs` | 定義された関数や class を表示します |
| `.! <command>` | 外部 shell command を実行します |
| `.errors` | 直近のエラーを表示します |
