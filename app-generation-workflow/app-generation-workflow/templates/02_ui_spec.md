# アプリ名 UI仕様書

## 1. 概要

本書は、対象アプリの UI 仕様を定義する。

## 2. アプリ種別

仕様化前ノートと UC仕様書で整理したアプリ種別を記載する。
UI仕様では、種別に応じて利用者が見る画面、操作、状態変化を明確にする。

- 種別:
- 補足:

種別別の主なUI確認観点:

| 種別 | UIで重視する内容 |
| --- | --- |
| 入力・計算・結果表示アプリ | 入力欄、実行操作、結果表示、入力エラー |
| データ管理アプリ | 一覧、詳細、追加、編集、削除、状態表示 |
| ビューアアプリ | 表示対象、表示切替、検索、絞り込み、空表示 |
| エディタアプリ | 編集領域、保存操作、未保存状態、取り消し |
| 変換ツール | 入力指定、変換条件、進行状態、変換結果 |
| ゲーム / インタラクティブアプリ | 開始状態、操作、画面更新、終了状態 |
| その他 | 利用者が判断に必要な表示と操作 |

## 3. 共通UI
