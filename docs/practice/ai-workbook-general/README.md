# 仕事で試す、AIへの頼み方 練習帳

社内外の連絡や資料作成を行う方が、自分の業務でAIへの頼み方と結果の確認方法を練習するための4冊です。特定の製品やプロジェクトの知識は必要ありません。

## 最初に使うもの

初めての方は、01の「手元に文章がない場合：この例で一度試す」から始めてください。架空の会議室のお知らせを使うため、材料の準備は不要です。結果を元の文章と比較し、採用・修正の理由を説明できれば、最初の練習は完了です。

## 4冊の進め方

1. [まず試してみる：AIへの頼み方](01_getting_started.md)：文章の整形、参考資料との照合、返信の確認を試します。
2. [もう少し試してみる：身近なAI活用例](02_more_examples.md)：任意の補足です。件名、短縮、催促、作業整理などから一例を選びます。
3. [仕事の資料を作成・更新する：AIへの頼み方](03_work_documents.md)：案内文、会議資料、手順書、活動報告などから、自分の作業に近い例を一つ選びます。
4. [AIへの指示を見直し、成果物の品質を高める](04_request_and_review.md)：新しい業務手順の説明資料を例に、依頼の不足を見つけ、確認・修正・比較を3回に分けて進めます。

一度に全冊を読む必要はありません。03・04は冒頭の案内で読む範囲を選べます。各冊の完了基準に沿って一例を試し、その後、自分の業務への置き換え方を参照してください。練習の完了と、成果物を実務で共有できる状態は分けて判断します。

## 必要なものと使い方

文章を入力できるAIを使います。特定のAI製品は指定していません。依頼例の【AIへの依頼文：ここから】と【AIへの依頼文：ここまで】の間をコピーし、指定された箇所を自分の情報に置き換えて送信します。

ファイルや画像は、使う環境が読み取れる場合だけ渡します。利用できない場合は必要な本文を貼り付け、画面や紙面の見え方は未確認として残します。01の末尾に、ファイル名と役割を伝える方法があります。

実務で試す場合は、作成・更新する資料、内容の根拠、必要に応じて書き方の見本を用意します。社外秘情報や個人情報は、所属組織のルールに従って扱ってください。AIの結果を人が元資料と確認し、判断できない点は担当者に確認します。参考資料との一致だけで、資料自体が最新・正確だとは判断しません。
