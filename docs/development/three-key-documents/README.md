# 三点セット解説書一式

[English](README.en.md) / [文書一覧](../../README.md)

UC・UI・ビジネスレイヤーの三点セットを使い、新規のコード生成、既存コードからの仕様候補の抽出、移行を進める解説書です。共通のファイル構成ガイドを含みます。

新規作成はコード生成、既存システムの理解は逆生成、移行は逆生成の必要性を判断してから移行の解説へ進みます。まず入口ガイドで読む順番を確認してください。
