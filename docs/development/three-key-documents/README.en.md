# Three-Specification Guides

[日本語](README.md) / [Documentation](../../README.en.md)

Guides to generating code, recovering specification candidates from existing code, and planning migrations using use-case, UI, and business-layer specifications. Includes a shared file-structure guide.

Start with the user guide to choose a route: code generation for new work, reverse generation for understanding existing systems, and migration after deciding whether specification recovery is needed.
