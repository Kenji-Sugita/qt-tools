# アプリ名 UC仕様書

## 1. 概要

本書は、対象アプリの UC(UseCase) を定義する。

## 2. アプリ種別

仕様化前ノートで選択したアプリ種別を記載する。
この種別は、ユースケースの粒度と確認観点を決めるために使う。

- 種別:
- 補足:

種別別の主な確認観点:

| 種別 | 重視するUC |
| --- | --- |
| 入力・計算・結果表示アプリ | 入力する、実行する、結果を確認する、入力不備を修正する |
| データ管理アプリ | 登録する、一覧する、更新する、削除する、状態を変更する |
| ビューアアプリ | 対象を開く、表示を切り替える、検索する、絞り込む |
| エディタアプリ | 作成する、編集する、保存する、取り消す、変更を確認する |
| 変換ツール | 入力を指定する、変換する、変換結果を確認する、失敗を確認する |
| ゲーム / インタラクティブアプリ | 開始する、操作する、状態が変化する、終了条件を確認する |
| その他 | 目的に応じてUCを定義する |
