# backlog

Use this file for long-term remaining work, problems, and deferred items that will not be tackled immediately next time.
Put the current state and items directly needed to resume work in `NEXT.md`. Put lasting specifications, design decisions, rejection rationale, decision criteria, and operating constraints in `DECISIONS.md`.
Do not use this file as an archive for completion history or validation logs.

## Remaining Work

### 1. Item Name

- Describe the remaining work.
- State why it is needed or its completion criteria.
- List related files and references.

## Problems

### 1. Problem Name

- Describe the currently known problem.
- Describe its impact.
- Reference investigation results or reproduction conditions.

## Deferred Items

### 1. Item Name

- Describe what is deferred.
- Explain why it is deferred.
- State the conditions for reconsideration.
