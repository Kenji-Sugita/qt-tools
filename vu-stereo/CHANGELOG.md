# Changelog

## 1.0.0 - 2026-08-30

### Added

- Added stereo VU meter display for macOS system audio.
- Added arc and linear meter backgrounds.
- Added adjustable input level, needle width, pivot display, lowered pivot,
  peak hold, language, and always-on-top settings.
- Added persistent settings with QSettings, including window position.
- Added local code signing workflow for Screen Recording permission continuity.
- Added user guide, signing notes, and privacy policy.
- Documented the product intent as a visual audio accessory rather than an
  instrument-grade meter.
